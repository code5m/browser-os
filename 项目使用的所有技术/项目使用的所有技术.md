# 项目使用的技术全景

根据目前看到的源码路径、构建过程和 Rust 编译器实际加载的依赖，这个项目本质上是一个：

> **Vue 前端外壳 + Tauri/Rust 原生主程序 + Linux GTK/WebKitGTK 原生多页签 WebView + 多数据库与系统能力集成的桌面浏览器工作台。**

它不是普通网页应用，也不是 Electron 套壳浏览器。

## 一、整体技术架构

```text
Vue 主界面
├── 页签栏、工具栏、状态栏、宫格界面
├── 会话关闭确认框
├── Store 状态层
└── Composable 逻辑层
          │
          │ Tauri IPC / Command / Event
          ▼
Rust / Tauri 原生主程序
├── 窗口生命周期
├── 单实例
├── 会话与数据访问
├── 剪贴板、密钥环、文件打开
├── Git、终端、数据库能力
└── Linux 原生布局桥接
          │
          ▼
自研 tauri-plugin-browser-tabs
├── 每个页签一个原生子 WebView
├── WebView 创建、移动、隐藏、恢复
├── 页签尺寸与位置同步
└── Linux GTK/WebKitGTK 平台实现
          │
          ▼
SQLite / MySQL / PostgreSQL
Linux 桌面系统 / DEB / XDG Desktop
```

### Tauri

Tauri 是整个桌面应用的主框架，负责：

- 创建主窗口
- 前端与 Rust 通信
- 打包应用资源

- 管理窗口权限

- 注册应用菜单
- 管理原生插件

实际构建链是：

```text
npm
  → Node.js Tauri CLI
  → Cargo
  → rustc
  → Release 二进制
  → Debian 安装包
```

构建进程中可以看到 `npm run tauri build`、Node 版 Tauri CLI、`cargo build --release` 和 `rustc` 顺序执行。

### Tauri IPC / Bridge

项目通过类似以下 Rust 模块承接前后端桥接：

```text

```

这部分负责：

- Vue 调用 Rust Command
- 原生 WebView 创建和定位
- 主窗口物理尺寸校正
- 页签显隐
- 弹窗期间暂停或移开浏览器 WebView
- 恢复 WebView 状态

## 六、刚才浮窗问题涉及的技术原理

刚才关闭确认框被网页遮挡，并不是普通 CSS 层级问题。

项目实际上存在两个不同的显示层：

```text
第一层：Vue / HTML 主界面
第二层：GTK 原生子 WebView
```

CSS 的：

```css
z-index: 99999;
```

只能调整同一个 HTML/WebView 内部的层级，不能让主界面的 HTML 元素压过另一个原生 GTK 子窗口。

因此最终采用的是原生窗口生命周期处理：

```text
用户点击关闭页签
        ↓
暂停网页定位
        ↓
临时隐藏或移开原生网页 WebView
        ↓
显示 Vue 的关闭确认框
        ↓
用户选择保存 / 删除 / 取消
        ↓
关闭或恢复原生 WebView
        ↓
重新同步位置与尺寸
```

这项技术属于：

- Vue 弹窗状态管理
- Tauri IPC
- Rust 原生窗口管理
- GTK/WebKitGTK 子窗口控制
- WebView 生命周期管理
- 物理像素尺寸同步

所以之前只改 CSS 滚动条或 `z-index` 无法彻底解决。

## 十四、构建优化技术

当前 Release 构建启用了：

```text
-C opt-level=s
-C panic=abort
-C lto
-C codegen-units=1
-C strip=symbols
```

对应意义是：

| 参数 | 作用 |
|---|---|
| `opt-level=s` | 优先减小程序体积 |
| `lto` | 链接时优化 |
| `codegen-units=1` | 提高整体优化效果，但最后链接更慢 |
| `panic=abort` | panic 时直接终止，减少异常展开代码 |
| `strip=symbols` | 移除符号，缩小发布包 |

这也是刚才打包一直停在 `713/714` 的原因：最终主程序正在做单 codegen unit 的 LTO 链接，CPU 接近 100%，并不是卡死。

```text

```

