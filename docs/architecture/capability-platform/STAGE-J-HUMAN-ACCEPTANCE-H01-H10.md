## 二、本夜改动的**重点风险面**（请优先看这三项）

1. **H02 / H03 / H04 — Home**：`HomePanel` 及其 4 个子组件由 Shell 静态渲染改为
   **WORKBENCH_MAIN 贡献 + 懒加载**。这是本夜对成熟 UI 改动最大的一处；
   结构门禁只能证明"路径与归属正确"，**观感是否一致只能由人判断**。
2. **H05 — Vault**：`VaultPanel` 物理迁入 `capabilities/vault/ui`，并重命名了 4 个派生状态
   （`vaultCurrent/vaultResults/vaultEdges/vaultBacklinks`，仅内部改名，UI 语义不变）。
3. **H07 — 收藏目录**：workspace → home 的调用改为经 shared 缝；功能若失效会出现"点了没反应"。
