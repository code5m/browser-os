Browser Shell

当前版最稳定的产品语言是 Chrome 风格浏览器壳。内部模块与网页共享同一套 Tab / Omnibox / Bookmark 结构。
截图已验证
层级
Window → Tab Strip → Navigation + Omnibox → Bookmarks → Workspace → Status Bar
内部路由
browseros://home / browseros://agents / browseros://db / browseros://term 等
核心规则
网页与内部页签并存；本地路径和内部地址均从 Omnibox 进入；收藏栏长期可见。

当前视觉系统

当前版本不是单一主题，而是两种密度体系共存。

Light Utility Surface

Home / Files / Skills / Settings / Tasks / Clipboard / Scripts / Graph
近白背景、浅灰蓝边框、系统蓝主操作，偏表单 / 列表 / 卡片。

Dark Professional Surface

Agent / Database / Git / Terminal
深蓝黑背景、高密度、明显面板分隔和状态色，适合长时间开发工作。

Shared Browser Identity

跨两种 Surface 的共同层
Tabs、Omnibox、Bookmarks、内部路由、窗口和状态逻辑提供共同产品身份。

当前版已知问题

这里只记录 AS-IS，不在当前版设计里偷偷替换成 A+ 方案。
首页入口同级较多；浅色 / 深色专业工具存在视觉割裂；地址栏候选层级弱；Grid 与 Graph 空态引导不足；Settings 较长；Agent 控件密度较高；Database / Git 功能成熟但主次层级仍可统一。未来目标改版请单独查看 A+ 原型和 Comparison，不与本设计混写。
