# Monaco 独立预算审核

日期：2026-10-26。状态：独立预算已获用户明确批准；不构成全量门禁或 GUI 通过。

用户已明确选择保留 Monaco，并单独审核新增编辑器的依赖与体积预算。该选择不等于批准任意数值，也不授权修改历史基线来掩盖增长。

## 可重复取证

运行 `node scripts/report-coding-editor-budget.mjs`。脚本使用项目生产配置和正式构建相同的 `minify: terser`，在内存中构建，不覆盖 dist、不改阈值或基线。正式构建的 Vue scope 后处理也在内存中执行。

只有完整模块清单全部属于 Monaco、DOMPurify 或 marked 的 chunk 才算编辑器专属；混合和无法归属的资源全部保留在本体。CSS 要求所有引用者均为编辑器专属；Worker 必须与已审查完整模块归属的输出字节 SHA256 完全相同。文件名不用于推断 Worker 归属。

本次无 CSS 拆分的输出与现有 dist 逐文件核对：缺失 0，大小差异 0。总字节按未压缩生产文件计量，不是网络 gzip、安装包大小或运行内存。

增强核对：`node scripts/report-coding-editor-budget.mjs --verify-dist` 已对 111 个文件逐一验证 SHA256，并要求磁盘文件清单与构建输出完全一致，不接受仅大小相同或漏算复制资源。该参数不可与实验 CSS 拆分同时使用。脚本另检查入口静态 JS 图，不允许 Monaco 被意外拉入启动依赖；动态加载与全局 CSS 不因此被视为零成本。

## 后续批准边界

独立编辑器预算需明确覆盖全部 JS、Worker、语言模块、CSS、字体和间接依赖；同时保留本体、共享资源及总量报告，禁止以外置资源逃逸核算。预算数值、依赖冻结例外和相应门禁契约应一起评审，不能仅改断言得到绿色。

以上为批准前归因事实。用户随后明确批准：编辑器 ≤3.5 MiB（3,670,016 字节）、本体及共享 ≤1.35 MiB（向下取整为 1,415,577 字节）、总量 ≤4.75 MiB（4,980,736 字节）；只允许 Monaco 0.57.0 的依赖冻结例外，其 DOMPurify 固定 3.4.17。

机器契约为 `docs/engineering/coding-editor-budget.json`。正式门禁执行生产等价构建和磁盘完整清单/SHA256 校验，再分别检查三个上限；历史基线、45% 数值及旧对比结果保留，不宣称旧预算已通过。Rust warning 增长仍阻断。旧依赖冻结中的其他条目及新增依赖拒绝测试均不变。

Monaco 已保留；本记录不证明完整 VS Code 功能、安装版 GUI 或整个智能体目标完成。
