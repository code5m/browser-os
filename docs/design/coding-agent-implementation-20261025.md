# BrowserOS 编程工作区实现记录

日期：2026-10-25。状态：开发中，未安装验收。目标仍是可选模型、代码编辑、工具调用、技能/MCP/知识上下文及工作台协作，不以聊天框或静态原型替代。

## 当前接线

智能体贡献视图 `agents` → `AgentManagerPanel` 编码工作区；原蓝图入口保留。共享 `aiService` 提供已配置模型，密钥通过 Rust 从系统凭据库读取。Vue 只经 `bridge.codingService` 调用主窗口专用 `coding_service`；远程网页没有新增权限。

`coding.rs` 提供项目内目录、读取、搜索、持久化会话及有界模型工具循环。模型写入先形成提案，用户查看差异后才能应用。手动编辑保存同样经过原内容/哈希冲突检查。逐文件原子替换，应用前备份并记录映射；不是跨文件事务。Plan 模式在 Rust 侧移除并拒绝写工具。没有提供模型任意 Shell 执行。

编辑区使用 Monaco（MIT），支持语法着色、查找替换、多光标、折叠、撤销重做、差异比较及保存快捷键。它不是完整 VS Code；没有宣称已有扩展宿主、语言服务器、调试器或终端。编辑器及语言模块按需加载；其包体增量仍需纳入现有门禁，不能通过改阈值或改基线隐去。

`coding_context.rs` 提供技能发现/选读、项目 docs 文本检索和本地 stdio MCP。MCP 发现不会启动服务；每次连接或调用需用户明确批准。模型和服务器响应不能替用户授权。当前不支持远程 HTTP/OAuth、MCP resources/prompts；不能把插件清单导入视作插件执行完成。

模型工具已接入 `list_skills`、`read_skill`、`search_knowledge`、`list_mcp_servers`，所以不再仅限手动粘贴技能/知识上下文。模型不能调用 `mcp_call`；连接和执行仍通过 MCP 面板逐次批准。已实现会话/项目精确匹配的 `cancel`：取消后不再处理当前供应商回复中的写工具，保留已存在的待审核变更。当前请求不能立即中断，需等待其返回或最长约 45 秒超时，按钮明确说明这一边界。

## 2026-10-26 受控命令接入

编码工作区底部新增“受控命令”，经 script 的公开 `commandWorkbench` 适配器调用既有 run_command、script_status、cancel_script，未新增进程执行路径或原生命令。agent 将 script 声明为可选依赖；脚本能力未 ACTIVE 时拒绝列表和新运行。运行加入 script 生命周期跟踪，已有运行仍可查询/取消；离开面板时请求取消。

只能选择已保存且启用的命令片段，不允许智能体传任意 Shell。参数变化、刷新配置或开始运行后撤销本次批准。危险命令显示警示，执行目录沿用已有片段配置，不假装自动使用当前项目目录。输出默认不发模型，用户可明确加入下一条消息的上下文。现有原生运行契约没有命令版本令牌，预览与真正执行之间对并发修改的强一致性尚未提供。

真实 Vue 面板及 script 公开适配器回归通过，原生传输明确为模拟；覆盖停用拒绝、逐次批准、参数修改撤销、轮询、取消、显式上下文和卸载清理。既有 Rust 执行器实际 21/21 测试通过，包含真实命令、进程组取消/后代清理及超时。此结果不代替安装版桌面或智能体自主操作闭环验证。

## 2026-10-26 审批与续跑链路

Build 模式新增模型工具 `request_operation`，只记录请求，不执行。Plan 模式不提供该工具。原生校验允许 command（既有片段 ID 与参数）、mcp（已发现服务 ID、工具名、参数）以及三个只读上下文请求；不接受模型传批准标志、任意 Shell、原始 MCP 启动命令或额外字段。会话存在待审批项时禁止继续聊天，操作清单随会话持久化。

界面明确展示请求和目标，批准一次才执行。MCP 执行按钮为单次消耗，结果记录失败不会自动重跑外部操作；MCP `isError` 不能标为成功。用户检查结果后单独记录，Rust 拒绝重复记录、错误状态和敏感结果。记录只追加为带“不可信数据”边界的会话消息；用户再点击“根据审批结果继续”才请求模型。拒绝也可记录并继续，不能由模型直接调用结果记录接口。

命令复用 `CodingCommandPanel` 和 script 公开适配器，预填提议但批准默认关闭。可手动分享可用片段目录，目录不含凭据、参数默认值或 Shell 正文。仍不支持模型创建任意命令、自动切项目目录或无限自动执行。

跨模块第一轮为只读：git_context 经 Git 公开接口读取当前项目状态；database_context 经 Database owner 读取当前已加载表/视图名称（不查询、不连库）；browser_context 经 Browser owner 读取标签元数据，移除 URL 用户信息、查询和片段。三个能力必须 ACTIVE。新增可选依赖同时声明于 Manifest 和治理注册表，不直引其他模块内部状态路径。

实际验证：原生运行时 12/12 回归通过；真实 Vue/Monaco 模拟传输的审批→执行→记录→续跑流程通过；专用组件验证错误/拒绝/单次执行通过；真实 Pinia owner 与公开适配器验证能力守卫、Git 调用、数据库不查询、浏览器 URL 脱敏通过。Git/MCP 传输为测试夹具，不能扩大成安装版或真实外部工作台已验收。
