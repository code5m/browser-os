Accessibility (A6/A8, R3B-04 closure)

Every interactive element has role, aria-label, keyboard focus (:focus-visible), and disabled state with reason (aria-disabled + title).

Menu navigation: ↑/↓ move, Enter execute, Esc close + return focus to origin. Tab order follows DOM.

ARIA roles used: toolbar, tablist/tab, search, main, menu/menuitem, dialog, tree/treeitem, status, button.

Frozen Shortcuts (A0 ruling, R3B-06 closure)

Ctrl+K → browser.focusAddressSearch (address/search field)

Ctrl+Shift+P → app.openCommandPalette (command palette)

No other command may claim either chord. All shortcuts unique (A6 audit PASS).

Collapse/Restore Semantics (A0 ruling, A3/A4 aligned)

Collapse All: hides every tool window including pinned. Records one restorable snapshot.

Restore Layout: restores visibility, dimensions, pin states from snapshot. Deterministic.

Pin: affects ordinary replacement and auto-hide only. Pinned windows still hide on Collapse All.

Transient hover/overlay state is NOT persisted (A4). Snapshot lifecycle: create on collapse, consume on restore, GC on close.

Geometry SSOT (A0 ruling, A2 measured)

Top chrome = 60px (2×30). Status = 24px. Strip = 28px. These are hard constants.

Collapsed active H = (innerH − 60 − 24) / innerH. Collapsed active W = (W − 28) / W.

900×600 is the tightest: 86.00% H (余量 1.00pp). Any +1px to 60/24/28 breaks it first.

Current baseline measures 63px top / 26px status (A2 §5). R3B prototype encodes A0 constants exactly.
