- `src-tauri/src/mcp.rs:15-16` — `use crate::domain::*; use crate::security_policy::{check_path_within_roots, redact_sensitive_url};`：同样无 Tauri 类型。

## 3. 给 A3 W11 加固的边界守护清单（防回退）

A3 在 W11 将加固 `deterministic JSON-RPC errors / bounded input·response size / stable tools/list / explicit fail-closed tools/call`，本审查要求**不得**为以下任一而破坏 §1 四条边界：

1. 边界尺寸上限（输入/响应）必须仅用 `serde_json` + `std::io` 在 `mcp_server.rs` 内实现，**不得**为"序列化/截断"引入 `tauri::` 或 `bridge::*`。
2. `tools/list` 稳定 schema 须继续以 `list_registry_entries()` 为单一真源（`mcp_server.rs:82-105`），**不得**改从 `bridge` 取能力。
3. 任何新加的 `mcp_tools/**` 或辅助模块必须置于 `#[cfg(feature = "mcp")]` 之下，且**不得**反向 `use crate::bridge` 或 `use tauri::..`。
4. fail-closed 覆盖必须继续**不调用** `script_runner` / `database` / 插件执行；新增未绑定能力一律 `isError=true`。
5. 若 W11 需要新增只读视角函数，仍只许落在 `crate::mcp`（→ `domain` / `security_policy`），**不得**把执行/写能力搬到 stdio 侧。
6. 默认构建（`cargo build` / `cargo test` 无 `--features mcp`）行为必须保持不变：`mcp_server` 模块与 `run_stdio` 调用均受 cfg 门控，不得泄漏进 default 编译单元。
