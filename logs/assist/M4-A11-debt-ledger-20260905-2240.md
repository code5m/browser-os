## 2. M4 新增债务的登记规则

1. 编号从 **D27** 起顺序分配。lane 在自身检查点里声明后，把「简述 / 来源检查点 / 关闭条件」发给 A0，由 A11 登记进本台账。
2. 每条新债务必须带**关闭验证命令**（对应命令矩阵里的 T0/T1/T2 编号），否则不登记。
3. 「有意设计、不关闭」的项单独标注 `DESIGN LIMITATION`，不占用 D 编号（沿用 M1-ACCEPT §7 分类：`BLOCKER` / `NON-BLOCKER` / `DESIGN LIMITATION` / `DEFERRED`）。
4. M4 里程碑裁定前，A11 复跑本台账：已关闭项标注关闭 SHA 与验证输出；未关闭项保持挂账并说明是否阻塞 M4。
