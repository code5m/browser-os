## 4. A10 落地后复核清单（G1–G11，A7/A8 代码落库后二次裁决用）

> 触发：当工作树出现 `graph.rs`/`bridge.rs`/`domain.rs`/`main.rs`/`default-commands.toml`/`bridge.ts`/`types.ts`/`check-graph-policy.py` 的 W12 diff 时，A10 重跑以下 11 项。

- **G1（HIGH）props 泄露**：3 命令**只**返回 `GraphNodeView`/`GraphEdgeView`（无 `props`）；严禁返回 `GraphNode`/`GraphEdge`。`bridge.ts` `graphQuery` 返回类型须为 `GraphQueryResult{nodes:GraphNodeView[]}`。验证：`serde_json::to_string(&r)` 不含 `"props"`（卡片 §8.1 已有断言）。
- **G2（MED）Display vs code**：命令 `Err` 只返回 `GraphError::code()`（ASCII），绝不 `e.to_string()` / `format!("{}", e)`（中文 Display 串）。grep 3 命令体确认无 `to_string()` on GraphError。
- **G3（LOW）快照路径安全**：`load_snapshot` 路径固定 `<data_dir>/graph.json`，**不得**由任何请求字段派生（防遍历）；任何错误回退空 store、不 panic、不把文件内容/secret 写入日志。
- **G4（MED）审计/日志不泄露查询参**：3 命令不写含 props/secret 的审计；`check_invocation_source` 及命令日志**不得**原样打印 `start_id`（节点 id 可能是文件路径/agent id）。
- **G5（HIGH）GRAPH_NO_SECOND_PATH**：`graph.rs` diff 中**不得**出现 `use crate::bridge` / `crate::bridge::`；命令定义在 `bridge.rs` 调 `crate::graph::*` pure helper（卡片 §3 裁定）。与 A2 边界复审一致。
- **G6（HIGH）零 tokio/rmcp/网络/第二执行路径**：`graph.rs` + `bridge.rs` 的 3 命令 grep `tokio|rmcp|std::process|Command::new|TcpListener|reqwest|std::net` 须为空。
- **G7（MED）ACL 位置**：3 命令插入 `list_artifact_images` **之前**；ACL 末条仍恒为 `list_artifact_images`（不得追加其后）。
- **G8（HIGH, 跨 A3）MCP 不暴露**：`mcp_server.rs`/`mcp.rs` 不得把 `graph_query`/`graph_node_get`/`graph_stats` 枚举为 tool。归 A3 W12 复审，A10 标注依赖。
- **G9（MED, 跨 A5）Agent/Skill 锁**：`graph_node_get` 返回 Skill/Agent **View**（仅 id/kind/label），无 `agent_kv` 值、无执行；UI 不暗示 agent runtime。归 A5 复审。
- **G10（MED, 跨 A11）构建指标/告警**：A7 引新 Rust 字节 + `GRAPH_OUTPUT_NO_PROPS` 码后，`measure-build-metrics.py` 须 ≤22%、`cargo` warning 不增。归 A11 重测。
- **G11（MED）source check 同源**：3 命令**全部** `check_invocation_source`，无一豁免；`request_id` 仅作前端取消 key，不参与后端逻辑/不 echo。
