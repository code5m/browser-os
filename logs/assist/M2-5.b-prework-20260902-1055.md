## 1. 目标

产出「脚本库」面板的前端草案，覆盖 4 个视图状态：

1. **列表态**：分类树 + 脚本卡片/表格 + 搜索。
2. **参数弹窗态**：按 `ParamType` 渲染不同控件 + 必填校验 + 危险输入的前端预提示。
3. **运行态**：实时输出流（模拟）、进度/计时、取消按钮、超时提示。
4. **历史态**：运行记录列表、状态筛选、展开查看输出尾部。

**非目标**：不调 `run_script`、不启动任何进程、不读写磁盘脚本库、不改 `bridge.rs`。

### 2.1 关键约束

- **零新 UI 依赖**：不得引入 Naive UI / Element Plus / xterm（xterm 已装但仅终端用）。表格、树、抽屉全部手写，沿用 `FileTreeNode.vue` / `AuditPanel.vue` 的样式。

### 4.1 `ScriptPanel.vue`

```ts
interface Props {

// 列表项：名称 / 分类 tag / 描述 / 参数个数 / 最近运行状态点 / [运行] [编辑] [删除]
// builtin 脚本的 [删除] 禁用（与 M2-3.a 的 builtin: bool 对齐）
```

### 4.2 `ScriptRunModal.vue`（参数弹窗 + 运行态）

```ts
interface Props {
  script: ScriptMetaLike | null;      // null → 关闭
  onSubmit: (values: Record<string, string | number | boolean>) => void;
  onCancel: () => void;
  onClose: () => void;
  // 运行态由外部 store 注入，组件自身不执行任何东西
  run?: { runId: string; status: RunStatusLike; output: string;
          elapsedMs: number; error?: string } | null;
  onCancelRun?: (runId: string) => void;
}
```

**参数控件映射**（严格按 `ParamType`）：

| ParamType | 控件 | 校验 |
|---|---|---|
| `String` | `<input type="text">` | 必填 + 长度 ≤ 4096 + **危险字符前端预检**（见下） |
| `Int` | `<input type="number">` | 必填 + 整数范围校验 |
| `Bool` | `<input type="checkbox">` | 无 |
| `Enum` | `<select>`，选项来自 `options` | 值必须在 options 内 |
| `Path` | 文本框 + 「选择」按钮（后续接 `browse_workspace`） | 必填 + 禁止 `..` + 需在授权根内 |

**危险字符前端预检**（与 M2-3.a §4.3 同源，前端**只提示不拦截**——拦截必须在后端）：

命中 `; & | \` $ ( ) < > * ? \n` 等字符时，输入框下方显示黄色提示「该值含特殊字符，后端将拒绝执行」。
> 原则：**前端提示 ≠ 安全边界**。真正的 fail-closed 在 `run_script` 内。

### 4.3 运行态状态机（前端视角）

```
idle ──提交──> running ──> succeeded | failed | cancelled | timeout
                  │
                  └──点击取消──> cancelling ──> cancelled
```

| 状态 | UI 表现 |
|---|---|
| `running` | 输出区滚动追加（rAF 合并）、右上角计时 mm:ss、按钮变「取消」、提交按钮禁用 |
| `succeeded` | 绿色徽章 + 退出码 0 + 耗时；可「再次运行」「复制输出」 |
| `failed` | 红色徽章 + 退出码非 0 + error 文案；输出区保留 |
| `cancelled` | 灰色徽章「已取消」；输出区保留已产生部分 |
| `timeout` | 橙色徽章「超时（N s）」；提示调大 `timeout_secs` |

**输出区硬约束**：最多渲染 **2000 行 / 256 KB**（与后端 `output_tail` 上限对齐），超出显示「输出已截断，仅显示最后部分」。
