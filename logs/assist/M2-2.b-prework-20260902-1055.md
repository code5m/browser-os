## 1. 目标

产出一套**可独立运行、不依赖后端命令**的图片预览 UI 草案，覆盖 5 个必测视图状态：

1. 画廊网格（多图缩略图）
2. 灯箱（点击放大、左右切换、ESC 关闭）
3. 缩放（滚轮 / 按钮 / 双击复位）
4. 错误态（图片加载失败、文件缺失、MIME 不支持）
5. 空态（无图片 / 加载中骨架屏）

**非目标**：不调任何 Tauri 命令、不读真实磁盘、不改 `assetProtocol`、不改 `bridge.rs`。

### 2.1 关键约束

- **零 UI 组件库依赖**：新增组件必须用现有 `.vue` + scoped CSS 手写，不得引入 photo-swipe / viewerjs（会直接顶爆 505 KB 主 chunk 基线）。
- **`renderMd` 不解析图片**：`markdown.ts` 的 `inline()` 只处理粗体/斜体/行内代码/链接（`src/utils/markdown.ts:1` 注释已明示）。图片只会以原始 `<img src="dataURL">` 出现在 `Artifact.html` 中被 `v-html` 渲染。→ **灯箱必须能接管已存在的 `<img>` 点击**，不能只支持组件内数组渲染。

## 4. 接口 / 数据契约（组件 props）

### 4.1 `ImageGallery.vue`

```ts
interface Props {
  images: ImageRefLike[];        // 空数组 → 空态
  loading?: boolean;             // true → 骨架屏
  columns?: number;              // 默认 4，响应式可选 'auto'
  onOpen?: (index: number) => void;
}
// 内部状态
// thumbFailed: Set<string>  → 单图错误占位，不整体失败
// selectedIndex: number | null
```

### 4.2 `ImageLightbox.vue`

```ts
interface Props {
  images: ImageRefLike[];
  index: number;                 // 当前索引
  open: boolean;
  onClose: () => void;
  onIndexChange?: (i: number) => void;
}
// 交互契约
// - ESC / 点击遮罩 → onClose
// - ← →  切换；首页按 ← 停在首页（不循环，避免"绕回去"误操作）
// - 滚轮 + 按钮缩放：scale ∈ [0.1, 8]，步长 1.2 倍
// - 双击 → scale === 1 ? 2 : 1（复位）
// - 拖拽平移：仅 scale > 1 时启用
// - 单图加载失败 → 显示错误占位 + 重试按钮，**不关闭灯箱**
```

### 4.3 mock 数据形状（不依赖后端）

```ts
// src/mocks/imageFixture.ts
export interface ImageRefLike {
  id: string; source: "file" | "inline_data_url";
  rel_path: string | null; mime: string; bytes: number;
  width: number | null; height: number | null;
  sha256: string; source_url: string | null;
  caption: string | null; created_at: string;
  /** mock 专用：真实接入后删除 */
  _mock?: { src: string; kind: "ok" | "broken" | "empty" | "huge" | "unsupported" };
}
```

### 4.4 五个视图状态判定表

| 状态 | 触发条件 | 视觉 |
|---|---|---|
| 加载中 | `loading === true` | N 个灰色骨架块，带脉冲动画 |
| 空态 | `images.length === 0 && !loading` | 居中图标 + "暂无图片" + 说明文案 |
| 正常 | 有图且加载成功 | 网格缩略图，`object-fit: cover`，hover 显示标题 |
| 单图错误 | 该图 `error` 事件触发 | 该格显示破损图标 + "加载失败" + 重试按钮；**其余格不受影响** |
| 全部错误 | 所有图均失败 | 网格上方一条汇总提示 + 每格各自错误态（不做整体替换） |
