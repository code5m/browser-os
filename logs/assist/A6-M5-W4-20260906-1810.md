### 3.4 流式载荷（4 个 Tauri event，非单事件 kind）

> 域权威（`M5-4` §4.3）：通道 = `app.emit("agent://<agent_id>/stream", payload)`；**终止**为三个独立事件 `.../done` / `.../error` / `.../canceled`。Skill 类比 `skill://<run_id>/stream`（A5 M5-4 §4.3 覆盖，A16 落码时定 topic）。
> 纠正 W3 `StreamChunk.kind:"exit"` 模型：终止由 3 个独立事件携带，前端分别订阅。

```ts
export type StreamChunk =
  | { kind: "data"; runId?: string; sessionId?: string; data: string }
  | { kind: "flow"; runId?: string; sessionId?: string; droppedChunks?: number; droppedBytes?: number };
// 终止事件（独立订阅）：
//   agent://<agent_id>/done    -> { result }
//   agent://<agent_id>/error   -> { code, message }
//   agent://<agent_id>/canceled-> {}
//   skill://<run_id>/done|/error|/canceled 同构
```

> 前端 `bridge.ts` 收 event → `useAgentStore` 累积。**纠正 A5 M5-4 §4.3「转 useAIStore.addStream」**：`useAIStore.ts` 不存在（F4），UI store 为 `useAgentStore.ts`（W3 R-A6-10 已定，A5 卡措辞作废）。

### 4.2 三面板状态机

| 面板 | 状态流转 |
|---|---|
| **ChatPanel**（`agent_chat` 流式渲染） | `idle` →（用户发消息 `runAgent`）→ `streaming`（`agent://<id>/stream` 事件 append `chunks`）→ 收到 `.../done` → `done`；收到 `.../error` → `error`；收到 `.../canceled` 或用户点取消 `cancelRun` → `canceled` → 回到 `idle`/`ended`。自动滚动仅当用户在底部；向上滚时不跳底（A1 M5-6 §4.2）。 |
| **SkillManager / AgentManager** | `list` →（点详情 `selectSkill/selectAgent`）→ `detail` →（点安装 `installSkill/installAgent`）→ 后端 `CONFIRM_REQUIRED` → 置 `pendingConfirms[requestId]` → **PermissionPreviewModal** `showing` → 用户 `approve`（`ackConfirm`）→ `installing`（loading.install） → 成功刷新 `skillInstalls`/`agentInstalls` 缓存 → `installed`；`deny` → 关闭无执行。 |
| **PermissionPreviewModal**（A1 M5-6 §4.1） | `closed` → `showing(confirm payload：名称+版本+ACL+capabilities 逐项+目标操作+风险提示)` → `approve`（调 `confirm_<action>`）/ `deny`（=拒绝，无「延后」）→ `closed`。`Dangerous` 必显 keyring 二次认证按钮。 |

### 4.4 边界（W4 红线：有界 + 隐私）

- **隐私**：`SkillExec.params` 中的 `password` 值**只存组件本地 `ref`**，不进 `useAgentStore`、不进 `SkillInstallState`、不写 `localStorage`、不进审计；`serializeSkillForm` 输出时 `password` → `"***"`（策略脚本 `AGENTSKILLUI_PASSWORD_IN_STORE` 守护）。`system_prompt` 域保证不含凭据，UI 可持；但不得回显到审计。
- **有界**：`sessions[sessionId].chunks` 单会话 UI buffer 上限（建议 ≤64KB，超出截断并标 `truncated`）；运行历史来自后端 `skill-runs.json`/`agent-runs.json`（各自 500 上限 FIFO），前端不另存全量。
- **桥接**：所有写操作经 `bridge.ts` 包装（A1 M5-6 FORBID：禁裸 `invoke`）；`pendingConfirms` 过期（`expiresAt`）自动清理，防止闸门卡死。
