### The single blocker (false positive, but a hard gate)

`src-tauri/src/plugin.rs:428` inside `filter_by_state` (doc comment: `None` = all):

```rust
.filter(|r| state.map(|s| r.state == s).unwrap_or(true))
```

`Option<bool>::unwrap_or(true)` here means "no state filter", **not** a signature bypass — it is a conservative-regex false positive (`PLUGIN_SIG_BYPASS` matches `todo!|unimplemented!|panic!|\.unwrap_or\(true\)`). It still fails pre-merge, so it must be resolved.

**Minimal fix (recommended, zero behavior change):**

```rust
.filter(|r| state.map_or(true, |s| r.state == s))
```

**Do not** narrow the fixture regex — that weakens the real bypass gate. If A9 keeps `unwrap_or(true)`, A0 must explicitly waive it and sync `BAD_SAMPLES`.
