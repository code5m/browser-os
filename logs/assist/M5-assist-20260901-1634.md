- SQL 风险分类 + 结果截断（`EXECUTE_QUERY_LIMIT=50`）；fail-closed。
- 工具集：#1 脚本 / #4 命令 / #5 git / #6 数据库 / #8 浏览器 / #11 定时任务。

## 5. 统一安全红线（贯穿 M5）

1. 所有 runtime/工具/MCP/Agent/Skill/插件复用同一安全策略（McpGlobalPolicy）。
2. 未声明、未确认或策略不确定 → fail-closed。
3. 任何执行/出网/落盘 → `audit.json` + 确认闸门 + `KeyringStore`，绝不开旁路。
4. 恶意/损坏 Skill 与插件、超大输出、无限工具循环、连接中断、卸载残留均有测试与预算上限。
