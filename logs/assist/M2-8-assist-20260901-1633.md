## 1. 协议加载（草案）

- 内置工具：`asset:` 协议（Tauri 2 的 `asset` 协议或自定义 `Assets`）+ `include_dir!` 嵌入，
  加载 `asset://localhost/tools/<file>.html`。
- 用户工具：`file://` 加载 `workspace/tools/<file>.html`（运行期读盘，M2-7-assist §4）。
- **不**走 `http(s)://` 远程；工具纯离线（§4.3 红线）。

---

## 2. 权限最小化（草案）

| 维度 | 策略 |
|------|------|
| IPC 能力 | 工具 webview 的 `webviews:["tool-*"]` 仅授予 `core:default` + 必要 `tool:*` 权限；
  **不**授予 `shell`/`fs`/主窗口 bridge 命令（防工具调 `run_script` 越权） |
| 网络 | CSP `default-src 'self' 'unsafe-inline'; connect-src 'none'; img-src data:`；
  禁 `fetch(http(s)://)`（M2-9 验收核） |
| 文件 | 仅能读自身 `asset://` 包内资源；用户工具限 `workspace/tools/` 目录 |
| DOM 隔离 | 子 webview 不共享主窗口 `localStorage`/`IndexedDB`（隔离源） |
| 脚本 | SVG/HTML 内 `<script src=外部>` 拒加载（M2-1 R1 / M2-9 核） |

---

## 3. 错误页（草案）

- 工具加载失败（文件缺失/解析错/CSP 违例）→ 渲染内置 `error-tool.html`（离线占位）：
  「工具无法加载：<reason>」，不白屏、不泄露内部路径。
- CSP 违例经 `webview.on_page_load` 或 `onWebviewError` 捕获 → 记 `audit.json`（不记敏感）。
- 用户工具恶意内容（尝试 `fetch` 外部）→ 加载即拦截，错误页提示「该工具尝试外部联网，已阻止」。

---

## 4. 生命周期（草案，复用 M0-2）

- 工具 webview 随「工具箱」面板关闭而 `destroy`（同 `CloseTab` 的 kill 范式）。
- 应用退出：`coordinator.register("destroy-tools", ...)` 遍历 `tool-*` webview `destroy()`，
  无残留（同 M2-4/M1-9 退出收口）。
- 热重载：用户丢新 HTML 进 `workspace/tools/` → `list_tools` 重扫即显，无需重启。

## 5. 风险点

| # | 风险 | 缓解 |
|---|------|------|
| R1 | 工具越权调 bridge | `tool-*` webview 权限最小化，不授 shell/fs/主命令 |
| R2 | 用户工具外部联网 | CSP `connect-src 'none'` + 加载期拦截 |
| R3 | SVG/HTML 脚本执行 | M2-1 R1 落盘拒带 script 的 svg；运行时 CSP 兜底 |
| R4 | 路径逃逸 | 用户工具限 `workspace/tools/`；`canonicalize` 校验 |
| R5 | 退出残留 | `destroy-tools` 注册进 ShutdownCoordinator |

---

## 6. 验收标准（草案）

| 能力 | 标准 |
|------|------|
| 隔离 | 工具 webview 无法调 `run_script`/读 `app_data_dir` 外文件 |
| 离线 | 5 内置工具 release 包内可开；无外部请求 |
| 错误页 | 加载失败有占位 + 原因；不白屏 |
| 生命周期 | 关面板/退出无 webview 残留 |
| CSP | `fetch(http)` 被阻；违例有审计 |
