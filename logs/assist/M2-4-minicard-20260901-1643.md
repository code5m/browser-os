# M2-4 强模型最小输入卡（≤80 行）

> 来源：M2-4-assist-20260901-1632.md。仅给 AI:DEEP/R:high，本卡不实现、不签 PASS。

## 目标
安全脚本执行通道 `run_script`：参数注入防护 + 取消/超时 + 进程树回收 + 输出背压；复用 `request_sync` 后台线程范式，前端订阅 `script-output`。

## 必改文件
- `src-tauri/src/bridge.rs`：新增 `run_script(app, meta, args)->Channel<LogLine>`；`coordinator.register("kill-script-<id>")`；`script-cancel` 命令。
- `src-tauri/src/domain.rs`：复用 `ScriptMeta`/`ScriptArg`（来自 M2-3-assist §3）/`LogLine{ts,stream,line}`。
- `security_policy.rs`：新增 `SCRIPT_OUTPUT_MAX_BYTES=4MB` 背压上限。
- `src/components/system/RunConsole.vue`：订阅 `script-output`，显示 `truncated` 标记。

## 禁止事项
- 绝不 `sh -c "..."` 拼接（RCE 红线）；用 `Command::new(interp).args([script, ...resolved])`。
- 不信任用户输入的解释器路径（锁定 `sh/bash/python3/node` 白名单）。
- 不在 `data_dir/scripts/<id>` 外执行（`canonicalize` 防 `..` 逃逸）。
- 不新建审计结构（复用 `workspace::log_audit`）。
- 不移动 `NEXT`。

## 实现要点
1. 注入防护：arg 值作独立 `argc` 参数（或 `shell_escape`），未声明占位不替换（M2-3 §3）。
2. 取消：`script-cancel(id)` → `child.kill()`+`wait()`，复用 M0-2。超时：`recv_timeout`/watchdog 线程，超时 `kill`+stderr "timeout"。
3. 进程树：`Command::new(...).process_group(0)` + `SIGKILL` 到进程组（Unix），防孙进程 orphan；复用 `TerminalSession` kill 范式。
4. 背压：首期单条 emit 无背压 → 硬上限 `SCRIPT_OUTPUT_MAX_BYTES`，超截断标 `truncated`；升级期（M3-1 后）改 `mpsc(128)+pump task`。
5. 写操作经 `confirm_sync` 闸门（dangerous 二次确认）。

## 反向用例
- T-ex-2 `DIR="/etc; rm -rf /"` → 值作独立参数，不执行 `rm`。
- T-ex-3 `sleep 100` timeout=2 → 2s killed + stderr "timeout"。
- T-ex-4 脚本 spawn 孙进程后 cancel → `ps` 验证进程组全回收。
- T-ex-5 输出 10MB → 截断至 4MB + `truncated=true`。
- T-ex-6 未声明 `${EVIL}` → 不替换。

## 失败动作
- orphan 残留 → 确认 `process_group(0)`+进程组 kill，复测 T-ex-4。
- 大输出冲垮前端 → 调 `SCRIPT_OUTPUT_MAX_BYTES` 或提前上 mpsc。
- 注入绕过 → 退 `sh -c` 拼接，改独立 `argc` 后复测 T-ex-2。
