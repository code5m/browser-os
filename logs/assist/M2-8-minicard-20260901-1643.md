# M2-8 强模型最小输入卡（≤80 行）

> 来源：M2-8-assist-20260901-1633.md。仅给 AI:DEEP/R:high，本卡不实现、不签 PASS。

## 目标
本地工具以隔离 WebView 运行：内置工具走 `asset:` 协议、用户工具走 `file://`；权限最小化 + CSP + 错误页 + 生命周期接入 ShutdownCoordinator。纯离线（§4.3 红线）。

## 必改文件
- `src-tauri/build.rs`：`include_dir!` 嵌入 `src/tools/`（待 M2-7 建目录，详见偏差）。
- `src-tauri/src/bridge.rs`：新增 `spawn_tool_window`（复用 `spawn_child_window` WebviewBuilder）；`coordinator.register("destroy-tools", ...)`。
- `src-tauri/capabilities/tools.json`：新增 `webviews:["tool-*"]` 权限最小化（仿 `browser-remote.json`）。
- `src/components/apps/`：工具箱面板 + 错误页 `error-tool.html`。

## 禁止事项
- 不授 `tool-*` webview `shell`/`fs`/主窗口 bridge 命令（防越权调 `run_script`）。
- 不联网：`connect-src 'none'`，禁 `fetch(http(s)://)`。
- 不走 `http(s)://` 远程加载工具。
- 不改 `tauri.conf.json`/`build.rs` 既有结构（仅增 include_dir）。
- 不移动 `NEXT`。

## 实现要点
1. 协议：内置 `asset://localhost/tools/<f>.html`（include_dir）；用户 `file://workspace/tools/<f>.html`。
2. 权限：`tool-*` 仅 `core:default`+必要 `tool:*`；不共享主窗 `localStorage`/`IndexedDB`（隔离源）；SVG/HTML 外部 `<script src>` 拒加载。
3. CSP：`default-src 'self' 'unsafe-inline'; connect-src 'none'; img-src data:`；违例经 `onWebviewError` 记 `audit.json`（不记敏感）。
4. 错误页：加载失败/CSP 违例/尝试外联 → 渲染 `error-tool.html`（原因提示，不白屏、不泄露路径）。
5. 生命周期：随工具箱面板关闭 `destroy`；退出 `destroy-tools` 遍历 `tool-*` 无残留。

## 验收命令
```
cargo build --release
npm run build
bash scripts/pre-merge.sh                   # ALL_PASS
# 手动：5 内置工具 release 包内可开；工具内 fetch(http) 被阻；关面板/退出无 webview 残留
```

## 反向用例
- 工具调 `run_script`/读 `app_data_dir` 外文件 → 权限拒绝（R1）。
- 用户工具 `fetch(http)` → 加载即拦截 + 错误页（R2）。
- 恶意 SVG/HTML `<script src=外部>` → CSP 兜底拒加载（R3）。
- `workspace/tools/` 外路径 → `canonicalize` 校验失败（R4）。

## 失败动作
- 权限泄漏 → 复核 `tools.json` 未授 shell/fs，复测 R1。
- 外联未阻 → CSP `connect-src 'none'` 校验，复测 R2。
- 退出残留 → 确认 `destroy-tools` 注册进 ShutdownCoordinator，复测生命周期。
> 偏差：§4.3 称 `src/tools/` 已落位，实际目录不存在（见 M2-7-assist）。强模型须先建目录再 include_dir。
