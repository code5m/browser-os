## 2. 当前基线评审（graph.rs，命令未落地）

### 2.1 `props` 处理
- `GraphNode`/`GraphEdge` 含 `props: GraphProps`；`GraphStore::to_json` 序列化全量含 props——但**仅用于 store 持久化/导出**，不进入任何命令响应。
- 插入时 `validate_props` 经 `graph_props_contain_secret` **双扫**（字段名黑名单 `token/password/secret/api_key` + 值模式 `sk-/AKIA/Bearer /eyJ/-----BEGIN`，AGRAPH-9）拒绝凭据，故 at-rest props 无机密。
- **当前无 graph 命令**，props 不外流到响应；W12 命令将经 `GraphNodeView`/`GraphEdgeView` 丢弃 props（A7 §3）。
- 结论：基线 props 不外流（持久化路径有双扫守门）；W12 输出删 props 由 A7 实施 + `GRAPH_OUTPUT_NO_PROPS` 守门。

### 2.2 错误回显（当前 `Display` 的隐患）
`GraphError::Display`（graph.rs:43-73）：
- **固定文案、不回显**：`SecretInProps` / `LabelTooLong` / `PropCountExceeded` / `Node/EdgeCapacityExceeded` / `EmptyId` / `IdTooLong` / `RefIdNotHex`。
- **会回显标识符/键**（graph.rs:55-58, 69-71）：
  - `PropKeyTooLong(k)` / `PropValueTooLong(k)` → 回显 **prop key**（如 `"api_key"`），非值；轻微 info-leak。
  - `DuplicateNode(id)` / `DuplicateEdge(k)` → 回显 node id / edge key（如 `"file:/a"`、64-hex），非机密。
  - `Serde(m)` → 回显 **serde 错误消息 `m`**，可能含被序列化数据片段（path/URL/值）——**真实回显向量**。
- **关键结论**：以上隐患仅在错误被“对外暴露”时成立。A7 W12 计划 §3.4 新增 `GraphError::code()`（稳定 ASCII 码），命令统一 `return Err(e.code().to_string())`——**只回稳定码，绝不用 `Display` 中文串、不回显 props/label/query body**。因此 W12 落地后，`Display` 回显隐患被 `code()` 路径消解。

### 2.3 审计（当前 + W12）
- 当前 `graph.rs` **0 处 `log_audit`**；`bridge.rs` 现有 `log_audit` 均为 task/session 等（grep 证实无 graph 命令审计）。
- A7 计划 §6：3 命令**不写**任何含 props/secret 的审计；`check_invocation_source` 已挡远程 webview。
- 结论：基线无审计泄漏；W12 由设计保证（命令不写 props 审计）。**建议**：落地后复核若 graph 命令新增 `log_audit`，其 detail 仅含 id/count/code，不得含 `props`/`label`/`query`/`body`。

## 4. 具体建议（concrete，非阻塞；交 A7/A10 实施）

- **R1（error-encoding / 审计机器守门缺口）**：A7 计划 §7.6 的 `GRAPH_OUTPUT_NO_PROPS` 仅守“输出 DTO 删 props”，**未覆盖要件②的错误编码路径与要件③的审计**。建议 A7 在其 `check-graph-policy.py` 同包内增补 `GRAPH_ERROR_STABLE_CODES`（或并入）：在 `bridge.rs` 的 `graph_*` 命令函数体内，断言（a）所有 `Err(GraphError::...)` 臂使用 `.code().to_string()` 而非 `to_string()`/`Display` 透传；（b）`graph_*` 命令内 `log_audit` detail 不含 `{props}`/`{label}`/`{query}`/`{body}`。此缺口当前**非 blocker**（A7 设计已满足），但缺机器守门，建议补强。
- **R2（当前 `Display` 残留）**：`graph.rs` `Display` 仍回显 key/serde msg；只要命令不走 `Display` 即安全。建议 A7 落地时显式确认命令错误一律经 `code()`（A4 落地后复核会验证）。
- **R3（持久化 `to_json`）**：`GraphStore::to_json` 序列化含 props，用于 store 落地；因插入已双扫拒密，at-rest 无机密；但 `from_json/to_json` 的 `Serde` 错误若外抛需经 `code()`。建议保持 `to_json` 仅用于持久化，不进入命令响应。
