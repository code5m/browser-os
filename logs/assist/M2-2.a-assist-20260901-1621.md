## 1. 组件拆分建议

```
ArtifactImagePreview（新增，挂 Artifact 详情视图）
├── GalleryGrid     : 多图网格缩略（复用 M1-9 资源预览契约）
├── Lightbox        : 点击放大，遮罩层，左右切换
│   ├── ZoomControl : 缩放（25%~400%），滚轮/按钮
│   ├── CaptionBar  : ImageRef.caption 展示
│   └── MetaBar     : mime / size_bytes / 尺寸（width×height）
└── ThumbStrip      : 底部缩略条快速定位
```

store 扩展（`useWorkspaceStore.ts` 或新建 `useArtifactStore`）：
```typescript
const currentImages = ref<ImageRef[]>([]);
const lightboxIndex = ref<number>(-1);  // -1 = 关闭
```

## 2. 状态模型

| 状态 | 触发 | UI |
|------|------|-----|
| empty | `currentImages.length === 0` | 显示「暂无图片」 |
| grid | 默认 | GalleryGrid 网格 |
| lightbox-open | 点缩略图 | Lightbox 遮罩 + ZoomControl |
| loading | 图片未解码完 | 骨架屏 / spinner |
| error | 解码失败 / MIME 拒 | 「图片无法显示」占位 + 原因 |

---

## 3. 缩放 / 灯箱 / 画廊验收标准（草案）

| 能力 | 验收标准 |
|------|----------|
| 画廊网格 | 多图按 `created_at` 或拖入序排列；点击进灯箱 |
| 灯箱 | 遮罩点击空白/ESC 关闭；左右键切换；不影响底层页签 |
| 缩放 | 25%~400% 连续；超界禁用；鼠标滚轮增量合理 |
| 大图 | 超过视口自动 fit；不溢出滚动条卡死 |
| 元信息 | 展示 mime/size/尺寸；与 `ImageRef` 一致 |
| 错误态 | MIME 拒 / 解码失败有占位与原因，不白屏崩溃 |

---

## 4. 依赖 M2-1 的接口清单

- `ImageRef` 字段（`path/caption/mime/size_bytes/width/height`）→ 由 M2-1-assist §1 定义。
- `bridge.load_images(artifact_id) -> ImageRef[]`（或并入 `load_artifacts` 返回）。
- 图片二进制读取走 `asset:`/`file://` 本地协议（遵守子 webview 定位规则，同 M2-8）。
