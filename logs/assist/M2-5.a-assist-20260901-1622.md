## 4. 参数弹窗流程（mock）

1. 点「运行」→ `ArgForm` 弹出，按 `scriptForm.args` 渲染控件。
2. 必填项校验；`secret=true` 用 `type=password`。
3. mock 期：收集参数 → `console.log(resolvedArgs)`，**不调 run_script**。
4. 真实期（M2-4）：`bridge.run_script(meta, resolvedArgs)` → `RunConsole` 订阅 `Channel`。

## 5. 执行状态 mock

```
type RunStatus = "idle" | "running" | "success" | "failed" | "cancelled";
const runStatus = ref<RunStatus>("idle");
const runLog = ref<LogLine[]>([]);  // { ts, stream: "stdout"|"stderr", line }
```
- mock 期 `RunConsole` 显示静态示例行（如 `[mock] stdout: hello`）。
- 真实期由 M2-4 的 `Channel<LogLine>` 灌入；支持取消按钮（M0-2 协议）。
