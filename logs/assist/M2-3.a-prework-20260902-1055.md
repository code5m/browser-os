### 2.1 两个必须先解决的硬约束

1. **M0-2 单一真退出入口未落地**。脚本执行是长生命周期行为，若没有统一退出收口，关闭主窗会残留 shell 子进程（与 #3 资源释放是同一个洞）。**建议：脚本执行能力必须在 `request_app_exit` 落地之后或同期合入**，否则等于新增泄漏源。
2. **`shell:allow-spawn` 的 `args: true` 已是完全开放**。经 Tauri shell 插件直接执行命令时，ACL 不再过滤参数。因此**脚本执行的参数校验必须在 `run_script` 内部自己做**，不能寄望于 capabilities。

### 4.1 领域模型

```rust
// src-tauri/src/domain.rs

/// 参数类型（决定前端控件与校验规则）
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "snake_case")]
pub enum ParamType {
    /// 自由文本。危险字符校验最严
    String,
    /// 整数
    Int,
    /// 布尔（复选框）
    Bool,
    /// 枚举，options 必填非空
    Enum,
    /// 本地路径。必须位于白名单根目录内，禁止 ".."
    Path,
}

/// 脚本参数定义
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ScriptParam {
    pub name: String,          // 占位符名，对应脚本里的 ${name}
    pub label: String,         // 前端显示名
    pub param_type: ParamType,
    pub required: bool,
    pub default: Option<String>,
    pub options: Vec<String>,  // 仅 Enum 使用
    /// 该参数是否允许出现在 shell 命令行中而不加引号包裹。
    /// 默认 false：一律以单引号包裹后拼接（防注入）
    pub raw: bool,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ScriptMeta {
    pub id: String,            // uuid v4
    pub name: String,          // 展示名
    pub category: String,      // 分类/标签
    /// 脚本绝对路径。必须在 workspace 或用户显式授权目录内
    pub path: String,
    pub interpreter: String,   // "bash" | "sh" | "python3" | "node" | ""（用 shebang）
    pub params: Vec<ScriptParam>,
    pub description: String,
    pub builtin: bool,         // 内置模板（不可删除）
    pub timeout_secs: u32,     // 0 = 用全局默认（建议 300）
    pub enabled: bool,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
}
```

### 4.3 危险参数规则（**fail-closed**）

参数值**在拼进命令行之前**必须过以下检查；任一命中即拒绝并记录 `audit.json`，**不执行**：

| 规则 | 触发字符/模式 | 错误码 |
|---|---|---|
| 命令替换 | `` ` ``、`$(`、`<(`、`>(` | `DANGEROUS_SUBSHELL` |
| 链接/管道 | `;`、`&&`、`\|\|`、`\|`、`&` 结尾 | `DANGEROUS_CHAIN` |
| 重定向 | `>`、`<`、`>>` | `DANGEROUS_REDIRECT` |
| 通配符展开 | `*`、`?`、`[` | `DANGEROUS_GLOB` |
| 换行/回车 | `\n`、`\r`、`\0` | `DANGEROUS_NEWLINE` |
| 变量注入 | `${`、`$FOO`（`$` 后跟标识符） | `DANGEROUS_VAREXP` |
| 路径穿越 | `..` | `PATH_ESCAPE` |
| 超长 | > 4096 字符 | `ARG_TOO_LONG` |
| 控制字符 | 0x00-0x1F | `DANGEROUS_CONTROL_CHAR` |

**默认拼接策略**：所有参数一律 `'...'` 单引号包裹（`raw: true` 的参数除外，且 `raw` 仅允许 `Path`/`Enum` 类型，并仍受路径穿越与超长检查）。
**`raw: true` 必须显式写审计条目**，便于事后追溯谁开了口子。

### 4.4 审计契约

- 写入时机：**执行前**写一条 `action = "script_run_start"`，**结束后**写一条 `action = "script_run_end"`（含 `status`/`exit_code`）。只有 start 没有 end = 异常（进程被杀/应用崩溃），后续可据此做恢复提示。
- 审计 `detail` 必须含：`run_id`、`script_id`、参数**脱敏值**（见下）、`triggered_by`。
- **脱敏规则**：参数名命中 `[Pp]ass|[Ss]ecret|[Tt]oken|[Kk]ey|[Aa]pikey` 时，值一律记为 `***`，**不许原文入审计**。
- 禁止把脚本输出全文写审计（会撑爆 1000 条上限），只写 `output_tail` 前 200 字符。

### 4.5 取消与超时

| 语义 | 契约 |
|---|---|
| 取消入口 | `script_cancel(run_id)`，前端按钮 / `request_app_exit` 均走它 |
| 取消实现 | kill **进程树**（不只是直接子进程）：`killpg` 或先 kill 直接子进程再等待子进程组；禁止只 `Child::kill()` 了事 |
| 取消后状态 | `Cancelled`，`exit_code = null`，写 `script_run_end` 审计 |
| 超时 | `timeout_secs`（脚本级，缺省取全局 300s），超时 → kill 进程树 → `Timeout` |
| 输出上限 | 单 run 输出保留最后 **256 KB**；超出丢弃头部并在 `output_tail` 头部插入 `[输出已截断]` 标记 |
| 并发 | 同一 `script_id` 默认**禁止并发**（防重复触发叠加）；不同脚本可并发，总数上限建议 8 |
| 孤儿保证 | 应用退出前必须对所有 `Running` 记录执行取消；`request_app_exit` 未落地前**不得合入** |

## 5. 风险

| # | 风险 | 等级 | 缓解 |
|---|---|---|---|
| R1 | `M0-2 request_app_exit` 未落地 → 关窗残留 shell 进程树 | **高** | 阻塞项：脚本执行与该入口同期或之后合入 |
| R2 | 参数拼接被注入（用户填 `; rm -rf /`） | **高** | §4.3 fail-closed 规则 + 单引号包裹 + 单测覆盖 N1~N6 |
| R3 | `shell:allow-spawn` args:true 已全开，ACL 不兜底 | **高** | 校验必须在 `run_script` 内部；不得依赖 capabilities |
| R4 | 脚本输出巨量（如 `yes`）撑爆内存/事件通道 | 中 | 256 KB tail 上限 + 输出事件节流（与 M3-1 的 mpsc+pump 共用方案） |
| R5 | 审计 1000 条上限被高频脚本刷掉历史 | 中 | 审计只写摘要；运行历史独立文件（也设上限） |
| R6 | 凭据/密钥经参数传入后被审计明文记录 | **高** | §4.4 脱敏规则；参数名命中即 `***` |
| R7 | 脚本路径指向任意可执行文件（不仅是 .sh） | 中 | `path` 必须落在 workspace 或用户授权目录白名单内，且 canonicalize 后前缀校验 |
| R8 | 定时任务（M4-58.a）复用本通道后放大 R2/R4 | 中 | `triggered_by` 字段预留，定时触发同样走完整校验 |
| R9 | 超时 kill 只杀直接子进程，孙子进程（如脚本起后台 daemon）残留 | 中 | 进程组 kill（setsid 创建进程组 + killpg） |
| R10 | 前端把 `run_id` 丢了导致无法取消 | 低 | `run_id` 由后端生成并在 `run_script` 返回中给出 |

## 8. 失败动作

| 失败 | 动作 |
|---|---|
| N1~N8 任一注入用例通过（脚本真被执行） | **阻断合并**，参数校验重做；未完成校验前禁止暴露 `run_script` 命令 |
| 取消/超时后 `ps` 仍有子进程 | 改进程组 kill（`setsid` + `killpg`）；未完成前脚本功能保持 disabled |
| `request_app_exit` 仍不存在 | **不合并**脚本执行，先做 M0-2；或临时把脚本入口隐藏（feature flag 关） |
| 审计出现明文密钥 | 立即修脱敏 + 清理已落盘的 `audit.json` 中泄露条目 |
| clippy warning 增长 | 按基线清零后再合入 |
| 输出撑爆内存 | 强制 256 KB 截断 + 事件节流；与 M3-1 mpsc 方案统一 |
