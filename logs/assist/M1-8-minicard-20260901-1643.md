# M1-8 强模型最小输入卡（≤80 行）

> 来源：M1-8-assist-20260901-1630.md。仅给 AI:DEEP/R:high，本卡不实现、不签 PASS。

## 目标
把现有"资源项列表"升级为请求级瀑布（时序/大小/状态码/耗时/MIME），带容量上限 + 隐私过滤 + 节流；仅会话内展示，不落盘。

## 必改文件
- `src-tauri/src/injected/resources_eval.js`：扩展采集 `performance.getEntriesByType('resource')`。
- `src-tauri/src/bridge.rs`：`report_resources` 增可选 `waterfall` 字段；复用 `check_items_count`/`check_text_field`/`check_invocation_source`。
- `src/components/browser/BrowserHost.vue`：新增瀑布面板（默认隐藏，设置开启）。
- `security_policy.rs`：新增 `MAX_WATERFALL_ITEMS=500`/`WATERFALL_BUF_CAP=1MB`/`WATERFALL_SAMPLE_MS=1000`。

## 禁止事项
- 不落盘瀑布（不写 `audit.json`/成果库）。
- 不记 `Set-Cookie`/`Authorization`/`token`；URL 中 `?token=` 须脱敏为 `?token=***`。
- 不采集 `file://`/内联 `data:`；仅 `http(s)://` 同域或已访问页。
- 不新建 IPC 通道（复用现有 `window.ipc.postMessage`）。
- 不移动 `NEXT`。

## 实现要点
1. 采集：`resources_eval.js` 内 `requestIdleCallback` 中读 `performance`，节流 `WATERFALL_SAMPLE_MS`，避免 R1 性能开销。
2. DTO：`ResourceWaterfallItem{url,type,size,duration_ms,status,mime}`；超 `MAX_WATERFALL_ITEMS` 截断 oldest。
3. 隐私：采集前脱敏鉴权头/查询参数；来源白名单；用户开关默认关。
4. 隔离：子 webview 注入脚本仅读本页 `performance`（R2 防跨 webview 泄漏）。
5. 时序：`scan_resources` 保持 `navigationFinished` 后触发（R4）。

## 验收命令
```
cargo build --release
npm run build
bash scripts/pre-merge.sh                  # ALL_PASS
# 手动：开瀑布面板 → 访问含多资源的页 → 看时序/大小/状态码
```

## 反向用例
- token URL 入瀑布 → 显示 `?token=***`，不现明文。
- 连续刷新 >500 条 → 截断 oldest，内存不爆。
- 关采集开关重启 → 瀑布清空，无审计/成果写入。
- `file://` 页 → 不采集。

## 失败动作
- 事件洪水 → 调 `WATERFALL_SAMPLE_MS` + `MAX_WATERFALL_ITEMS` 后重测。
- 隐私泄露（token 现明文）→ 退敏感度过滤逻辑，复测反向用例 1。
- 页面卡顿 → 确认采集在 `requestIdleCallback` 内，非主线程同步 eval。
