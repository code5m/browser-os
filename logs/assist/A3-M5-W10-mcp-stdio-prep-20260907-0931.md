### 1.1 产品代码（4 文件）
- `src-tauri/Cargo.toml`：新增 `[features] mcp = []`（默认关；`--features mcp` 才纳入骨架）。**未引入 rmcp/tokio 等新依赖**（W10 允许 optional gated，但本波采用更稳的纯 std-only 骨架，默认构建零变化）。
- `src-tauri/src/main.rs`：
  - 声明 `#[cfg(feature = "mcp")] #[path = "mcp_server.rs"] mod mcp_server;`（feature 关时整模块不编译）。
  - `main()` 顶部注入 `#[cfg(feature = "mcp")] if args 含 "--mcp-stdio" { crate::mcp_server::run_stdio(); return; }`——以该标志启动时不进入 Tauri 主流程，直接跑只读 stdio JSON-RPC 环。
- `src-tauri/src/mcp_server.rs`（**新**）：feature-gated 的 MCP stdio-prep 骨架。
  - 仅用 `std::io` 做 stdio 传输（`stdin` 逐行读 JSON-RPC、`stdout` 写响应），**不碰 `std::net`、不起监听、不 spawn 进程、不调 `script_runner`、不碰 DB/fs 写/插件运行时**。
  - **复用 `crate::mcp` 注册表/策略接线**：`list_registry_entries()`（能力单一真源）+ `current_policy_snapshot()`。`tools/list` 从注册表派生 7 个能力；`tools/call` 仅两个只读 introspection 工具（`mcp_policy_get`/`mcp_registry_list`）复用视图函数零副作用返回；其余 registry 能力（file_read 等）是 **prep 态**，fail-closed 返回 `isError=true`（不落地任何执行路径，M5-2.b 后续再绑定 core API）。
  - 7 个 focused 单元测试覆盖 `initialize`/`tools/list`/只读调用/fail-closed/未知方法/通知无响应。
- `scripts/check-mcp-policy.py`：**策略升级**（见 §2）。

### 1.2 为何放在 `src/mcp_server.rs` 而非 `src/bin/mcp_server.rs`
W10 Allowed Scope 提到 `optional src-tauri/src/bin/mcp_server.rs`。但 `mcp` 模块当前声明在 `main.rs`（二进制 crate）而非 `mvp_core` lib，独立 `[[bin]] mcp_server` 无法 `use crate::mcp::*`。更关键：**Cargo 会自动把 `src/bin/*.rs` 识别为独立二进制**——若放在 `src/bin/`，会生成一个独立 `mcp_server` bin，其内 `crate::mcp` 无法解析而编译失败（已实测 E0432）。故采用 dispatch 允许的「or equivalent compile-isolated skeleton」：以 `#[cfg(feature="mcp")]` 模块置于 `src/mcp_server.rs`，经 `#[path]` 纳入主二进制，复用 `crate::mcp` 直接生效，默认构建零变化。策略脚本 `MCP_SERVER_GATED` 同时覆盖 `src/bin/mcp_server.rs` 与 `src/mcp_server.rs` 两种路径。

## 2. 策略脚本升级（check-mcp-policy.py）

W10 打开了「gated stdio 骨架」这一曾被 W7 Hard Stop 否决的架构切片，故把 W9 M5-2.b 前瞻卡落地为门禁：

- **`MCP_NO_RMCP_SERVER`（ACTIVE）放宽**：仍禁未门控的 rmcp/tokio/网络监听；但改为**放行 feature-gated 形态**——
  - `[[bin]] mcp_server` 仅当带 `required-features` 才放行（否则仍判违规）；
  - `mcp_tools/` 目录内文件仅当以 `#![cfg(feature="mcp")]` 自门控才放行。
- **新增 `MCP_SERVER_GATED`（ACTIVE，第 9 个 ACTIVE 码）**：守「允许的 stdio 骨架」——
  - 文件（`src/bin/mcp_server.rs` 或 `src/mcp_server.rs`）必须以 `#![cfg(feature = "mcp")]` 自门控（默认构建不编译）；
  - `Cargo.toml` 须声明 `[features] mcp`；
  - 不得含网络/监听/进程派生/执行副作用（`axum`/`hyper::Server`/`TcpListener`/`TcpStream`/`UdpSocket`/`Command::new`/`.spawn(`/`std::process`）；
  - 必须走 stdio（使用 `std::io`）。
  - 满足则 `None`（不违规）；未满足则报错（与 W7 Hard Stop 一致）。
- `--expect-current-gaps` 升级为 **W10 相位**：gated stdio 骨架已落地 + 只读桥在 + 无未门控 rmcp/server/listener/tokio + 奇偶/只读/红线性门禁全绿。

> 注：自查发现两处「自身注释/字符串触发策略误报」已修正——Cargo.toml 注释移除 `rmcp`/`tokio` 字面量、`mcp_server.rs` 移除 `MCP_COMMAND_REGISTRY` 字面量（后者会让 `MCP_FS_TOOL_PATH_POLICY` 误判）。修正后默认/当前相位均 PASS。
