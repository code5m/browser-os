## 1. 会话模型草案（domain.rs 新增）

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct BrowserSession {
    pub id: String,                 // = TabInfo.id
    pub url: String,
    pub title: String,
    pub preview: Option<String>,    // 最小预览（缩略文本/首屏描述，非图片二进制）
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
    pub saved: bool,                // 用户显式收藏的会话（区别于临时）
}
```

- 持久化：`data_dir/sessions.json`（仿 `repos.json`/`bookmarks.json` 模式）。
- `TabInfo` 与 `BrowserSession` 1:1；`tab_new` 时建 session（`saved=false`），
  用户「保存会话」置 `saved=true`。

## 2. 保存 / 删除 / 关闭 flush

| 操作 | 触发 | 行为 |
|------|------|------|
| 保存 | 用户点「保存此会话」 | `session.saved=true` + 落盘 `sessions.json` |
| 删除 | 用户删会话/清历史 | 从 `sessions.json` 移除 + kill 对应 tab（若活跃） |
| 关闭 flush | 应用退出 / tab 关闭 | `coordinator.register("flush-sessions", ...)`：遍历内存 tabs，
  写 `updated_at` + `preview`（取当前 `report_resources` 缓存）后落盘 |
| 重启恢复 | 启动 `setup` | 读 `sessions.json`，非 `saved` 的临时会话可丢弃或保留（策略待定，建议保留 1 天） |

---

## 3. 最小预览（草案）

- 不存图片二进制（避免膨胀），存 `preview: Option<String>`：取页面 `<title>` + 首段文本
  （`report_resources` 已能拿资源，可扩展取 `document.body.innerText.slice(0,200)`）。
- 前端 `BrowserHost` 会话缩略卡显示 `title` + `preview`；点击 `tab_new(url)` 恢复。
- 容量：单预览 `MAX_PREVIEW_BYTES = 512`（复用 `security_policy::check_text_field`）。

---

## 4. 生命周期接入（草案，复用 M0-2）

```rust
// bridge.rs setup 或 main.rs，仿 kill-terminals
coordinator.register("flush-sessions", move || {
    let app = app.handle();
    if let Err(e) = flush_sessions(&app) { eprintln!("[flush-sessions] {e}"); }
});
```
- `flush_sessions`：加锁 `state.tabs` → 逐 tab 写 `BrowserSession` → 原子落盘
  （`tempfile`+rename，防损坏，同 M4-6 原子落盘要求）。
- 退出时由 `ShutdownCoordinator` 在 `ExitRequested` 前调用，保证不丢。

## 5. 风险点

| # | 风险 | 缓解 |
|---|------|------|
| R1 | 退出竞态 | flush 在 `ExitRequested` 同步执行，须在 `shutdown_coordinator` 注册（不新建线程） |
| R2 | 预览膨胀 | `MAX_PREVIEW_BYTES` 截断；不存图片 |
| R3 | 隐私 | 会话含 URL 可能敏感；`sessions.json` 同级 `bookmarks.json` 权限，不出院 |
| R4 | 重启重入 | `tab_new` 恢复时若 tab 已存在则跳过，防重复 |
| R5 | 与 M1-3 收藏混淆 | `saved` 会话 ≠ 书签（书签是 URL 快捷，会话是带预览的浏览上下文），UI 分开展示 |

---

## 6. 验收标准（草案）

| 能力 | 标准 |
|------|------|
| 保存 | 显式保存后 `sessions.json` 含 `saved=true` 项 |
| 删除 | 删除后项消失 + 活跃 tab kill |
| 关闭 flush | 正常退出后 `updated_at` 更新、预览写入；重启可恢复 |
| 最小预览 | 卡片显示 title+预览文本；不超 `MAX_PREVIEW_BYTES` |
| 生命周期 | 退出无残留 tab 进程；flush 在 ExitRequested 前完成 |
