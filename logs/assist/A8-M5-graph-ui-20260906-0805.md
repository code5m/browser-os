## 0. 摘要（给 A0 / 后续 Lane / 实施期 A19 卡）

M5-9 是「知识图谱」能力的**前端消费层**：把 A7/A9 在 M5-7/M5-8 落地的图谱核心（节点/边/查询/统计命令）以
**力导向图 + 查询框 + 节点详情 + 容量状态 + 无障碍 + Agent 子图注入**呈现给用户与 Agent。

本预研给出：**事实基线 → 面板地图（组件拆分）→ 状态模型（useGraphStore）→ 纯逻辑层（graphUi.ts）规划 →
数据契约需求（A7 必须暴露的 DTO/命令，逐字对齐 A9 契约）→ 六大能力落点 → 构建体积与懒加载（IF-2 延续）→
护栏继承（M4 红线）→ UI 任务卡拆分（M5-9.a~f）→ 逻辑测试计划（未来 check-graph-ui-logic.mjs 的断言）→
风险 → 验证 → 合并须知**。

核心结论（沿用 M4-8 已验证口径）：

1. **纯逻辑 / 组件壳先于后端命令**：模仿 M4-8 `TaskPanel` 的 `backendReady` 拦截，后端 `graph_*` 命令未落地前
   面板为**只读壳、零 invoke**；`GRAPH_COMMANDS_AVAILABLE` 由 `src/bridge.ts` 暴露，`graphUi.ts` 纯函数可被
   `node scripts/check-graph-ui-logic.mjs` 直接断言（无 DOM / 无 store 依赖）。
2. **懒加载保体积**：力导向图依赖（d3-force / canvas 力算）是体积大户，必须按 A5/A8 M4 Integration Fix 口径
   动态 `import()` 进布局，避免主 chunk 再涨（IF-2 红线，§7）。
3. **Agent 子图注入是只读预览**：导出/复制子图为上下文片段，真正「注入 Agent 记忆」走 A4 `agent_kv` / A5 运行时，
   M5-9 只负责取子图 + 格式化 + 复制，不新增任何命令/出网动作。
4. **零护栏漂移**：所有未来 `graph_*` 命令必须 source check + ACL（插 `list_artifact_images` 之前）、
   隐私过滤在**查询层**（前端只展示不负责过滤）、容量/截断标志显式提示、审计按 A9 低频口径。

## 2. 面板地图（组件拆分）

全部位于 `src/components/workspace/`，不引入新目录；与现有 `TaskPanel`/`DatabasePanel` 平级，经布局开关统一切换。

| 组件 | 职责 | 后端依赖 | 备注红线 |
|---|---|---|---|
| `GraphPanel.vue` | 主面板：容器 + 顶部工具条（查询框/容量徽标/重建按钮/注入按钮）+ 力导向画布 + 详情抽屉 | `graph_query`/`graph_stats`/`graph_build` | 后端未就绪时只渲染 banner + 空态，**不**渲染画布 |
| `GraphCanvas.vue` | 力导向图渲染（节点/边/拖拽/缩放/点击）；**懒加载** | `graph_query` 结果 | 力算依赖动态 `import()`，不进主 chunk（§7） |
| `GraphSearchBox.vue` | 查询构造器：start/kinds/relations/depth/limit/privacy 表单 | `graph_query` | 前端前置校验 depth≤2、limit≤1000（后端仍终裁） |
| `GraphNodeDetail.vue` | 节点详情抽屉：label/kind/ref_id/sources/隐私级/props 摘要/出边入边列表 | `graph_neighbors` | 凭据/私密字段永不展示；`restricted` 节点只给「不可见」占位 |
| `GraphCapacityBadge.vue` | 容量状态徽标：节点/边计数、degraded 标记、truncated 显式提示 | `graph_stats` | 超限/截断**显式提示**，绝不静默 |

> **拆分原则**（与 M4-8 一致）：重型渲染（`GraphCanvas`）与重型依赖隔离在可懒加载子组件；
> `GraphPanel` 本身轻量，保证未就绪时也能渲染只读壳而不拉起力算依赖。

## 3. 状态模型（useGraphStore 设计，镜像 useTaskStore）

`src/stores/useGraphStore.ts`（pinia）草案：

```ts
// 约束（board + A9 契约）：
//   - 组件不得直接 invoke，一切经 `bridge.ts`；
//   - 后端 6 条命令（graph_build/query/neighbors/stats/rebuild/prune）由 A7（M5-8）落地；
//     未落地前 `backendReady=false`，所有动作 no-op 且零 invoke（LIMITED START 口径，同 M4-8）。
//   - privacy 过滤以**后端查询层**为准（A7 §7.4）；前端仅展示隐私过滤提示（A7 结果无 `filtered_by_privacy`，不展示精确计数），绝不自行过滤。
//   - 凭据/私密 props 永不进前端持久化（A7 §7.4 / graph-model-taskcard §4.6 K3）。

const graph = ref<GraphView>(emptyGraphView());
const stats = ref<GraphStats | null>(null);
const selectedNodeId = ref<string | null>(null);
const loading = ref(false);
const error = ref<string | null>(null);
const backendReady = ref<boolean>(GRAPH_COMMANDS_AVAILABLE);

// 与 useTaskStore:59 同款拦截：未就绪不发一条 invoke。
function guard(): boolean {
  if (backendReady.value) return true;
  error.value = "后端图谱命令尚未就绪（A7 / M5-8 未交付），面板为只读壳";
  return false;
}

async function loadStats(): Promise<void> { if (!guard()) return; /* bridge.graphStats() */ }
async function query(q: GraphQuery): Promise<void> { if (!guard()) return; /* bridge.graphQuery(q) */ }
async function neighbors(id: string): Promise<void> { if (!guard()) return; /* bridge.graphNeighbors(id) */ }
async function rebuild(): Promise<void> { if (!guard()) return; /* bridge.graphRebuild()，低频审计 */ }
// 子图注入：仅取+格式化，复制由 GraphInjectionDialog 调剪贴板；不出网。
function buildInjectionContext(view: GraphView): string { return formatSubgraphAsContext(view); }
```

要点：
- `backendReady` 由 `GRAPH_COMMANDS_AVAILABLE` 初始化，后端落地后翻 `true`（仿 `bridge.ts:53`）。
- `guard()` 复用 M4-8 的「零 invoke」语义，避免对不存在命令反复报错、污染错误条。
- 历史/审计不进 store；`graph_rebuild` 进度事件由后端 emit，store 订阅后刷新 `stats`（同 TaskPanel 的 run 快照并入）。

## 4. 纯逻辑层（graphUi.ts）规划

`src/utils/graphUi.ts`：**无 invoke / 无 DOM / 无 store 依赖**，可被 `node scripts/check-graph-ui-logic.mjs`
直接 `import` 断言（完全镜像 `taskUi.ts` 头部约束）。须导出：

```ts
// 常量（与 A9 契约冻结值对齐，前端不得自行放宽）
export const GRAPH_MAX_DEPTH = 2;            // A7 §3.3 / §5.5：>2 拒绝 GRAPH_DEPTH_EXCEEDED
export const GRAPH_MAX_QUERY_LIMIT = 1000;   // A7 §3.3 / §5.5：>1000 拒绝 GRAPH_LIMIT_EXCEEDED
export const GRAPH_DEFAULT_LIMIT = 200;      // A7 §5.5
export const GRAPH_MAX_NODES = 50_000;       // A7 §3.3 容量红线
export const GRAPH_MAX_EDGES = 200_000;
export const GRAPH_MAX_DEGREE = 500;
export const GRAPH_MAX_SOURCES = 20;         // A7 §3.3：sources 集合上限

// 类型（镜像 A7 §5.5 / §3.2 GraphQuery/Result/Node/Edge，逐字对齐 serde snake_case）
// 注意：A7 权威 `GraphNode` 存储模型**无** stored privacy 字段（隐私为查询层派生，§7.4）；
// `privacy?` 以下为「派生展示字段，待 A7 确认是否进 GraphNodeView」（见 §5.4）。
export interface GraphNodeView { id: string; kind: string; ref_id: string | null;
  label: string; degree: number; sources: string[]; updated_at: string;
  privacy?: string; }   // * 派生隐私级（public/internal/private/restricted），待 A7 裁定
export interface GraphEdgeView { id: string; src: string; dst: string; relation: string;
  weight: number; source: "rule" | "ai"; }
export interface GraphQueryResult { nodes: GraphNodeView[]; edges: GraphEdgeView[];
  truncated: boolean; field_truncated: boolean; elapsed_ms: number; query_id: string; }
  // 注：A7 权威结果**无** filtered_by_privacy（早期 graph-model-taskcard §4.4 有，已被 A7 覆盖）
export interface GraphStats { node_count: number; edge_count: number; degraded: boolean;
  last_event_seq: number; schema_version: number; }   // A7 §8 graph_stats()
export interface GraphExport { format: "json" | "graphml"; content: string; truncated: boolean; }
  // A7 §5.4 graph_export()

// 纯函数（可单测）
export function validateGraphQuery(q: GraphQuery): GraphIssue[];   // depth≤2 / limit≤1000 / 前端前置（对齐 A7 §5.5）
export function kindLabel(kind: string): string;                   // 节点类型中文标签（对齐 A7 §3.1 枚举）
export function relationLabel(relation: string): string;           // 边关系中文标签（对齐 A7 §3.1 枚举）
export function privacyLabel(privacy: string): string;             // public/internal/private/restricted（仅当 GraphNodeView 含派生 privacy）
export function formatCapacity(stats: GraphStats): { ratio: number; degraded: boolean; text: string };
export function formatTruncation(r: GraphQueryResult): string | null;  // truncated/field_truncated 显式提示文案（禁静默）
export function formatSubgraphAsContext(view: GraphView): string;  // 子图→Agent 上下文片段（纯文本，不含私密节点）
export function accessibleNodeContrast(kind: string): { fg: string; bg: string }; // 无障碍对比色（§6.5）
```

> **纯逻辑边界**：`validateGraphQuery` 只做**前端即时反馈**，后端查询层仍为唯一裁决者（同 `taskUi.validateTaskDraft` 口径）。
> 隐私过滤**不**在 `graphUi.ts` 做——那是后端 `graph_query` 的责任（A7 §7.4：不可靠 UI 过滤）。

| 命令 | UI 用途 | 后端红线（来自 A7 §8/§5.5/§7） |

### 5.2 DTO（src/types.ts 镜像，serde rename_all="snake_case"）

- `GraphQuery { start: string[]; relations: string[]; kinds: string[]; max_depth: u8; limit: usize; privacy: string; cancel: QueryCancel }`
  —— `max_depth` 拒绝 >2（`GRAPH_MAX_DEPTH`），`limit` 拒绝 >1000（`GRAPH_MAX_QUERY_LIMIT`），`privacy` 默认 `public`（Agent 上下文注入时）。
- `GraphQueryResult { nodes; edges; truncated; field_truncated; elapsed_ms; query_id }`
  —— `truncated`/`field_truncated` 沿用 M4-1.c §2 语义：超限**非错误**，UI 必须显式提示；**不含** `filtered_by_privacy`（早期 taskcard 有，A7 已覆盖）。

  —— `privacy?` 为派生展示字段，A7 权威 `GraphNode` 存储模型无 stored privacy（隐私查询层派生，§7.4）；是否进 View 待 A7 裁定（§5.4）。

- `GraphStats { node_count; edge_count; degraded: bool; last_event_seq; schema_version }` —— A7 §8。
- `GraphExport { format: "json"|"graphml"; content: string; truncated: bool }` —— A7 §5.4 `graph_export`。

## 6. 六大能力落点（后续需求TODO §13 一一对应）

### 6.1 力导向图（force graph）
- `GraphCanvas.vue`：节点=实体、边=关系；支持拖拽/缩放/点击聚焦。
- **依赖隔离**：力算（d3-force 或自研 canvas 力算）经动态 `import()` 加载（§7）。
- 隐私：画布**只渲染后端已返回的节点**；`restricted` 节点永不出现（后端查询层已剔除）。
- 容量：节点数接近 `GRAPH_MAX_NODES` 时 `GraphCapacityBadge` 显式降级提示，画布降采样（不渲染全部 5 万节点）。

### 6.2 搜索 / 查询（search）
- `GraphSearchBox.vue`：构造 `GraphQuery`（start/kinds/relations/depth/limit/privacy）。
- 前端前置校验（§4 `validateGraphQuery`）：depth≤2、limit≤1000、privacy 合法；后端终裁。
- 关键字模糊匹配：`graph_query.keyword`（graph-model-taskcard §4.4）若后端支持则接；不支持则前端按 label 本地过滤。

### 6.3 节点详情（node details）
- `GraphNodeDetail.vue`：点击节点 → `graph_neighbors(id)` → 抽屉展示 label/kind/ref_id/sources/隐私级/props 摘要/出边入边。
- `ref_id` 回指既有领域对象（Artifact.id / ScriptMeta.id / TaskDef.id …），详情里提供「跳转到原实体」深链（只读，不跨模块调用）。
- 凭据/私密字段：props 中若是 `private`/`restricted`，只显示「此字段不可见」占位（K3）。

### 6.4 容量展示（capacity）
- `GraphCapacityBadge.vue`：`graph_stats()` 驱动；展示节点/边计数、`degraded` 标记、`truncated` 提示。
- 硬约束显式：达 `GRAPH_MAX_NODES`/`GRAPH_MAX_EDGES` 时提示「先 prune」（A9 §4.7）。

### 6.5 无障碍（accessibility）
- 力导向图对屏幕阅读器不友好，须提供**等价表格视图**（`GraphNodeDetail` 的列表态 + 键盘可达的节点列表）。
- `accessibleNodeContrast(kind)`：按节点类型给高对比配色，满足 WCAG AA。
- 所有交互（查询/重建/注入）均键盘可达，禁止仅靠鼠标 hover 暴露信息（M2-6 观察项同口径）。
- 力导向动画尊重 `prefers-reduced-motion`，提供静态布局备选。

### 6.6 Agent 子图注入（subgraph injection）
- `GraphInjectionDialog.vue`：用户框选/点击中心节点 → `graph_query`（depth≤2）→ `formatSubgraphAsContext(view)`
  生成纯文本上下文片段（节点+边+label 摘要，**不含**私密 props 全文）→「复制到剪贴板」。
- **不自动出网**：真正写入 Agent 记忆走 A4 `agent_kv` / A5 运行时（M5-3/M5-4/5 范围），M5-9 只取+格式化+复制。
- 隐私守门：注入片段的 `privacy` 取子图最高级（A7 §7.4 保守取最高，隐私为查询层派生）；`restricted` 节点不进片段（K3）。
- 依赖：`graph_query` 的 `privacy` 参数在 Agent 上下文场景默认 `public`（A7 §5.5 / §7.4），由 `GraphInjectionDialog` 固定传 `public`。
