## 3. A5 M5-4/5 兼容性评审（Agent/Skill runtime / 命令）

### 3.1 G4 capability 单源缺口 — 与 M5-2 的对账（**核心兼容性点**）

- **建议（给 A0/A3 M5-2.b）**：能力常量**最终须落在 `mvp_core`（`core/capability.rs`）**，由 bin 侧（`domain.rs`/`mcp.rs`/`security_policy.rs`）re-export，避免影子副本（D46）。理由见 §4 R1（R-B3）。A5 在 G4 未补前**不得**新建 `SKILL_CAPABILITY_V1`/`AGENT_CAPABILITY_V1` 独立文件，否则触发 capability 漂移。

### 3.2 执行复用 / 第二路径（AGSK_1 vs core 边界）
- A5 红线 `AGSK_1`（`grep std::process|Command::new|tokio::spawn` = 0）与 `check-core-boundary.py`「第二执行路径」**同源**；`skill_runtime.rs`/`agent_runtime.rs` 必须走 `script_runner::start_run`/`start_command`（M2-4）。

### 3.3 命令命名空间（避免误触 `MCP_PARITY`）
- A5 的 15 条命令命名 `skill_*`/`agent_*`（M5-5.a），**非** `mcp_*`；`MCP_PARITY` 只扫 `mcp_server_start|mcp_server_stop|mcp_policy_get|mcp_policy_set`，不会误伤 `skill_*`/`agent_*`。

## 4. 兼容性风险 / 开放项（精确文件清单 + 解锁条件）

### R1（主阻塞，属 A3 M5-2.b）— capability 单源必须进 `core/`（R-B3）
- **事实**：`lib.rs` 仅 `pub mod core;`；`domain.rs` 是 bin 模块（`main.rs: mod domain;`）。故 `core/`（`agent_kv.rs`、未来 `capability.rs`）**不能 `use crate::domain`**（R-B3，与 A4 W3 delta §2 完全一致）。
- **后果**：`MCP_CAPABILITY_V1`/`McpGlobalPolicy` 当前 bin-only，A4 M5-3.b 与 A5 G4 无法在无 `core use crate::domain` 前提下单源消费。
- **A3 须在 M5-2.b 做**：在 `core/capability.rs`（`mvp_core` lib）定义 `pub const MCP_CAPABILITY_V1` + `pub struct McpGlobalPolicy`（或 re-export），bin 侧 `domain.rs`/`mcp.rs` 改为 `pub use mvp_core::capability::*`（与 `lib.rs:30` 的 `pub use crate::core::*;` re-export 约定一致），**删掉 `domain.rs` 里的影子定义**。`check-mcp-policy.py::MCP_CAPABILITY_DRIFT` 会因"单一真源"在 `core/capability.rs` 而继续 PASS。
- **解锁对象**：A4 M5-3.b（U-4）、A5 G4（capability 常量列表）—— 二者目前 BLOCKED on A3，与本波前 A4/A5 自述一致。

### R2 — A5 计划把 capability 放 `security_policy.rs`，与 A3 `domain.rs` 放置冲突
- **处置**：以 R1 的 `core/capability.rs` 为唯一真源；`security_policy.rs` 仅 `pub use` 它即可，不另定义。A5 不得并行定义 `SKILL_CAPABILITY_V1`/`AGENT_CAPABILITY_V1`。

### R3 — agent_kv 持久化路径须走路径根守门
- 一旦 MCP 暴露 `agent_memory_query`，须 `touches_fs:true` + 注册 + `check_path_within_roots`（`MCP_FS_TOOL_PATH_POLICY`）；含 URL/敏感串须 `redact_mcp_url`（`MCP_URL_NOT_REDACTED`）。

### R4 — A4/A5 落码后须保持门禁绿
- `python3 scripts/check-mcp-policy.py`（默认 + --self-test）、`python3 scripts/check-core-boundary.py`、`bash scripts/pre-merge.sh` 必须全 PASS；尤其不得引入 rmcp/tokio/监听（`MCP_RUNTIME_LEAK`/`MCP_LISTEN_PORT`/`MCP_OPTIONAL_DEP`/`MCP_BIN_GATED` 在 `MCP_CAPABILITY_V1` 存在时已置真）。

### R5 — A1 M5-3 卡 C-5/C-6 仍错（A4 W3 delta §4）
- 与 M5-2 无直接耦合，但 M5-3.a 实现前硬门禁文案须修正（值扫描 vs 字段名、per-agent 1 MiB 字节 vs "32 条"）；否则 T-priv-2/T-cap-3 反向失败。属 A1/A0 范围，A3 仅转述提醒。
