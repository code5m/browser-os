## 4. 数据模型

### 4.1 核心类型

```rust
/// 实体类型（对应上游领域对象）
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq, Hash)]
#[serde(rename_all = "snake_case")]
pub enum NodeKind {
    Artifact,     // 成果（M2-1.a 的 Artifact）
    Script,       // 脚本（M2-3.a 的 ScriptMeta）
    Command,      // 命令片段（M2-4）
    Tool,         // HTML 工具（M2-7.b 的 ToolMeta）
    Skill,        // 技能（M5-12.a 的 SkillDef）
    Bookmark,     // 书签（M1-1，尚未实现）
    Repo,         // 仓库（RepoConfig，已存在）
    Task,         // 定时任务（M4-58.a 的 TaskDef）
    Image,        // 图片附件（M2-1.a 的 ImageRef）
}

/// 关系类型
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum Relation {
    /// 成果 A 的正文/HTML 中链接到实体 B
    References,
    /// 属于某分类/标签（dst 为 Tag 节点或 kind 内聚）
    BelongsTo,
    /// 由某 Agent/Skill 生成
    GeneratedBy,
    /// 被某定时任务触发
    TriggeredBy,
    /// 同属一个仓库（Repo）
    SameRepo,
    /// 同源（source_url 的 host 相同）
    SameSource,
    /// 相似（文本/哈希近似）
    Similar,
    /// 附件关系（Artifact 拥有 Image）
    HasAttachment,
    /// 自定义（规则期可扩展，需带 label）
    Custom(String),
}

/// 抽取来源：决定可信度与是否可被覆盖
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "snake_case")]
pub enum GraphSource {
    /// 规则/正则抽取：确定性、可重复、离线
    Rule { rule_id: String },
    /// Agent 语义抽取：需人工校正
    Ai { model: String, confidence: f32 },
    /// 人工建立/校正：**优先级最高，不被自动抽取覆盖**
    Manual,
}

/// 节点：只存索引，不存主数据（派生索引层原则）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct GraphNode {
    /// 稳定 ID：`{kind}:{ref_id}`，保证重建幂等
    pub id: String,
    pub kind: NodeKind,
    /// 回指主数据的 ID（Artifact.id / ScriptMeta.id / ...）
    pub ref_id: String,
    pub label: String,
    /// 扩展属性（如 host、tag、created_at），不复制主数据正文
    pub props: serde_json::Value,
    pub source: GraphSource,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct GraphEdge {
    pub id: String,              // uuid v4
    pub src: String,             // GraphNode.id
    pub dst: String,             // GraphNode.id
    pub relation: Relation,
    pub weight: f32,             // 0.0 ~ 1.0
    pub source: GraphSource,
    pub created_at: DateTime<Utc>,
}
```

### 4.2 派生索引层原则（硬约束）

1. **节点不存主数据正文**。`GraphNode` 只存 `ref_id` + 展示所需的 `label` + 少量 `props`。主数据仍以 JSON 文件为准。
2. **图谱可随时重建**：`graph_build()` 必须是**幂等**的——同样输入产出同样的节点/边（`GraphNode.id` 用 `{kind}:{ref_id}` 而非 uuid，正是为此）。
3. **不因图谱缺失阻断主流程**：图谱读取失败 → 返回空图 + 告警，不影响成果库/脚本库使用。
4. **Manual > Rule/Ai**：人工校正的边不被自动抽取覆盖（重建时保留 `source=Manual` 的边）。

### 4.3 存储方案（首期 SQLite 邻接表）

```sql
-- 应用自身的图库：app_data_dir()/mvp-browser-os/graph.db
CREATE TABLE IF NOT EXISTS graph_nodes (
  id          TEXT PRIMARY KEY,          -- '{kind}:{ref_id}'
  kind        TEXT NOT NULL,
  ref_id      TEXT NOT NULL,
  label       TEXT NOT NULL,
  props       TEXT NOT NULL DEFAULT '{}', -- JSON
  source_kind TEXT NOT NULL,              -- 'rule' | 'ai' | 'manual'
  source_meta TEXT NOT NULL DEFAULT '{}', -- JSON: {rule_id} 或 {model,confidence}
  created_at  TEXT NOT NULL,
  updated_at  TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_nodes_kind ON graph_nodes(kind);
CREATE INDEX IF NOT EXISTS idx_nodes_ref  ON graph_nodes(ref_id);

CREATE TABLE IF NOT EXISTS graph_edges (
  id          TEXT PRIMARY KEY,
  src         TEXT NOT NULL REFERENCES graph_nodes(id) ON DELETE CASCADE,
  dst         TEXT NOT NULL REFERENCES graph_nodes(id) ON DELETE CASCADE,
  relation    TEXT NOT NULL,
  weight      REAL NOT NULL DEFAULT 1.0,
  source_kind TEXT NOT NULL,
  source_meta TEXT NOT NULL DEFAULT '{}',
  created_at  TEXT NOT NULL,
  UNIQUE(src, dst, relation)
);
CREATE INDEX IF NOT EXISTS idx_edges_src ON graph_edges(src);
CREATE INDEX IF NOT EXISTS idx_edges_dst ON graph_edges(dst);
CREATE INDEX IF NOT EXISTS idx_edges_rel ON graph_edges(relation);

-- 元数据（schema 版本 + 上次构建时间）
CREATE TABLE IF NOT EXISTS graph_meta (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
-- 初始： INSERT INTO graph_meta VALUES ('schema_version','1');
```

**关键设计点**：
- `ON DELETE CASCADE` + `UNIQUE(src,dst,relation)`：前者自动清理孤儿边，后者保证重建幂等（`INSERT OR REPLACE`）。
- 若用 `rusqlite`，需在连接时 `PRAGMA foreign_keys = ON`（SQLite **默认关闭**外键，这是经典坑）。
- `schema_version` 为未来迁移留口（与 M4-14.a §5-bis.2 的迁移策略对齐）。

### 4.4 两阶段抽取

| 阶段 | 触发 | 规则 | 标记 |
|---|---|---|---|
| **规则期（首期）** | `graph_build()` 手动触发 / 成果保存后增量 | 纯本地正则/规则，离线，确定性 | `source = Rule { rule_id }` |
| **智能期（后续）** | 用户显式触发（**非自动**） | 调 M5-12.a 的 Agent 做实体识别/关系推断 | `source = Ai { model, confidence }` |
| **人工校正** | 用户在 UI 上增删边 | — | `source = Manual`（优先级最高） |

**首期规则清单（建议）**：

| rule_id | 产出 | 依据 |
|---|---|---|
| `artifact_internal_link` | `Artifact -References-> Artifact` | 解析 `Artifact.html` 中指向其他成果 ID 的链接 |
| `artifact_same_source` | `Artifact -SameSource-> Artifact` | `source_url` 的 host 相同 |
| `artifact_has_image` | `Artifact -HasAttachment-> Image` | `Artifact.images[].id`（依赖 M2-1.a） |
| `artifact_same_repo` | `Artifact -SameRepo-> Repo` | `SyncJob.repo_id` + `artifact_ids` |
| `artifact_similar` | `Artifact -Similar-> Artifact` | `hash` 前缀相同或标题相似度超阈值（阈值待定） |
| `script_referenced_by_task` | `Task -TriggeredBy-> Script` | `TaskDef.target`（依赖 M4-58.a） |

**智能期红线**：Agent 抽取需要调 LLM（出网）→ 必须走确认闸门 + 审计 + keyring（与 M5-12.a 一致），且**结果必须标 `source=ai` 以便人工校正**。

### 4.6 一致性 / 孤儿清理

| 场景 | 处理 |
|---|---|
| 主数据被删（如 `delete_artifact`） | 优先：删除时同步删节点（**但需改 `delete_artifact`，与 M2-1.a §4.5 规则 5 同类**）；兜底：`graph_build()` 时清理 `ref_id` 已不存在的节点，边靠 `ON DELETE CASCADE` |
| 边指向不存在的节点 | 外键 + CASCADE 兜底；构建后校验并记 warning |
| 图谱损坏 / schema 版本不符 | 备份为 `graph.db.corrupt-<ts>`，重建空图 + 告警，**不静默失败** |
| 主数据更新（如成果改标题） | 增量构建按 `updated_at` 更新 `label`；`ref_id` 不变则 `id` 不变 |

## 6. 反向用例

| # | 场景 | 期望 |
|---|---|---|
| N1 | 对同一批主数据连续 `graph_build()` 两次 | 节点/边数量**完全一致**（幂等） |
| N2 | 构建后删除一个 Artifact，再构建 | 该节点消失，相关边消失（无孤儿） |
| N3 | 手工插入 `ref_id` 不存在的节点 | 构建时被清理 + 记 warning |
| N4 | 手工插入指向不存在节点的边 | 被外键/CASCADE 或构建校验清除 |
| N5 | `graph_neighbors(id, depth=3)` 命中全图 | 返回 ≤ 500 节点，标记 `truncated` |
| N6 | `depth=10` | 拒绝或钳制到 3（`DEPTH_EXCEEDED`） |
| N7 | `graph.db` 被手工写坏 | 备份为 `.corrupt-<ts>`，重建空图 + 告警 |
| N8 | schema_version 从 1 升到 2（未来） | 应用迁移流程（与 M4-14.a §5-bis.2 对齐），迁移前自动备份 |
| N9 | 主数据存在但图谱为空 | 所有查询返回空结果 + 提示"请先构建图谱"，不报错 |
| N10 | Agent 抽取（智能期）未确认就执行 | 不执行；确认后写 `source=ai` 的边 |
| N11 | 人工新增一条边后再次 `graph_build()` | 该边**保留**（Manual 优先级最高） |
| N12 | 规则抽取与 AI 抽取产生同一条边（同 src/dst/relation） | 按优先级覆盖：Manual > Ai > Rule；`UNIQUE` 约束保证不重复 |
| N13 | 1000 个成果全量构建 | 完成时间可接受（建议 < 5s），有进度回显 |
| N14 | `graph_export("graphml")` | 首期返回"暂不支持"的明确错误（不是 panic） |
| N15 | 图谱库中 `props` 含恶意 JSON | 反序列化不崩溃；前端渲染转义 |
