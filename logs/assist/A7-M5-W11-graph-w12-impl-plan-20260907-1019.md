## 3. 命令契约（精确签名 + DTO + 稳定错误码）

> **关键架构裁定（修正 W10 §2.5 的含糊）**：3 条命令**定义在 `bridge.rs`**（与全仓其他命令一致），调用 `crate::graph::*` pure helper + `check_invocation_source`（同在 `bridge.rs`）。`graph.rs` **不 import `crate::bridge`**（守 `GRAPH_NO_SECOND_PATH`），仅提供 helper + `GraphState` newtype + `GraphError::code()`。这样既不破坏 `GRAPH_NO_SECOND_PATH`，又满足 source check 同源。

### 3.1 `graph_query`
```rust
// bridge.rs
#[tauri::command]
pub async fn graph_query(
    app: AppHandle,
    webview: tauri::Webview,
    req: GraphQueryRequest,        // { start_id: String, depth: Option<u8>, limit: Option<usize>, request_id: Option<String> }
) -> Result<GraphQueryResult, String> {
    check_invocation_source(&webview, "graph_query", None, &app)?;
    let start = req.start_id.trim();
    if start.is_empty() {
        return Err("GRAPH_INVALID_ID".to_string());
    }
    let state = app.state::<crate::graph::GraphState>();
    let store = state.store.read().unwrap();                 // 纯内存读锁，临界区不跨 await
    let depth = (req.depth.unwrap_or(2) as usize).min(GRAPH_MAX_DEPTH);
    let eff_limit = (req.limit.unwrap_or(GRAPH_QUERY_LIMIT)).min(GRAPH_QUERY_LIMIT);
    let total = store.bounded_neighbors(start, depth, GRAPH_QUERY_LIMIT).len();   // 全局 cap 下的真实总数
    let shown = store.bounded_neighbors(start, depth, eff_limit);
    let ids: BTreeSet<String> = shown.iter().map(|n| n.id.clone()).collect();
    let edges = store.edges.iter()
        .filter(|e| ids.contains(&e.from) && ids.contains(&e.to))
        .map(GraphEdgeView::from)
        .collect();
    let nodes = shown.into_iter().map(GraphNodeView::from).collect();
    drop(store);
    Ok(GraphQueryResult {
        found: total > 0,
        nodes, edges,
        truncated: total > eff_limit,
        applied: GraphQueryLimits { depth, limit: eff_limit },
        node_count: <shown count>,
        edge_count: <edges len>,
    })
}
```
- `found=false`（start 不在 store）返回 `Ok(...found:false, 空 nodes/edges)`，**不报错**。
- `truncated`：当且仅当 `total > eff_limit`（含 `eff_limit` 被 `GRAPH_QUERY_LIMIT` 截断的情形）。
- 复用纯 helper，无 `props` 流出（`GraphNodeView::from` 丢弃 `props`）。

## 5. Cancellation（W12 新增维度，确定性无副作用）
- **前端**：`bridge.graphQuery(req, signal?)` 由 `AbortController` 包裹；新查询发起时 `abort()` 上一个（复用 W6 `searchGraphNodes` 的 300ms debounce + “cancel last query” 范式）；`request_id`（可选入参）作 `AbortController` map 的 key，避免乱序回包。
- **后端**：命令标 `#[tauri::command] async`，但无 mutation / 无 IO / 无子进程；JS 丢弃 Promise 即 Tauri 取消 Future，**零副作用、零残留状态**（读锁在返回前已 `drop`）。
- **取消语义**：命令要么返回完整结果、要么被丢弃；**不产生半截结果、不写审计、不泄露 props**。
- **不引入取消信道开销**：因 bounded 查询瞬时完成，后端**不**需 `tokio` cancel channel；契约仅要求“drop = no-op”。与 W10 硬停 L208（rmcp/tokio 必须 optional+feature-gated、default 构建不变）一致——图谱 live-query **不引入**任何 `tokio`/`rmcp` 依赖。

## 6. Privacy（W12 A4 复审口径对齐，K7 双闸）
- **输出脱敏**：`graph_query`/`graph_node_get` 返回 `GraphNodeView`/`GraphEdgeView`（仅 `{id,kind,label}` / `{from,to,kind}`），**不含 `props`**。`GraphNodeView::from(GraphNode)` / `GraphEdgeView::from(GraphEdge)` 显式丢弃 `props` 字段（编译期保证 View 无 `props` 成员）。
- **错误串零 secret**：所有 `Err` 为 §3.4 稳定 ASCII 码，**绝不** echo `props`/secret/body/路径/capability reason。图谱面无 URL/capability 概念，错误仅为稳定码 → A4 结论 PASS。
- **载入双扫**：`GraphState` 快照经 `GraphStore::from_json` 载入，复用 `GRAPH_PRIVACY_DOUBLE_SCAN`（字段名 + 值模式），命中即拒（`SecretInProps`）。
- **审计/日志**：3 命令**不写**任何含 props/secret 的审计；无 checkpoint 落盘 props。`check_invocation_source` 已挡远程 webview。
- **ACL source check**：3 命令与全仓命令同口径过 `check_invocation_source`（远程页面/伪造 label 一律拒绝）。
