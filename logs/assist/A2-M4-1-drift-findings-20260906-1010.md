## D43 — `database.rs` 重定义 `domain.rs` 冻结常量（M4-1.c §1）

**归属**：A3（`src-tauri/src/database.rs`，M4-2）
**严重度**：中（静默漂移风险；类型不一致）

**现状**：`database.rs:39–59` 重定义 9 个 `DB_*` 常量，与 `domain.rs:1014–1047` 重复，
且超时三常量类型为 `u64`（domain 为 `u32`）。

**修复（A3 在 `database.rs` 顶部）**：
```rust
// 删除 39–59 行的本地 const 块，改为：
use crate::domain::{
    DB_MAX_SQL_BYTES, DB_MAX_ROWS, DB_MAX_RESULT_BYTES, DB_MAX_TEXT_FIELD_BYTES,
    DB_DEFAULT_QUERY_TIMEOUT_SECS, DB_MAX_QUERY_TIMEOUT_SECS, DB_SOFT_TO_HARD_GRACE_SECS,
    DB_CANCEL_CHECK_EVERY_ROWS, DB_MAX_EXPORT_BYTES,
};
// 类型摩擦处显式 cast（domain 为 u32）：
// Duration::from_secs(DB_DEFAULT_QUERY_TIMEOUT_SECS as u64)
```

**A4/A3 待办（固化单源）**：在 `scripts/check-database-policy.py` 增码位
`DB_LIMIT_CONST_REDEFINED` —— 扫 `database*.rs`，若出现 `pub const DB_<NAME>` 且
`<NAME>` 同时存在于 `domain.rs` 的 `DB_*` 集合，即违。可照搬现有 `DATABASE_GOOD` 的
常量块作为坏样本（删去即回归）。

## D44 — 结果 DTO / `DbValue` 双份且 serde 不一致（M4-1.c §2，含活 UI 缺陷）

**归属**：A3（结构）+ A5（`dbUi.ts` / 未来 `src/types.ts` 镜像）
**严重度**：高（二进制单元格在前端已坏）

### D44a — `DbQueryResult` 缺 `limit_hit` / `state`

`database.rs:151` 的 `DbQueryResult` 缺 `domain.rs:1101` 冻结要求的：
```rust
pub limit_hit: Option<DbLimitKind>,   // domain.rs:1069 枚举：Rows/Bytes/Field
pub state: DbQueryState,              // domain.rs:1069 枚举：Completed/Cancelled/Timeout/Failed
```
**修复**：A3 在 `database.rs::DbQueryResult` 补两字段，查询收口时据实填充
（超限置 `limit_hit`；取消/超时/失败置 `state`，正常为 `Completed`）。

### D44b — `DbValue` 枚举名漂移

| 冻结（domain.rs:1085） | 实现（database.rs:123） | 前端 `dbUi.ts:242` 期望 |
|---|---|---|
| `Int(i64)` → `int` | `I64(i64)` → `i64` | `Int` ✅ |
| `Float(f64)` → `float` | `F64(f64)` → `f64` | `Float` ✅ |
| `BlobLen(u64)` → `blob_len` | `Binary { bytes }` → `binary` | `BlobLen` ✅ |

**修复**：A3 将 `database::DbValue` 改为与 `domain::DbValue` 完全一致
（枚举变体 `Null/Bool/Int/Float/Text/BlobLen(u64)`，serde `rename_all="snake_case"`）。
TS 镜像（`src/types.ts`、A5）按 domain 书写即可，无需为 `database.rs` 现状另写一套。

### D44c — 活 UI 缺陷（当前已坏）

`src/utils/dbUi.ts:242–262` `decodeDbValue` 按契约解码 `Int`/`Float`/`BlobLen`；
后端实际发 `i64`/`f64`/`binary` → 分支全失配，二进制单元格落入 `JSON.stringify` 兜底。
**A3 修完 D44b 后此缺陷自动消失**（无需改 `dbUi.ts`，它本来就是对的）。
