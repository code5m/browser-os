## 5. 对 A9 / A6 的落地约束（把裁决讲清楚）

1. **插件 manifest 生命周期只做元数据与状态**：`install/enable/disable/list/get` + 可信密钥数据管理；
   **不得**引入 `plugin_invoke` 等执行类命令（触发 `AGSK_PLUGIN_CMD_NOT_EXEC`）。
2. **能力白名单保持 fail-closed**：`PLUGIN_CAPABILITY_V1` 在未裁决前维持空集合；
   **不得**登记 `agent.*` / `skill.*` / `tool.invoke` 一类执行能力（触发 `AGSK_PLUGIN_MANIFEST_AGENT_CAP`）。
3. **插件 UI 只给生命周期可供性**：「安装 / 启用 / 禁用 / 卸载 / 查看」可以；
   「运行 / 执行 / 调用」按钮与 `skillRun` / `agentChat` 引用不可以（触发 `AGSK_PLUGIN_UI_EXEC_AFFORDANCE`）。
4. 若确需开放插件执行（Stage-II 话题），**先经 A0 裁决**，再把对应码位从 PENDING 转 ACTIVE 并补齐
   ACL / source check / 审计脱敏四件套——不得先上线后补门禁（`AGSK_EXEC_LOCKED` 同款防窗口期设计）。
