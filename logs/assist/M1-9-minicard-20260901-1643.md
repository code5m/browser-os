# M1-9 强模型最小输入卡（≤80 行）

> 来源：M1-9-assist-20260901-1631.md。仅给 AI:DEEP/R:high，本卡不实现、不签 PASS。

## 目标
浏览器会话保存/删除 + 关闭 flush（退出/关 tab 时落盘）+ 最小预览（文本非图片）+ 生命周期接入 ShutdownCoordinator。

## 必改文件
- `src-tauri/src/domain.rs`：新增 `BrowserSession{id,url,title,preview,saved,created_at,updated_at}`。
- `src-tauri/src/bridge.rs`：`tab_new` 建 session；新增 `save_session`/`delete_session`；`coordinator.register("flush-sessions", ...)`。
- `data_dir/sessions.json`：持久化（仿 `bookmarks.json` 原子落盘 tempfile+rename）。
- `src/components/browser/BrowserHost.vue`：会话卡片显示 title+preview；"保存此会话"按钮。

## 禁止事项
- 不存图片二进制预览（仅 `preview: Option<String>`，首段文本 ≤ `MAX_PREVIEW_BYTES=512`）。
- 不新建退出线程（flush 须同步在 `ExitRequested` 前由 `ShutdownCoordinator` 调）。
- 不与 M1-3 书签混淆（`saved` 会话 ≠ 书签，UI 分开展示）。
- 不移动 `NEXT`。

## 实现要点
1. 模型：`TabInfo` 1:1 `BrowserSession`；`tab_new` 建（`saved=false`），用户显式保存置 `true`。
2. flush：退出/关 tab → `coordinator.register("flush-sessions")` 遍历内存 tabs 写 `updated_at`+`preview` 后原子落盘。
3. 最小预览：取 `<title>`+`document.body.innerText.slice(0,200)`，经 `report_resources` 扩展拿；超 `MAX_PREVIEW_BYTES` 截断。
4. 恢复：启动 `setup` 读 `sessions.json`，非 `saved` 临时会话建议保留 1 天；`tab_new` 恢复时若 tab 已存在跳过（R4 防重入）。
5. 删除：从 `sessions.json` 移除 + kill 对应活跃 tab。

## 验收命令
```
cargo build --release
npm run build
bash scripts/pre-merge.sh                  # ALL_PASS
# 手动：保存会话→sessions.json 含 saved=true；正常退出→updated_at 更新；重启可恢复
```

## 反向用例
- 退出竞态：flush 在 `ExitRequested` 前完成，无残留 tab 进程（R1）。
- 预览膨胀：单预览 >512B 截断，无图片（R2）。
- 重入：恢复时已存在 tab 跳过，不重复（R4）。
- 删除活跃会话：tab 被 kill + 项消失。

## 失败动作
- flush 丢数据 → 确认注册进 `ShutdownCoordinator` 且同步执行，非新线程。
- 预览过大 → 调 `MAX_PREVIEW_BYTES` 截断逻辑。
- 恢复重复 tab → 补 `tab_new` 存在性检查后重测 R4。
