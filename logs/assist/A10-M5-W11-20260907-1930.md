## 5. 红线快答（board 标准五问，A10 视角）

1. **是否出现监听/网络？** 否。`mcp_server.rs` 全文件仅 `std::io`（行 26：`use std::io::{self, BufRead, Read, Write}`）；`Cargo.toml` 无 `rmcp`/`tokio`；`MCP_SERVER_GATED` / `MCP_NO_RMCP_SERVER` 双 PASS。
2. **是否回显 raw 参数/凭据？** 否（**双重守门**）。(a) `arguments` 字段在代码层面完全不入响应（`name` 走 `match` 键，`params.arguments` 永不参与）；(b) 单元测试 `arguments_are_never_echoed_in_fail_closed` 显式断言 `SECRET_TOKEN_DO_NOT_ECHO_xyz` 不出现；(c) 静态策略 `MCP_STDIO_NO_ARG_ECHO`（A10 W11 新增）扫描 `to_string(&params)` / `to_string(&arguments)` / `format!("...{params}...")` / `println(... params)` 四类回显形态，self-test 检出对应坏样本。
3. **是否出现 side-effecting 工具？** 否。bound 工具只读（`mcp_policy_get`/`mcp_registry_list` 仅返回 `serde_json::to_string` 序列化结果）；其余 `match` 末臂 fail-closed 且明示 no execution；全仓 `mcp*.rs` 无 `script_runner`/`db_*`/`fs::write`/`spawn`/`Command::new` 执行路径。
4. **默认依赖是否被污染？** 否。`mcp = []` 零附加依赖（`Cargo.toml:23`），`#![cfg(feature="mcp")]` 自门控（`mcp_server.rs:1`），默认 `cargo build` 零变化。
5. **策略是否弱化？** 否。check-mcp-policy.py 自测/默认/当前相位三模式全 PASS，**10 个 ACTIVE 码位零命中**（含 A10 W11 新增 `MCP_STDIO_NO_ARG_ECHO`），无 PENDING 债；A3 / A10 自身均按 W11 派发**只增**策略守门（`MCP_STDIO_NO_ARG_ECHO` 收紧 W11 Hard Stop #3）、未删未改任何既有码位。
