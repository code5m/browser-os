## 一、关键事实：到达 UI 的数据已脱敏（这是本轮最有价值的结论）

核查冻结契约（`types.ts:990-1038`、`domain.rs:2311-2411`、`bridge.ts:721-739`）：

| 到达前端的 DTO | 字段 | 已剔除 |
|---|---|---|
| `PluginSummary` | id/version/display_name/state/capability_count/hash_prefix/updated_at | 签名原文、资源路径、metadata |
| `PluginDetail` | 上述 + description/min_app_version/capabilities/signature/installed_at/resource | **无 `metadata` 字段** |
| `PluginSignatureView` | algorithm/key_id/status | **无 `value` 原文** |
| `PluginResourceMeta` | declared_hash/path_provided(bool)/verified(bool) | **无资源路径字符串** |
| `TrustedKeyRecord` | key_id/fingerprint(16hex)/note/added_at | **无 pubkey 原文** |

- 后端出错只经 `plugin::error_code` 收口为稳定码（`PLUGIN_MANIFEST_INVALID` 等），`plugin_install`/`plugin_set_state` 只 `Err(code.to_string())` —— **错误正文不出进程**（A4 W13 已确认）。
- 资源路径只取布尔 `path_provided` / `verified`，不落盘、不出口。

⇒ 只要 A6 **只用冻结的 `bridge.ts` 方法 + 冻结 TS 类型**，渲染面天然不碰密钥/签名/路径/metadata。

## 二、A6 必须守住的 4 条红线（已编码进 `scripts/check-plugin-ui-privacy.py`，gated）

> 红线之所以必要：即使 DTO 已脱敏，A6 仍可能（a）裸 `invoke` 绕过类型取到原始清单/密钥；（b）自行硬编码或错误 typing 渲染禁止字段；（c）把持有中的完整 manifest（含 metadata + signature.value）写入浏览器存储；（d）把原始错误体渲染出来。

| 码位 | 红线 | 触发示例 |
|---|---|---|
| `PLUGIN_UI_NO_RAW_INVOKE`（ACTIVE） | 只经 `bridge.pluginX`，禁止裸 `invoke("plugin_*")` / 直 import `@tauri-apps/api/tauri` | `invoke("plugin_list", …)` |
| `PLUGIN_UI_NO_SECRET_RENDER`（ACTIVE） | 只渲染红脱敏 DTO 字段 | `{{ plugin.signature.value }}`、`{{ detail.pubkey }}`、`resource_path` |
| `PLUGIN_UI_NO_BROWSER_STORAGE`（PENDING） | 插件记录/密钥/清单原文不得落 localStorage/sessionStorage/indexedDB | `localStorage.setItem("plugin:"+id, …)` |
| `PLUGIN_UI_ERROR_CODE_ONLY`（PENDING） | 错误渲染只用稳定码，禁止 `err.message` / `String(err)` / `err.toString()` | `{{ err.message }}` |

**关于 `metadata` 的口径**：安装表单需收集用户自有 `metadata` 输入并传给 `pluginInstall({ manifest })`（允许）；风险在「渲染回显 / 持久化」。故夹具**不**把 `metadata` 列入渲染黑名单（避免误伤用户输入），而由 `PLUGIN_UI_NO_BROWSER_STORAGE` 兜底「不得持久化」；A6 也不得把 `metadata` 回显到详情面板。
