## 4. A7 schema 边界确认（对齐实际 DTO，working tree `domain.rs` L2040-2116）

**`GraphNode`** = `{ id:String, kind:GraphNodeKind, label:String, props:GraphProps }`
- `GraphNodeKind` ∈ {File, Dir, Tab, Script, Skill, Agent, Tag, Topic}
- `id` 稳定派生：`sha256("kind:path")`；Skill/Agent 节点 `sha256("skill:"+SkillDef.id)` / `sha256("agent:"+AgentDef.id)`（须 `GRAPH_NODE_ID_HEX_LEN=64` 位十六进制，AGRAPH-10 完整性）

**`GraphEdge`** = `{ from:String, to:String, kind:GraphEdgeKind, weight:u32, props:GraphProps }`
- `GraphEdgeKind` ∈ {InDir(文件系统归属), References(引用/派生), RelatedTo(语义相关), TaggedWith(标签), Uses(Agent→Skill，引用 A5 `SkillDef.id`), A2aWith(Agent 间 A2A，对应 A4 信封，图谱只存关系边不存消息体), Memorizes(Agent 在 `agent_kv` 有记忆，映射 A4，不存值)}

**容量/脱敏常量（单一真源）**：`GRAPH_MAX_DEPTH=4` · `GRAPH_QUERY_LIMIT=1000` · `GRAPH_MAX_NODES=5000` · `GRAPH_MAX_EDGES=20000` · `GRAPH_LABEL_MAX_BYTES=256` · `GRAPH_PROPS_MAX_BYTES=MAX_TEXT_FIELD_BYTES(64KiB)` · `GRAPH_NODE_ID_HEX_LEN=64`。

**对 A8 纯逻辑设计的关键修正（重要）**：
1. **无 `privacy` 字段**：实际 DTO 不含 privacy/GraphNodeView；`props:GraphProps`(=`BTreeMap<String,String>`) 在后端**已脱敏**（注释明示「不得含凭据/正文/body」）。→ 我 W3 卡 (`A8-M5-graph-ui-W3-card-20260906-1412.md`) 的 `derivePrivacy()` 已**过时**，应删除；脱敏属后端职责，UI 仅负责「不显示 props 正文」(K7)。
2. **容量估算用实际常量**：`estimateCapacity(nodeCount, edgeCount)` 对齐 `GRAPH_MAX_NODES=5000`/`GRAPH_MAX_EDGES=20000`（≠ 此前假设的未知值）；查询深度 ≤ `GRAPH_MAX_DEPTH=4`、单查返回 ≤ `GRAPH_QUERY_LIMIT=1000`。
3. **`elementKind(d)`**：node 含 `id`+`kind`+`label`；edge 含 `from`+`to`；据此判别。
4. **`layoutHint(kind)`**：`InDir` 边暗示树形布局（文件系统）；`A2aWith`/`RelatedTo`/`References` 用力导向；`TaggedWith` 聚类；与官方卡 §4.1「颜色按 kind、大小按 degree」一致。
5. **Agent 消费面板 (b)**：`Uses`/`A2aWith`/`Memorizes` 边直接引用 A5 `SkillDef.id`/A4 `agent_kv` 语义 → 面板可据边类型展示「该 Agent 消费哪些 Skill/记忆」，无需新字段。
