# M1-4 强模型最小输入卡（≤80 行）

> 来源：M1-4-assist-20260901-1145.md。仅给 AI:DEEP/R:high 直接照做，本卡不实现、不签 PASS。

## 目标
默认浏览器接入：用户从系统（xdg-open）点 http/https 链接时，在本应用新开页签；进程冷启动时 URL 不丢；设为默认浏览器须用户显式确认（禁静默）。

## 必改文件
- `src-tauri/src/main.rs`：加 `RunEvent::Opened` 分支 + `PendingOpenUrls: Mutex<Vec<String>>` + emit `app://open-url`；`m0_ready` 命令内 flush 缓存。
- `src/App.vue`：onMounted 监听 `onAppOpenUrl` + `m0Ready()` 后重放；`isHttp()` 校验后 `browser.tabNew`。
- `setup-linux.sh`：新增 `register_default_browser()`（MIME + `update-desktop-database` + `xdg-settings set default-web-browser`），**仅设置页按钮显式触发**。
- `src-tauri/capabilities/*.json`：声明新 IPC/事件权限（不放开隐式授权）。

## 禁止事项
- 不改 `security-policy-v2` / `app.security`。
- 不静默改系统默认浏览器（安装/首启自动改 = 红线）。
- 不 emit 非 http/https scheme（`file:`/`javascript:`/`data:` 拒收 + audit + toast）。
- 不新增 Rust 代码漏 ACL（每个新命令同步改 permissions toml，见 §10 风险）。
- 不移动 `NEXT`。

## 实现要点
1. 冷启动缓存：进程早于前端就绪收到的 URL 进 `PendingOpenUrls`；`m0_ready` 返回时后端 flush（或前端 emit `app://replay-pending`）。
2. 显式注册：`.desktop` 文件名**先实测** `ls /usr/share/applications/*mvp*`，再写 MIME 段；禁止凭猜。
3. 校验：`isHttp(url)` 统一前置，非 http(s) 直接 `log_audit`+toast 不导航。
4. 门禁：开工前 `cargo fmt --check` + `bash scripts/pre-merge.sh` 取绿基线（M1-2-fix1 教训）。

## 失败动作
- `.desktop` 文件名不符预期 → 实测后修正 `register_default_browser` 内路径，不猜。
- 冷启动丢 URL → 确认 `PendingOpenUrls` flush 时机在 `m0_ready` 内，非 onMounted 后才注册监听。
- 门禁红 → 先 `cargo fmt` + clippy 修，再提交。
