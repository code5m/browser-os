## 1. ImageRef 字段草案（domain.rs 新增，不破坏现有 Artifact）

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ImageRef {
    pub path: String,            // 相对 workspace_dir 的路径，如 "<id>/images/abc.png"
    pub caption: Option<String>, // 可选说明
    pub mime: String,            // 由扩展名/魔数判定，如 "image/png"
    pub size_bytes: u64,         // 落盘时记录，用于超限拒绝与 UI 展示
    pub width: Option<u32>,      // 可选，前端灯箱用
    pub height: Option<u32>,
}
```

`Artifact` 新增字段（向后兼容，默认空 Vec）：
```rust
pub images: Vec<ImageRef>,
```

## 2. 存储目录建议

```
data_dir/workspace/<artifact_id>/images/<uuid>.<ext>
```
- 每个成果独立子目录，随 `Artifact` 删除一并清理（参考 `workspace.rs` 删除逻辑）。
- 不混放，避免 `load_artifacts` 遍历时误读图片。

---

## 3. MIME 白名单

| 允许 | 扩展名 | 备注 |
|------|--------|------|
| `image/png` | png | 首选 |
| `image/jpeg` | jpg/jpeg | |
| `image/webp` | webp | |
| `image/gif` | gif | 静态首帧，不动图 |
| `image/svg+xml` | svg | **高风险**：须禁用脚本执行（见 R2） |

拒绝：`image/svg+xml` 若带 `<script>` 须拒；其余 MIME 一律 `Err("不支持的图片类型")`。

---

## 4. 大小上限

- 单图硬上限：`IMAGE_MAX_BYTES = 10 * 1024 * 1024`（10MB）。
- 单成果图片总大小软上限：`IMAGE_TOTAL_CAP = 50 * 1024 * 1024`，超则 `Err("图片总量超限")`。
- 超限文件不落盘、不进 `ImageRef`。

---

## 5. 路径策略

1. `path` 仅存相对 `workspace_dir` 的部分，禁止绝对路径 / `..` 逃逸。
2. `save_image` 写入前 `canonicalize` 校验落点在 `workspace_dir/<id>/images/` 内。
3. 文件名用 `uuid`，不沿用原文件名（防路径注入 / 覆盖）。
