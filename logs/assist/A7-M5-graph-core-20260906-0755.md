### 3.1 枚举

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum GraphNodeKind {
    Artifact,   // Artifact.id
    Script,     // ScriptMeta.id
    Command,    // CommandSnippet.id

### 3.4 稳定 id 规则（幂等，禁随机 uuid）

```
id        = "{kind}:{sha256(natural_key)[:16]}"
natural_key:
  artifact  = artifact.id
  script    = script.id
  command   = snippet.id
  bookmark  = bookmark.url
  task      = task.id
  skill     = skill.id
  repo      = repo.id
  tag       = "#" + tag_text
  person    = "@" + handle
  url       = url 归一（去尾斜杠 / scheme 小写）
edge id    = sha256("{src}|{dst}|{relation}")[:16]   # 同关系去重
```

- 重抽/增量依赖稳定 id 做 upsert（同 id → 覆盖 props，追加 source 到 `sources`）。
- 机器可检：`GRAPH_STABLE_ID_UUID`（出现 `Uuid::new_v4` 生成图 id 即违规）。

## 4. 派生索引规则（M5-7 可追溯抽取）

### 4.1 三层触发模型

| 触发 | 机制 | 依赖的 M4 产物 |
|---|---|---|
| 实时增量 | 上游写后发 `GraphEvent`（app 内事件，不经 scheduler） | A4 写路径钩子（图模块自行消费 `graph_event`） |
| 周期校验/重建 | 注册**内部维护任务**（interval≥60s），执行 `graph_rebuild`/`graph_verify`/`graph_prune` | A7 `task_add` + `script_runner`（复用，无第二执行路径） |
| 溯源补采 | `task-runs.json` 历史 → `Task→Script/Artifact` 边 | A7 `TaskRunRecord`（同 `run_id` join `script-runs.json`） |

### 4.2 两阶段抽取

```
上游变更（Artifact/Repo/Script/Task/Skill 落库）→ 发 GraphEvent
  → 阶段一（确定性 rule）：规则/正则抽取 URL/路径/#tag/@person/code-ref/front-matter → upsert 节点/边(source=rule)
  → 阶段二（语义 ai）：仅预留 trait SemanticExtractor，结果标 source=ai 可人工校正；
    触发 LLM 出网必须走 audit + 确认闸门 + Keyring（§7 红线）
```

- 增量消费：读 `graph_event` 未消费行（`seq > last_event_seq`），逐条 upsert，更新 `graph_meta.last_event_seq`。**失败幂等**：同 seq 可重放。

### 4.3 抽取来源映射（首期 rule 阶段覆盖）

| 上游对象 | 产出节点 | 产出边 |
|---|---|---|

## 5. 存储与重建/导出/查询契约（M5-8 图存储与查询 · 权威）

### 5.1 存储位置决策（G-D1 · A7 裁定 = A）

**裁定**：独立 SQLite 文件 `data_dir/graph/graph.db`，由 M5 `graph.rs` 模块直接 `rusqlite::Connection::open` 打开；**不经 `DbPool`、不经 `DbConnectionConfig`、不经 Keyring**。

理由：图是 app 自有派生数据，无凭据、无需用户连接体系；但取数限流/取消**必须**与 A3 同源（G-D2），避免口径漂移。A9 草案建议一致，本卡升为裁定，交 A0 在 M5 实施波确认。

### 5.2 DDL（挂同一 SQLite 实例，独立迁移文件 `src-tauri/src/graph/migrations/0001_graph.sql`）

> 全部以 `ref_id` 回指既有领域对象；外键由**应用层**而非 DB 保证（既有 `ScriptMeta` 等无对应父表在此库）。

```sql
CREATE TABLE graph_node (
  id         TEXT PRIMARY KEY,
  kind       TEXT NOT NULL,
  ref_id     TEXT,
  label      TEXT NOT NULL,
  props      TEXT NOT NULL,
  sources    TEXT NOT NULL DEFAULT '[]',
  degree     INTEGER NOT NULL DEFAULT 0,
  updated_at TEXT NOT NULL
);
CREATE INDEX idx_node_kind ON graph_node(kind);
CREATE INDEX idx_node_ref  ON graph_node(ref_id);

CREATE TABLE graph_edge (
  id         TEXT PRIMARY KEY,
  src        TEXT NOT NULL REFERENCES graph_node(id) ON DELETE CASCADE,
  dst        TEXT NOT NULL REFERENCES graph_node(id) ON DELETE CASCADE,
  relation   TEXT NOT NULL,
  weight     REAL NOT NULL DEFAULT 1.0,
  source     TEXT NOT NULL,
  created_at TEXT NOT NULL
);
CREATE INDEX idx_edge_src ON graph_edge(src);
CREATE INDEX idx_edge_dst ON graph_edge(dst);
CREATE INDEX idx_edge_rel ON graph_edge(relation, src);

CREATE TABLE graph_event (
  seq       INTEGER PRIMARY KEY AUTOINCREMENT,
  kind      TEXT NOT NULL,   -- node_upsert|edge_upsert|node_delete|edge_delete
  payload   TEXT NOT NULL,
  created_at TEXT NOT NULL
);

CREATE TABLE graph_meta (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
-- 初始：schema_version=1；last_event_seq=0
```

### 5.3 重建（rebuild）契约

- 全量：`graph_build` 扫描上游 `scripts.json`/`snippets.json`/`tasks.json`/`repos.json`/`bookmarks.json`/`artifacts` → 重算全图 → `atomic_write` 迁移标记 + 替换。
- 增量：消费 `graph_event` 未消费行（seq > last_event_seq），upsert 后推进游标；**幂等重放**。
- 降级：达 `GRAPH_MAX_NODES`/`GRAPH_MAX_EDGES` 即停 upsert、catalog 标 `degraded`、记 `over_cap`。
- 超长 rebuild 不被下一 tick 顶掉（复用 `scheduler.rs` InFlight 非重叠）。

### 5.4 导出（export）契约

- 格式：GraphML / JSON（二选一，默认 JSON）。
- 内容：仅节点/边/属性；**不含**任何凭据/私密 props（隐私过滤在导出层同样生效）。
- 上限：导出体 ≤ `DB_MAX_EXPORT_BYTES`(16MiB，A3 占位常量) 或 `GRAPH_MAX_*` 派生，超限截断并标 `truncated`。

### 5.5 查询（query）契约

复用 A3 `DbQueryResult` 字段语义，新增图谱专属字段：

```rust
pub struct GraphQuery {
    pub start: Vec<String>,     // 起始节点 id（1..N）
    pub relations: Vec<String>, // 空 = 任意 relation
    pub kinds: Vec<String>,     // 空 = 任意 kind
    pub max_depth: u8,          // 拒绝 > GRAPH_MAX_DEPTH(2)
    pub limit: usize,           // 拒绝 > GRAPH_MAX_QUERY_LIMIT(1000)，默认 200
    pub privacy: String,        // 查询层隐私过滤；Agent 默认 "public"
    pub cancel: QueryCancel,    // 复用 A3 公开取消句柄
}
pub struct GraphQueryResult {
    pub nodes: Vec<GraphNodeView>,
    pub edges: Vec<GraphEdgeView>,
    pub truncated: bool,
    pub field_truncated: bool,
    pub elapsed_ms: u64,
    pub query_id: String,
}
```

**查询硬约束**：
- `max_depth > 2` → 拒绝 `GRAPH_DEPTH_EXCEEDED`（避免 N² 爆炸）。
- `limit > 1000` → 拒绝 `GRAPH_LIMIT_EXCEEDED`。
- 隐私过滤在**查询层**：`privacy` 低于节点 props 最严级别时剔除该节点；Agent 默认 `public`，凭据/私密配置节点永不进入 `public` 结果。
- `truncated` 沿用 M4-1.c §2 语义：超限非错误，但禁止静默截断。

### 5.6 SQLite reuse 细节

## 7. 红线条目（延续 M4 护栏）

1. **无第二执行路径**：图谱抽取/重建只经 `script_runner` 或纯函数，禁 `std::process::Command`/`sh -c`（码 `GRAPH_SECOND_EXEC_PATH`）。
2. **未来 `graph_*` 命令全过 `check_invocation_source`**；远程 webview 一律拒绝（与 `run_command`/`task_*` 同口径）；ACL 新条目插 `list_artifact_images` 之前。
3. **Keyring**：图谱无凭据，不写 `DbConnectionConfig`/Keyring 命名空间（码 `GRAPH_NO_KEYRING_CRED`）。
4. **审计脱敏**：`detail` 仅 `task_id`/`run_id`/`count`/`status`/`reason`/`error_code`；单次 `graph_query` 不记审计（码 `GRAPH_AUDIT_LEAKS`）；仅 `graph_build`/`graph_rebuild`/`graph_prune`/`restricted 越权` 记低频审计。
5. **容量上限**：`GRAPH_MAX_*` 硬约束，超限降级不崩（码 `GRAPH_CAP_EXCEEDED`）。
6. **pre-merge 覆盖**：`check-graph-policy.py` 挂 `pre-merge.sh`（G-D5）。
7. **隐私**：`privacy=public` 永不返回私密配置节点（码 `GRAPH_PRIVACY_BYPASS`）。
