## 1. ScriptMeta 字段草案（domain.rs 新增）

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ScriptMeta {
    pub id: String,
    pub name: String,
    pub category: String,        // 分类（如 "文件"/"网络"/"文本"）
    pub path: String,            // 脚本文件绝对/相对路径（workspace/scripts/<id>）
    pub args: Vec<ScriptArg>,    // 参数化契约（见 §3）
    pub description: Option<String>,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ScriptArg {
    pub key: String,             // 占位符名，如 "DIR"
    pub label: String,           // 表单标签
    pub required: bool,
    pub default: Option<String>,
    pub secret: bool,            // 密码类，UI 用 password 且不回显
}
```

> 与 §4.1 初稿相比：补 `description/created_at/updated_at/ScriptArg` 结构，
> 使 UI 参数弹窗与审计有数据支撑。

## 2. scripts.json 存储格式

```
data_dir/scripts.json = Vec<ScriptMeta>
# 脚本正文存独立文件，避免 JSON 内嵌大文本：
data_dir/scripts/<id>.sh   # 或 .py/.js，按 shebang/扩展名判定解释器
```

- 复用 `repos.json` 的 `load/save` 模式（见 `workspace.rs:75-84`）。
- 删除脚本：从 `scripts.json` 移除 + 删 `<id>` 正文文件。

## 3. 参数占位符契约

- 脚本正文中用 `${ARG_DIR}` / `${ARG_NAME}` 形式占位（key 大写、前缀 `ARG_`）。
- 执行前（M2-4）由后端做**白名单替换**：仅替换 `ScriptMeta.args` 中声明的 key，
  未声明的不替换、且不接受任意 `${...}` 注入。
- **严禁**：字符串拼接 shell 命令（`run_script` 必须走 `std::process::Command`
  arg 数组，绝不用 `sh -c "..."` 拼参）——M2-4 安全边界，本 assist 仅声明不实现。
