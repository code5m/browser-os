### 4.2 面板能力（对齐 M5-9 既定范围）

列表浏览 · 关键字搜索 · 节点详情 · 容量展示（节点/边/度数上限 + 超限提示）· 无障碍（高对比/键盘可达/`aria` 标签）· 子图注入预览（只读，不编辑图谱）。

### 4.3 `graphUi.ts` 纯函数（常量对齐 A7 §3.3 / 类型对齐 A7 §5.5）

- `elementKind(d: unknown): 'node' | 'edge'`（判别）。
- `estimateCapacity(nodeCount, edgeCount, maxDegree): { within: boolean; reason?: string }`（容量估算，对齐 `GRAPH_MAX_NODES/EDGES/DEGREE`）。
- `derivePrivacy(view: GraphNodeView): 'public' | 'masked' | 'hidden'`（待 A7 §5.4 隐私裁定；默认 `masked` 失败闭合）。
- `layoutHint(kind): 'force' | 'tree' | 'radial'`（布局建议）。
- `injectPreview(subgraph): string`（注入预览文本，纯展示）。
- `a11yLabels(d): { role: string; label: string }`（无障碍标签）。

### 4.4 数据契约需求（向 A7 索取，写入本卡待回填）

- DTO：`GraphNodeView{id,label,kind,privacy}`/`GraphEdgeView{id,source,target,label}`/`GraphQuery{...}`/`GraphQueryResult{nodes,edges}`/`GraphStats{nodeCount,edgeCount,maxDegree}`/`GraphExport{format,content}`。
- 常量：`GRAPH_*` 六个（§3.3）。

### 4.5 构建体积计划（IF-2 延续）

`GraphCanvas.vue` 经 `defineAsyncComponent`/`import()` 懒加载；`graphUi.ts` 仅在 `GraphPanel` 内引用。目标：主 chunk 不因此波上升 >2%（基线 197.04 kB 前已超 15% 门禁，本卡承诺零新增回归）。

### 4.6 逻辑测试计划（`check-graph-ui-logic.mjs` 断言清单）

1. 容量估算：节点数 ≤ `GRAPH_MAX_NODES` 且边数 ≤ `GRAPH_MAX_EDGES` 且度数 ≤ `GRAPH_MAX_DEGREE` → `within=true`；任一越界 → `within=false` + `reason`。
2. 隐私派生默认失败闭合：`derivePrivacy` 缺字段/未知 privacy → `masked`。
3. 布局提示：node→`force`、edge→`tree`（或 A7 裁定值）。
4. 注入预览：空子图→空串；非空→非空可读串。
5. 无障碍标签：每个元素返回非空 `role`+`label`。
6. 常量零影子：脚本内嵌 `GRAPH_*` 必须与 `domain.rs` 集中常量相等（防切片后自比退化，对齐 A4 W1 修订 `T-kv-22` 纪律）。
