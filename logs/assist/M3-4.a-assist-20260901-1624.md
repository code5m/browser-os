## 2. 可低风险实现项（E1/E2 草案，供强模型参考）

### E1 临时历史上限
```typescript
// useSystemStore.ts，onTermData 内
const TEMPORARY_HISTORY_LIMIT = 40;
termLines.value.push(d.data);
if (termLines.value.length > TEMPORARY_HISTORY_LIMIT) {
  termLines.value.splice(0, termLines.value.length - TEMPORARY_HISTORY_LIMIT);
}
```
- 仅裁剪渲染缓冲，不落盘、不影响 PTY。
- 验收：连续输出 >40 行后 `termLines.length <= 40`。

### E2 resize 静默窗口
```typescript
// TerminalPane.vue ResizeObserver 回调
const QUIET_MS = 120;
let quietTimer: number | null = null;
resizeObserver = new ResizeObserver(() => {
  if (quietTimer) clearTimeout(quietTimer);
  quietTimer = window.setTimeout(() => { /* 触发 termResize */ }, QUIET_MS);
});
```
- 防抖避免 resize 风暴刷屏；不改 PTY、不改 kill。
- 验收：拖动窗口时输出无抖动重渲；`termResize` 调用频率受控。
