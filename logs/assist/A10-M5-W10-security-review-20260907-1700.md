## 5. A10 终审 BLOCK/PASS 闸（A3 交付后套用）

> 核心原则：W10 允许「feature-gated 的只读 MCP stdio 骨架」，但**任何以下违例 = 立即 BLOCK**，交 A0 决策。

- **GATE-A（feature 隔离 / default 无污染）**：`cargo tree --no-default-features | grep -E "rmcp|tokio"` 必须**空**；默认 `cargo build`/`cargo test` 不得编译 `mcp_server` bin；`[[bin]] mcp_server` 必须含 `required-features = ["mcp-server"]`；`rmcp`/`tokio` 在 Cargo.toml 必须 `optional = true`，**不得进 `default` features**。→ 防默认依赖污染（W10 L208）。
- **GATE-B（stdio-only / 无 listener）**：`src-tauri/src/bin/mcp_server.rs` 及 `mcp_tools/**` 全文 grep `TcpListener|TcpStream|tokio::net|axum|hyper::Server|std::net::Tcp|UdpSocket` **必须空**（除注释）。传输仅 stdin/stdout（stdio JSON-RPC）。→ 防网络监听（W10 L207）。
- **GATE-C（零工具副作用 / 只读）**：`mcp_server.rs`/`mcp_tools/**` 不得含 `std::process::Command`/`tokio::process`/`Command::new` 直接派生子进程、不得 `fs::write`/`sqlx`/`rusqlite` 写、`script_runner`/`SkillExec` 调用、模型调用。仅复用 `mcp.rs` 只读 API。→ 防副作用执行（W10 L206/L207）。
- **GATE-D（策略翻转正确 = 最关键）**：A3 必须**先翻转** `check-mcp-policy.py`：`MCP_NO_RMCP_SERVER`(forbidden, 全文 grep) → `MCP_SERVER_GATED`(ACTIVE)，且：
  - 允许 `rmcp`/`tokio` **仅当** 出现在 `optional=true` + `required-features` gate 上下文（gated 源码/依赖）；
  - **保留** default 依赖泄漏自检：若 `rmcp`/`tokio` 出现在非 gated 的 `[dependencies]` 或普通源码（无 `#[cfg(feature="mcp-server")]`），仍 FAIL；
  - self-test 须增**坏样本**（default [dependencies] 引入 rmcp 即 FAIL）+ **好样本**（optional+required-features gated 通过）。
  - 若 A3 擅自**直接删除** `MCP_NO_RMCP_SERVER` 而不保 default 泄漏自检 → A10 **BLOCK**（默认泄漏无人守）。
  - 若 A3 **未翻转** 策略即加 gated rmcp → 现有全文 grep 会把合法 gated 代码判违规，A3 提交会被 pre-merge 拦；A10 亦 BLOCK 并指其补齐翻转。
- **GATE-E（脱敏 / 无 secret echo）**：`mcp_server.rs` 全文 0 `log_audit`/`println!`/`eprintln!`/`info!`/`warn!`/`error!`（错误仅走 stdout JSON-RPC）；error 对象 schema 有界（`serde` 限定字段），`e.to_string()`/Display 不得裸回显 secret（CredentialLeak 已 `<redacted>`、Graph SecretInProps 固定分类）；`returns_url=true` 的 tool 必经 `redact_mcp_url`；capability reason（若有）不得含 system prompt/token/cookie/Authorization。→ 与 A4 §4-A~C 一致。
- **GATE-F（不加新 Tauri 命令 / source-check+ACL 同步）**：A3 W10 复用既有 `mcp.rs` 只读桥（mcp_policy_get/registry_list/capability_preview），**不得新增 `tauri::command` 函数**于 prep（stdio bin 非 Tauri 命令，不进 ACL）。若 A3 将来加新 Tauri 命令须 source-check+ACL+bridge/types+policy/tests 原子（W10 L209）。
- **GATE-G（core/bin 边界 / 无第二执行路径）**：`mcp_server.rs` 不调用 `bridge::*`、不引 tauri 进 core、不新建 script/db/plugin 执行通道（A2 主审边界，A10 交叉确认）。
- **GATE-H（build metrics / warnings）**：A11 主审（≤22%、warnings 不增）；A10 提示 A3 feature 若增 cargo warning 须清理。
