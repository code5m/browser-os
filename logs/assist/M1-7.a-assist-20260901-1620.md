## 1. Git UI 信息架构（建议）

```
repo 视图（mainView==='repo'）
├── RepoPanel（已有，配置态）：选择仓库、配 remote/branch/token
└── RepoReadonlyPanel（新增，M1-7 只读态，mock 期先空壳）
    ├── BranchBar       : 当前分支 + 分支切换下拉（只读枚举）
    ├── StatusList      : git_status 文件列表（modified/added/deleted/untracked）
    ├── DiffViewer      : 选中文件的 diff（缩放/折叠/截断提示）
    └── SyncButton      : 沿用现有 requestSync（写操作，非本次 mock 范围）
```

> 视图切换：`RepoPanel` 顶部加 Tab「配置 / 状态」，状态 Tab 渲染 `RepoReadonlyPanel`。
> 挂点不变（仍 `repo` 视图），无需新 `mainView` 值。

## 4. 交互流程（mock 版）

1. 用户在 `RepoPanel` 选仓库 → 设 `activeRepoId`。
2. 切「状态」Tab → `RepoReadonlyPanel` 渲染。
3. mock 期直接读 `MOCK_*` 常量；真实期调 `bridge.git_status(activeRepoId)` 等（M1-5.a 交付后接）。
4. 点 `StatusList` 某项 → `DiffViewer` 显示该文件 diff。
5. 点分支下拉 → 仅展示（切换为写操作，不在 M1-7.a 范围）。
