## 一、落地改动（仅追加 / 低风险）

1. `src-tauri/src/snippets.rs`：
   - 新增 `BUILTIN_SNIPPET_ID_PREFIX = "builtin:"` 常量。
   - 新增 `builtin_snippets() -> Vec<CommandSnippet>`：五类（system/network/disk/process/text）共 **15 条只读诊断命令**（`uname -a`/`uptime`/`hostname`/`ss -tulnp`/`ip addr show`/`ping -c 4 8.8.8.8`/`df -h`/`du -sh .`/`ls -la`/`ps aux`/`free -h`/`top -b -n 1`/`grep -rn {PATTERN} .`/`wc -l {FILE}`/`cat {FILE}`），全部 `builtin=true`、`dangerous=false`（只读）、`argv[0]` 字面量、无 shell 拼接；含占位符的内置（PATTERN/FILE）为整元素占位且 `params` 有对应项。
   - 新增 `merge_builtin_snippets(user)`：内置恒在 + 用户片段保留；用户误用 `builtin:` 前缀者丢弃（防命名空间污染）。**不写 `snippets.json`**（幂等、不被用户改动污染）。
   - 新增单测 `m2_6_e_builtin_snippets_present_readonly_and_merge_safe`：15 条存在、五类全覆盖、`builtin`/`dangerous=false`/`argv[0]` 非占位符/非 shell 解释器、合并不覆盖用户、误用前缀被丢弃。

2. `src-tauri/src/bridge.rs`：
   - `snippet_list` 改为 `merge_builtin_snippets(workspace::load_snippets(&app))`，首次打开命令库即见内置种子。
   - `snippet_update` 增加 `id.starts_with(BUILTIN_SNIPPET_ID_PREFIX)` 早拒（内置不可经用户接口修改）。

3. **未改动**：`validate_snippet` 契约字段、`snippets.json` 落盘格式、前端、`package*.json`、`default-commands.toml`、capabilities。

## 二、踩坑（已就地修复，供后续夹具编写避坑）

- `check-command-domain-policy.py` 扫描 `snippets.rs` 时把**注释/测试里的字面量 `sh -c`/`bash -c`** 当作真 shell 拼接（`CMD_SHELL_CONCAT_PRESENT`），且用子串 `placeholder_of(&s.argv[0])` 判定「argv[0] 占位拒绝规则存在」。因此：
  - 注释改写避免 `sh -c`/`bash -c` 字面量；
  - 测试改用「`argv[0]` 非 `{...}` 占位符 + 非 shell 解释器名列表」判定，避开 `placeholder_of(&s.argv[0])` 子串；
  - 否则会假阳性误报或导致坏样本漏检（M2-6 夹具 15 坏样本自检失稳）。
- 顶层 `use` 引入仅测试使用的 `SNIPPET_BUILTIN_CATEGORIES` 触发 `unused import` warning（+1），使 build metrics `warnings_increased` 失败；改为在 `#[cfg(test)] mod tests` 内导入。
