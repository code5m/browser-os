## 4. a 卡必须裁决并冻结的分歧

### 4.1 ScriptMeta 字段口径（两套设计二选一或合并）

| 维度 | `M2-3-assist` 版 | `M2-3.a-prework` 版 | a 卡需裁定 |
|---|---|---|---|
| 参数集合字段名 | `args: Vec<ScriptArg>` | `params: Vec<ScriptParam>` | 择一（建议 `params`：与"参数"语义一致，避免与进程 argv 混淆） |
| 参数结构 | `key/label/required/default/secret` | `name/label/param_type/required/default/options/raw` | 是否引入 `ParamType`（String/Int/Bool/Enum/Path）与 `raw` |
| 解释器 | 无（按 shebang/扩展名推断） | `interpreter: String`（bash/sh/python3/node/空=用 shebang） | 是否显式声明（显式更可审计，但需校验白名单） |
| 超时 | 无 | `timeout_secs: u32`（0=用全局默认 300） | 是否纳入 M2-3（字段可先落，语义由 M2-4 实现） |
| 内置标记 | 无 | `builtin: bool`（不可删除） | 是否需要 |
| 启停 | 无 | `enabled: bool` | 是否需要 |
| 时间戳 | `created_at` / `updated_at` | 同 | 一致，可直接冻结 |

### 4.2 存储布局

- assist 版：`data_dir/scripts.json` + `data_dir/scripts/<id>.sh`（正文独立文件，避免 JSON 内嵌大文本）。
- prework 版：另加 `script-runs.json`（运行历史，带上限）。
- **a 卡需裁定**：运行记录（`ScriptRunRecord`）是否在 M2-3 落盘，还是整体推迟到 M2-4
  （建议：结构可在 M2-3 定义，但**不落盘命令**，避免 M2-3 出现无写入者的空存储）。

### 4.3 危险参数规则归属

prework §4.3 给出 9 条 fail-closed 规则（命令替换/链接管道/重定向/通配符/换行/变量注入/
路径穿越/超长/控制字符）。**a 卡需裁定**：这些校验是作为**纯函数在 M2-3 落地并单测**
（b 卡实现、M2-4 直接调用），还是整体推迟到 M2-4。
建议：M2-3 落地纯函数 + 单测（无副作用、可充分覆盖），M2-4 只负责在拼命令行前调用它。

### 4.4 审计与脱敏

- 写入时机：执行前 `script_run_start` / 结束后 `script_run_end`（prework §4.4）。
- 脱敏：参数名命中 `[Pp]ass|[Ss]ecret|[Tt]oken|[Kk]ey|[Aa]pikey` 时值记 `***`。
- **a 卡需裁定**：脱敏是否要求 **M2-3 就在 `ScriptParam` 上提供 `secret: bool` 标记**
  （assist 版有 `secret`、prework 版没有，靠名字正则兜底）——建议两者都保留（显式标记优先，
  名字正则兜底），并冻结"审计只写摘要、不写输出全文（至多 output_tail 前 200 字符）"。

### 4.5 M2-4 边界（本卡**不做**）

执行、取消、超时、输出上限、进程组 kill、并发互斥、运行历史落盘、前端面板（M2-5）——
全部归 M2-4/M2-5。M2-3 只提供：领域模型、参数校验纯函数、工作区持久化、四条元数据命令。
