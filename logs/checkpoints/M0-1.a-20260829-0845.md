- `set -euo pipefail`；根目录 `git rev-parse --show-toplevel` 动态解析，无硬编码路径。
- 模式：`--help` / `--self-test`（fixture，标记非正式证据）/ 正式模式 / 非法参数退出 2。

- clippy 一次结构化命令（`--message-format=json`）覆盖主工程 + path dependency，按 `package_id`
  分组（`mvp-browser-os` / `tauri-plugin-browser-tabs`），按 (lint, 文件, 行, 列) 去重计数；
  不把人类可读 warning 行直接相加。
- 前端 `npm run build`：1 次预热 + N 次正式（`BS_FRONTEND_SAMPLES` 可覆盖，默认 3），记录
  median/min/max 与波动率；统计 dist 总字节、最大 JS 原始/gzip 字节。
- release 构建 `--locked`，记录二进制字节与 SHA-256。
- 生成 `logs/m0-baseline/<run_id>/`：environment.json（source+environment fingerprint）、
  scenario.json、summary.json（机器判定源）、summary.md、raw/、measurements/、commands/、SHA256SUMS。
- 产品 ready/终端钩子未实现时，相关指标（startup/idle/cycle/terminal/orphan）在 summary 中标记
  `BLOCKED`（owner=M0-1.b、解除条件=钩子落地），不计入本检查点 PASS 判定；`--self-test` 有对应断言。
- 证据保留：`.gitignore` 例外使 raw 原始 `.log` 可入库；summary/environment/scenario/measurements/哈希均提交。
