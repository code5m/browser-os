## 本轮最重要的发现：远程权限集名实不符

`src-tauri/permissions/remote-collect.toml` 自述「允许远程浏览窗口调用 collect_selection 与 report_resources」，实际 `commands.allow` 放行了 **6 个**命令：

| 命令 | 副作用 | 风险 |
|------|--------|------|
| `save_note` | 写文件到 notes 目录 | 外部页面静默写盘 |
| `collect_selection` | 写 artifact + 审计 | 外部页面写盘 |
| `request_open_terminal` | 触发打开终端 | 外部页面诱导授予 shell 能力 |
| `report_resources` / `report_title` / `report_grid_load_failed` | 广播事件 | 载荷无边界（内存放大/事件洪水） |

即：**任意外部页面（含被劫持页面）都能写用户文件、请求开终端**。这比 M0-3.a 记录的 SEC-03（残留 `browser` label）严重得多，已登记为 SEC-08 并在本轮收口。

## 收口规则（可验证）

1. **来源校验**：label 必须 ∈ {`main`, `tab-*`, `grid-*`}；`browser` 及任何伪造 label 拒绝。
2. **用户意图**：`main` 的调用本身即用户手势结果，免令牌；来自 `tab-*`/`grid-*` 的**副作用**调用必须出示一次性令牌（30s TTL、作用域绑定、消费即失效、重放拒绝）。
3. **载荷边界**：`report_resources` ≤ 500 条目；`report_title`/文本字段 ≤ 64 KiB；`collect_selection` 的 html ≤ 1 MiB。
4. **SEC-04 残余风险**：远程 URL 全通配是浏览器固有属性，无法收窄，改以上述三项作为补偿控制并在威胁矩阵登记。

## 为什么收紧不影响现有功能（已核查）

- `save_note`、`request_open_terminal`：**零前端调用点**（仅 `bridge.ts` 有封装）。
- `collect_selection`：唯一调用点是主窗口 `ActivityBar` 按钮 → `useWorkspaceStore.collectSelection`，走 `main` 免令牌路径。
