## 2. 图片预览支持边界（如实声明）

| 项 | 边界 |
|---|---|
| 支持格式 | `image/png`、`image/jpeg`、`image/webp`、`image/gif`（MIME 白名单 + magic bytes 双重判定，扩展名由 MIME 反查） |
| 拒绝格式 | `image/svg+xml`（可携带 `<script>`，XSS 面）、BMP（首期不开）、其余 `image/*` 与未知 MIME（fail-closed）、拼接型 MIME（`image/png.html`） |
| 尺寸限制 | 单张 ≤10MB；单成果 ≤50 张 / 50MB；最长边 ≤8000px（防解码 OOM）；>2MB 不得内联（须落盘） |
| 元数据 | 尺寸解析失败为 `None`（**不伪造**，四容器逐一实现；未知变体如实留空）；`bytes`/`sha256` 来自真实字节 |
| 来源 | 仅 `workspace/images/<artifact_id>/`（成果附件）；source_url 落库前脱敏 |
| 不在本卡 | 画廊/灯箱/缩放 UI、字节读取通道（asset:// scope 或后端直读）、`collect.js` 内联通道接入——均属 M2-2 |

## 3. 缓存/容量/生命周期

- **无内存缓存**：图片仅存磁盘（内容寻址 + 原子写），本卡刻意不引入任何原图驻留内存的缓存（满足「不允许原图无界驻留」）。
- **容量有界**：单张 10MB / 单成果 50 张 / 50MB / 8000px，全部**写入前**判定（不留临时文件）；去重按 SHA-256，同图不占双份磁盘。
- **生命周期**：`delete_artifact` 联动 `remove_dir_all(images/<id>)`（canonicalize+前缀校验+拒删根目录），失败不阻断删 JSON 但留 `image.prune_failed` 审计（R5 孤儿防护）。
- **tmp 不积累**：原子写 tmp+rename，rename 失败立即清理 tmp（无启动残留路径依赖）。
- **无新增线程/后台任务**：全部同步 IO，shutdown 路径无需新增清理任务（`close_tab`/flush 路径零改动）。
- **tab/session 边界**：图片与 tab/session 无耦合（成果维度），M1-9 会话恢复不触碰图片，不引入泄漏面。

## 8. 人工验收清单（可复现）
