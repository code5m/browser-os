## 2. 事实复核

- `shell:allow-spawn` 只存在于 `src-tauri/capabilities/default.json` 与生成 schema/历史文档，不存在业务调用点。
- 前端零引用 `@tauri-apps/plugin-shell`，仅 `package.json` / `package-lock.json` 保留依赖。
- Rust 侧仅 `main.rs` 两处 `.plugin(tauri_plugin_shell::init())` 注册，业务执行通道已经走 `std::process::Command` + 白名单解释器 + argv 数组，不经 Tauri shell 插件。
- 后端终端能力使用 `portable_pty::CommandBuilder`，不依赖 Tauri shell 插件；`open` 能力使用 Rust `open` crate，也不依赖 Tauri shell 插件。
