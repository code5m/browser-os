## §0 一页结论

M6 = **有界运行时能力切片（bounded runtime-capability slice）**：M5 把「协议与生态的形状」全部做完并把**执行权**全部锁住，M6 才第一次讨论「开哪一条、开多窄、怎么验收」。

## §2 M6 候选工作流（WBS）

> 每项给出：解锁的运行时权限 / 硬依赖 / 硬停 / 出口标准 / 验证归属。**均为提案，非开工授权。**

### M6-1 · plugin stage-II 有界调用

- **解锁权限**：`plugin_invoke` 由 `Err("not-implemented-in-W6")` 转真实调用；配套 `plugin_cancel`
- **范围约束**：仅本地已安装且已启用插件；仅 manifest 声明的 capability；**无**网络下载、**无**动态加载、**无**文件系统越权；强制超时/取消/审计；DTO 仍脱敏
- **硬依赖**：W13 stage-I 状态机 + key registry；W14 UI 显式确认；M6-2 的执行闸门范式（建议先行）
- **硬停**：不引入插件商店/自动更新；不开放 `storage_*` 之外的持久化；不渲染 stdout/stderr 原文
- **出口标准**：`check-plugin-policy.py` 新增 stage-II 守门码并 PASS；plugin Rust tests 全绿；`check-plugin-ui-logic.mjs` 不掉断言；`pre-merge.sh` ALL_PASS；体积 ≤ 25.2%
- **验证归属**：A9 契约 / A10 安全 / A11 矩阵 / A4 隐私 / A6 UI

### M6-2 · MCP stdio 真实 runtime（只读能力绑定）

- **解锁权限**：把 W11 中 fail-closed 的 `tools/call` 绑定到**本地只读**能力（复用现有只读命令）
- **范围约束**：**仅 stdio**；**无** TCP/HTTP listener、**无**网络绑定、**无**后台 daemon；`rmcp`/`tokio` 仍 optional + required-features gated，默认构建不变
- **硬依赖**：W11 dry-run 硬化；A3 威胁模型与 fail-closed 契约
- **硬停**：不回显 raw arguments / token / cookie / Authorization；不做远程 MCP server
- **出口标准**：`cargo test --features mcp mcp_server` 全绿；`check-mcp-policy.py` PASS；默认构建零新依赖
- **验证归属**：A3 威胁模型 / A4 隐私 / A10 安全 / A11 矩阵
- **A1 排序意见**：**建议首个开工**（骨架已备、权限最窄、无新进程与网络）

### M6-3 · Agent/Skill 执行授权

- **解锁权限**：`agent_run` / `skill_run` 类执行闸门；默认 **fail-closed**
- **范围约束**：用户显式意图 + ACL + 审计三件套齐备才执行；凭据只走 keyring；`ExternalCli` 走 `script_runner` 需先实测
- **硬依赖**：M6-1 的执行闸门范式（超时/取消/审计）；A5 授权设计
- **硬停**：无静默后台执行；无凭据回显；不绕过 M2 既有安全执行通道
- **出口标准**：`check-agent-skill-policy.py` PENDING 转 ACTIVE 的守门码 PASS；执行锁回归不破
- **验证归属**：A5 授权 / A4 隐私 / A10 安全 / A11 矩阵

### M6-4 · graph 受控写与导出

- **解锁权限**：受控写命令 + `graph_export("graphml")`
- **范围约束**：单条/小批量写入 + 审计；导出有界（节点/边上限）；**无**爬虫语义、**无** `source=ai` 自动抽取
- **硬依赖**：A7 写路径威胁模型 + 只读回归计划；W12 只读 3 命令不回归
- **硬停**：不大图（>10k 节点）性能冒险；不做二进制文档解析（pdf/docx）
- **出口标准**：`check-graph-policy.py` PASS；`check-graph-ui-logic.mjs` 113/113 不回退；导出体积/超时有界
- **验证归属**：A7 图 / A10 安全 / A11 矩阵 / A8 手动验收

### M6-5 · 后台 worker（有界队列）

- **解锁权限**：有界后台任务队列 + 取消 + 进程退出收口
- **范围约束**：**非**常驻 daemon；队列长度/并发/超时有界；退出必须 wait（沿用 M4 D25 `on_channel_dead` 教训）
- **硬依赖**：M6-1/M6-3（先有可取消的有界执行，再有后台）；M0 资源闭环红线不破
- **硬停**：无开机自启、无守护进程、无隐藏窗口
- **出口标准**：退出/取消路径有测试；资源闭环复检 PASS
- **验证归属**：A10 安全 / A11 矩阵 / A8 手动验收

### M6-6 · 分发与签名（插件商店 / 第三方签名 / 多版本并存 / 自动更新）

- **解锁权限**：网络分发 + 远程信任根
- **A1 排序意见**：**风险最高、默认不进 M6**；须产品负责人单独书面批准，建议独立为 M7
- **硬依赖**：M6-1 稳定 + 本地信任根运行一段时间 + A10 入口闸
- **硬停**：不默认开放远程签名；不引入自动静默更新

## §3 排序提案（波次与依赖）

### 3.1 依赖顺序（建议）

```
M6-2 (MCP stdio 真实·只读·最窄)
   └─> M6-1 (plugin stage-II 有界调用)
          └─> M6-3 (Agent/Skill 执行授权)
                 └─> M6-5 (后台 worker 有界队列)
M6-4 (graph 受控写/导出)  —— 与 M6-1 并行度低，建议排在 M6-1 之后单独成波
M6-6 (分发/签名)          —— 需 PO 单独批准，默认不排入 M6
```

### 3.2 波次建议

| 波 | 内容 | 新开运行时权限 | 必交付 |
|---|---|---|---|
| **M6-W1** | 契约冻结 + 入口闸（即 W16 本身） | **无**（docs/review only） | A2 边界裁定 / A3 威胁模型 / A4 隐私契约 / A5 授权设计 / A7 图写威胁模型 / A9 契约清单 / A10 入口闸 / A11 验证计划骨架 + **手动 GUI 证据补录计划** |
| **M6-W2** | M6-2 MCP stdio 真实只读绑定 | 1 项：MCP 真实 `tools/call`（仅本地只读） | 策略/测试/证据同包 |
| **M6-W3** | M6-1 plugin stage-II 有界调用 | 1 项：plugin invoke（本地、有界） | 超时/取消/审计 + UI 确认 |
| **M6-W4** | M6-3 Agent/Skill 执行授权 | 1 项：执行闸门（fail-closed） | 授权设计落地 + 执行锁回归 |
| **M6-W5** | M6-5 后台 worker 有界队列 | 1 项：后台执行（非 daemon） | 退出/cancel 测试 + 资源闭环 |
| **M6-W6** | M6-4 graph 受控写与导出 | 1 项：graph 写 + 导出 | 只读回归 + 导出有界 |
| **M6-W7（条件）** | M6-6 分发与签名 | 需 PO 单独批准 | 建议独立为 M7 |

### 3.3 排序原则（A1 建议写进 M6 章程）

1. **一次只开一种运行时权限**（one-authority-per-wave）：跨权限组合必须先分波
2. **默认 fail-closed**：无用户显式意图、无 ACL、无审计 → 不执行
3. **复用既有闸门**：`check_invocation_source` + ACL + redacted DTO/audit + 策略脚本 + UI 只走 `src/bridge.ts`
4. **命令五件套同包**：新命令 = Rust 实现 + ACL + `bridge.ts` + `types.ts` + 策略/测试，缺一不可
5. **体积硬顶 25.2%**：A0 已声明为一次性抬升，M6 任何再增长需 A0 显式决策
6. **证据先于结论**：手动 GUI/运行时证据未补录 → 不得标完成（沿用 W15 的诚实记录口径）
