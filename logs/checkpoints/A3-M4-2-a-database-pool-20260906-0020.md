## 3. 三条硬红线落实

1. **多语句**：SQLite 走 `prepare`（禁 `execute_batch`）+ `detect_multiple_statements` 第二道；第一道归 A4 分类器（M4-1.c §5）。
2. **凭据**：连接参数全类型化构造，无 DSN/连接串拼接；Keyring 键 `db:<conn_id>`（与 git `repo_id` 命名空间隔离）；
   任何出模块错误串一律 `sanitize_message`（截断 512 字符 + `password=/token:` 等整体替换为 `***`）。
3. **不伪造**：MySQL/PG 取数通道与 TLS 一律显式 `DB_NOT_SUPPORTED`（D27 无真实服务端可验证），不留假能力。

## 4. A4 集成边界（稳定内部 API，勿改设计）

- `DbPool::connect(cfg: &DbConnectionConfig, password: Option<&str>, roots: &[PathBuf]) -> Result<DbPool, DbError>`
- `DbPool::query(&mut self, sql, &QueryCancel, timeout_secs: Option<u64>, query_id: &str) -> Result<DbQueryResult, DbError>`
- `DbValue`（JSON `snake_case`：`null`/`bool`/`i64`/`f64`/`text`/`binary{bytes}`）—— **BLOB 只回长度**
- `DbQueryResult { columns, rows, row_count, truncated, field_truncated, elapsed_ms, query_id }`
- `QueryCancel { cancel() / is_cancelled() }`；`DbError { code, message(已脱敏), discard_connection: bool }`
- `DbErrorCode` 18 码（与 `domain.rs` 闭合枚举一致）；`discard_connection` 供 A4 池管理判断「弃连 vs 归还」
- `credential_key(conn_id) -> "db:<conn_id>"`（夹具码位 `DB_CRED_NAMESPACE`）
