## §4 七项冻结契约 — 裁定结论（逐项，无留白）

### 1. 字节通道（冻结：convertFileSrc + asset://，绝对路径经只读命令供给）

- **通道形态**：`imgSrc = convertFileSrc(workspaceImagesDir() + "/" + imageRef.rel_path)`。
  - `convertFileSrc` 来自 `@tauri-apps/api/core`，`AppPanel.vue` 已验证可用。
  - `workspaceImagesDir()` 为**新增无参只读命令**（后端 `fn workspace_images_dir(app: &AppHandle) -> String` 返回 `workspace_dir(app).join("images")` 的 `to_string_lossy()`，不暴露绝对盘符私细节，仅给拼接基准）。
  - `rel_path` 取自 `ImageRef.rel_path`（`domain.rs:67`），由后端白名单拼出（`images.rs:390`），前端**不得**自行推导或硬编码 data_dir / 绝对路径。
- **scope 决策（高风险项，本裁定终局）**：图片目录已落在 `$HOME/.local/share/**` 内，**M2-2.b 严禁修改 `tauri.conf.json` 的 `assetProtocol.scope`**（含 add/remove/reorder）。若 release 冒烟证明 asset:// 实际不可达，按 b 卡 FAIL_ACTION 升级裁决，**禁止擅自扩 scope**。
- **仅 `ImageSource::File` 进预览**：`ImageRef.rel_path` 为 `None` 的 `InlineDataUrl` 类型（仅存于 `Artifact.html`，`domain.rs:54-56`）**不进画廊/灯箱**（属契约第 5 项排除范围），预览组件须按 `rel_path` 是否 `Some` 决定渲染或降级占位。
- 命令契约：`workspace_images_dir` 必须 `check_invocation_source`（同 `list_artifact_images` 范式）、进 `invoke_handler`、`default-commands.toml` ACL，审计仅记 action 名无路径内容。

### 2. 组件归属（冻结：共用组件 + 两挂点）

- 共用预览组件落 `src/components/shared/`：`ImageGallery.vue`（网格/缩略图）、`ImageLightbox.vue`（灯箱/缩放/错误态/空态）。
- **成果库挂点**：`src/components/workspace/ArtifactPanel.vue` 编辑区（`ws.current`）内嵌 `ImageGallery`，点击缩略图经 store/事件打开 `ImageLightbox`。
- **全局灯箱挂点**：`ImageLightbox` 在 `src/App.vue` 顶层挂载（与既有 `SessionCloseDialog` / `GitWriteConfirmDialog` 同「全局 modal-mask」范式，`src/components/shared/ConfirmModal.vue` 为 mask 层级参考），供后续工具箱/会话复用，避免重复实现预览能力。
- 组件内不直接 `invoke`；所有后端调用经 `src/bridge.ts` 封装（`bridge.listArtifactImages` / `bridge.workspaceImagesDir`）。

### 3. 交互契约（冻结，已收敛）

- 关闭：ESC 或点击遮罩关闭灯箱。
- 切换：←/→ 切换上一张/下一张，**不循环**（首张按 ←、末张按 → 索引不变）。
- 缩放：`scale` clamp 至 **[0.25, 4]**，步长 **1.2**；滚轮/按钮增量缩放到边界即停。
- 双击：`scale === 1 ? 2 : 1`（双击复位到 1 或放大到 2）。
- 拖拽平移：仅 `scale > 1` 时启用。
- 单图失败（404/解码失败）：该格显示占位图 + 重试按钮，**不关闭灯箱**。
- 键盘监听：仅灯箱 `open` 时 `addEventListener('keydown')`，关闭/卸载时 `removeEventListener`，防止泄漏（对齐 `IMG_PREV_LISTENER_LEAK` 夹具）。

### 4. 隐私红线（冻结）

- 溯源只展示主机名：复用 `src/utils/image.ts` 的 `imageSourceHost`，**不得把 `source_url` 原文渲染上屏**（禁止 `{{ ...source_url }}` / `:src="...source_url"` / `v-html` 含 source_url）。
- 错误文案统一消费 `IMAGE_ERROR_TEXT` / `imageErrorText` 常量，不暴露内部路径/后端报错细节。
- 组件（除 `bridge.ts` 外）不得直接 `invoke`；新组件/逻辑文件剥离注释后不得含 token/cookie/authorization/password/secret（对齐 `IMG_PREV_CREDENTIAL_TOKEN` 夹具）。
- `list_artifact_images` 已在后端做 `source_url` 二次脱敏（`bridge.rs:2549`），前端为第二道防线。

### 5. InlineDataUrl 消费不在本卡（冻结：排除）

- `injected/collect.js` 内联图片来源接入属于**收集侧**改动：需放宽 `save_image` 来源范围到远程页面 + 意图令牌，并改 `permissions/remote-collect.toml`，属安全边界扩张，**留后续检查点另行裁决**。
- M2-2.b **禁止**：放宽 `save_image` 来源校验（不得删/降级 `bridge.rs:2514` 的 `check_invocation_source`）、改动 `remote-collect.toml`、改动 `injected/collect.js`。
- 后果：M2-2.b 预览只覆盖已落盘的 `File` 型图片；内联图（如网页选区截图未落盘者）暂不可在画廊预览，属已知边界，由后续检查点补。

### 6. 体积与依赖（冻结：零新增）

- **零新 npm 依赖**：`package.json` / `package-lock.json` 不得变化（对齐 `IMG_PREV_NPM_DEP_ADDED` 夹具）。
- 不引入任何 UI 组件库；纯 Vue 3 + 原生 CSS 实现缩放/拖拽。
- 构建体积门禁以 `scripts/measure-build-metrics.py --compare` 为准：总体积涨幅 ≤15%（基线：M2-1 后主 JS 实测 119.29 KB；前草案 505/548 KB 已过时，以实测为准）。

### 7. 测试契约（冻结：纯逻辑层 + headless 断言 + 静态夹具）

- 纯逻辑层 `src/utils/imagePreview.ts`：导出 `clampScale`、`nextIndex`/`prevIndex`（边界不循环）、`scaleForWheel`/`scaleForDoubleClick`、`shouldRenderImage(rel_path)`、`buildAssetSrc(dir, rel_path)` 等**无 DOM 依赖**纯函数，复用 `src/utils/image.ts`。
- headless 断言 `scripts/check-image-preview-logic.mjs`：用 node 直接 import `imagePreview.ts`（经 esbuild/tsx 或等价的纯 JS 转译，不依赖浏览器），覆盖反向用例 **T-prev-1~12**（矩阵见 `logs/checkpoints/M2-2-20260903-1340.md` §5），全过。
- 静态夹具 `scripts/check-image-preview-policy.py`：覆盖违规码 **IMG_PREV_SCOPE_EXPANDED / IMG_PREV_NPM_DEP_ADDED / IMG_PREV_DIRECT_INVOKE / IMG_PREV_RAW_URL_RENDERED / IMG_PREV_LISTENER_LEAK / IMG_PREV_REMOTE_COLLECT_TOUCHED / IMG_PREV_SAVE_IMAGE_WIDENED / IMG_PREV_COLLECT_TOUCHED / IMG_PREV_BRIDGE_WRAP_MISSING / IMG_PREV_ACL_MISSING / IMG_PREV_HANDLER_NOT_REGISTERED / IMG_PREV_CREDENTIAL_TOKEN**（§6 全量），并接入 `scripts/pre-merge.sh`。
- 两脚本均需实现 `--self-test`（好/坏样本自检），门禁接入后 `pre-merge.sh` 须 `ALL_PASS`。
