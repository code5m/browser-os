## 1. 改造前的问题（为什么动这里）

| 问题 | 改造前 | 风险 |
|---|---|---|
| 载入零校验 | `load()` 直接 `return JSON.parse(raw)` 的原始数组 | 缺 `id` / `type` 非法 / `name` 是 number 等脏数据原样进 UI → 渲染崩或显示 `undefined` |
| 无界 | 快捷方式数组无上限，`push` 无封顶 | 脏数据可把首页/存储撑爆 |
| 无最近访问 | 只有 shortcuts | 共享验收 #2 要求的「快捷方式/最近访问」缺一半 |
| 敏感披露 | `HomePanel.vue` 用 `:title="s.target"` 直出目标 | 完整本地路径 / URL query（可能含 token）直接显示，违反共享验收 #4 |
| 错误回显 | `open()` 失败时 `toast("启动失败: " + e.message)` | 原始错误串可能含路径/凭据，违反共享验收 #4 |
| 随机 id | `makeId()` 用 `Math.random()` | 每次载入渲染 key 漂移；脏数据重复 id 无法去重 |

## 2. 交付内容

### 2.1 `src/utils/homeUi.ts`（新增，纯逻辑层，与 `graphUi.ts` 同范式）
无 invoke / DOM / store / Vue 依赖，可被脚本 headless 直测。单一真源：
- 容量常量：`HOME_MAX_SHORTCUTS=24`、`HOME_MAX_RECENTS=12`、`HOME_MAX_NAME_LEN=64`、
  `HOME_MAX_TARGET_LEN=2048`、`HOME_MAX_ICON_LEN=8`、`HOME_DISPLAY_MAX_LEN=48`。
- 类型：`HomeShortcut` / `HomeRecent` / `HomeArea` / `HomeAreaView`（`HomeAreaView` 是 `MainView` 的**子集**，不新增路由）。
- 校验与迁移：`isShortcutType` / `clampText` / `stableId`（确定性 djb2 派生）/ `sanitizeShortcut`
  / `normalizeShortcuts`（校验+去重+id 去重+封顶）/ `normalizeRecents`（+时间倒序）
  / `recentFromShortcut` / `pushRecent` / `boundedPush` / `defaultShortcuts`（稳定默认，内容与改造前一致）。
- 零敏感披露：`looksSensitive` / `homeDisplayTarget`（目录·应用只给**末段名**，URL 只给
  `scheme+host+path`，丢弃 userinfo/query/fragment；非法 URL 回退类型标签）/ `homeAccessibleLabel` / `areaAccessibleLabel`。
- 面板三态：`panelStateHome` → `loading|empty|ready|error`，配 `HOME_EMPTY_MESSAGE` /
  `HOME_RECENTS_EMPTY_MESSAGE` / `HOME_ERROR_FALLBACK`（**错误态绝不回显原始 error**）/ `HOME_LOADING_MESSAGE` /
  `HOME_SHORTCUT_LIMIT_MESSAGE`。
- 主要工作区：`HOME_PRINCIPAL_AREAS`（browser/files/db/repo/term/tasks/skills/agents/graph/plugin，10 项，freeze）。

### 2.2 `src/stores/useHomeStore.ts`（改）

- 新增导出：`recents`、`hasRecents`、`panelState`、`principalAreas`、`openArea(view)`、
  `displayTarget(s)`、`accessibleLabel(s)`、`removeRecent(id)`、`clearRecents()`。
- **既有导出全部保留**（`shortcuts`/`editing`/`has`/`open`/`seedDirShortcuts`/`favoriteCurrentPage`/
  `favoriteCurrentDir`/`startAdd`/`startEdit`/`cancelEdit`/`saveEdit`/`remove`/`resetDefault`），

## 6. 诚实风险

1. **A5 采用风险（最大）**：若 A5 仍直出 `s.target`，完整路径/URL 仍会显示。`homeUi` 已提供
   `homeDisplayTarget`/`homeAccessibleLabel`，但**是否采用取决于 A5**；建议 A9 用
   `scripts/check-home-ui-logic.mjs` 加一条「不得直接渲染 target」断言兜底。
2. **最近访问只记成功路径**：应用启动失败不记录（刻意设计，避免失败项污染列表）；用户可见性依赖 A5 是否渲染 recents 区。
3. **recents 是新增 key**：老用户首次进入 recents 为空（空态文案已备 `HOME_RECENTS_EMPTY_MESSAGE`），属预期。
4. **指标**：本次 dist total 790,073B、`chunk_over_500kb=False`、cargo_warnings=2（既有
   `grid_process.rs`，与基线一致，未增加）。指标是**集成前**单 lane 采值；A0 集成全部 lane 后需复采，
   若超当前预算应停机报出精确 delta，而不是提高上限。
5. **默认快捷方式内容未变**（仍为改造前 6 条外链），仅把真源迁到 `homeUi`；是否调整为工作区优先属产品决策，留在 A1/A5。
