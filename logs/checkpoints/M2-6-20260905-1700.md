### 冻结条款（a 卡必须逐条明确裁定，不得含糊）

| # | 条款 | 展开者倾向（留给实现者裁定，可推翻但须写明理由） |
|---|---|---|
| F1 | **存储形态**：`line: String` 还是 `argv: Vec<String>`？ | **倾向 `argv: Vec<String>`**。理由：字符串行需自实现 shell 词法解析（引号/转义/空格），既易错又逼近 P0 红线；argv 数组天然满足「无拼接、无引号、无 shell 参与」。代价是内置片段需以数组形式录入（可读性略降，可用 DSL 或构建期序列化缓解） |
| F2 | **占位语法** | 倾向**整元素占位**：argv 元素严格等于 `{NAME}` 时整体替换为该参数值（一个元素 ⇄ 一个值）。**不做字符串内插值**（如 `grep -r {PATTERN}`）——避免「一个值被词法切成多个 argv 元素」的注入面。参数名字符集沿用 `ScriptParam.name`（`[A-Za-z0-9_]`，≤32） |
| F3 | **参数模型** | 复用 `ScriptParam`（`name/label/param_type/required/default/options`），**不新增 `ScriptArg`**；`raw` 字段在 argv 模式无效果，命令片段**不得**依赖它 |
| F4 | **`dangerous`** | 倾向**显式字段 `dangerous: bool`**（用户/内置可标），而非仅靠 argv[0] 黑名单推断。理由：黑名单易被绕过（别名、绝对路径、`env` 间接调用）；显式字段 + 内置片段预置更可审计。二次确认在前端（d 卡），字段在 a 卡冻结 |
| F5 | **分类** | `category: String`，与 `ScriptMeta.category` 同口径（保持简单，不用枚举）；内置分类常量取需求 #4 的五类：系统 / 网络 / 磁盘 / 进程 / 文本处理 |
| F6 | **存储与内置** | `data_dir/snippets.json`；内置片段标 `builtin: true`（不可删除，口径同 `ScriptMeta.builtin`）；**无独立正文文件**（与脚本库的关键差异，b 卡不得套用 `body_path_in`） |
| F7 | **审计事件名** | 倾向 **`cmd.*` 与 `script.*` 并列**：`cmd.run.start` / `cmd.validate.reject` / `cmd.run.cancel` / `cmd.crud.*`。detail 口径沿用脱敏约定（id/名称/计数/错误码，无参数值、无命令行明文——**注意：命令行可能含用户参数，须按 `ScriptParam.secret` 脱敏后再记，或直接不记 line**） |
| F8 | **超时口径** | 复用 `ScriptMeta.timeout_secs` 语义：`timeout_secs: u32`，`0` = 全局默认 **60**，上限 **600**（与 M2-4 一致，不新设口径） |
| F9 | **执行入口归属** | a 卡**不裁定**`run_command` 的实现方式，仅冻结「**必须复用 `script_runner` 内核，不得新建进程/输出/取消/落盘链路**」这一红线；具体入口（改造 `start_run` 接受 argv，或新增 `start_command`）留 **c 卡**裁定 |
| F10 | **与脚本库的关系** | 命令片段**不得**被塞进 `scripts.json` / 不得伪装成 `ScriptMeta`（二者存储与执行形态不同）；但二者共享 `script-runs.json` 运行记录与前端执行态组件 |
