## 4. 冻结条款（F1~F12，跨卡通用红线）

| 编号 | 条款 | 机器可检方式 |
|---|---|---|
| **F1** | 数据库**写默认拒绝**（fail-closed）。无显式 `allow_write` 且未二次确认的写一律拒绝；**生产判定不确定 = 按生产处理** | 静态夹具 `DB_WRITE_DEFAULT_DENY` / `DB_PROD_UNCERTAIN_FAILS_CLOSED` + Rust 反向用例 |
| **F2** | 凭据**零落地**：只经 `KeyringStore`；不进日志、审计 detail、前端 state、普通文件、checkpoint。落盘的连接配置**结构性不含 password 字段**（不是「写前清空」，是类型上不存在） | `check-database-policy.py` 的 `DB_CRED_IN_AUDIT` / `DB_CRED_IN_LOG` / `DB_CFG_HAS_PASSWORD_FIELD` + 审计格式串单测 |
| **F3** | 结果必须有**行数上限 + 字节上限 + 超时/取消**；超限返回截断标记，**不静默丢弃、不静默截断** | `DB_RESULT_LIMIT_MISSING` + Rust 单测 |
| **F4** | SQL 风险分类与生产判定是**纯函数**，落 `security_policy.rs`，**零 db 依赖**（保证 A4 可先于 A3 合入） | 夹具扫描 `security_policy.rs` 不得出现 `sqlx`/`rusqlite`/`crate::database` |
| **F5** | 所有新命令：过 `check_invocation_source` + **ACL 插在 `list_artifact_images` 之前** + `main.rs` handler 注册 + 审计。审计 detail 只含 `op/conn_id/task_id/计数/风险等级`，**不含 SQL 正文、参数值、凭据、连接串** | `DB_ACL_ORDER` / `DB_CMD_NOT_REGISTERED` / `DB_AUDIT_LEAKS_SQL` |
| **F6** | 调度**只做触发**：执行唯一入口 `script_runner::start_run` / `start_command`，**禁止第二套进程/spawn 路径**（同 M2-6「不另建执行旁路」口径） | `check-scheduler-policy.py` 的 `SCHED_SECOND_EXEC_PATH`（扫描 `scheduler.rs` 禁 `std::process::Command`/`sh -c`/`bash -c`） |
| **F7** | `stop-scheduler` 注册进 `ShutdownCoordinator`，且其**注册索引必须小于 `kill-running-scripts`**（先停触发，再杀运行中的） | Rust 单测断言注册顺序；`check-lifecycle-contract.py` 扩一条不变量 |
| **F8** | 时钟**可注入**：调度判定逻辑不得直接读 `SystemTime::now()` / `Instant`，须经可替换 `Clock`，否则「错过执行 / 系统时间变化」不可测 | `SCHED_CLOCK_NOT_INJECTABLE`（扫描 `scheduler.rs` 判定函数体内禁用裸时钟 API） |
| **F9** | **同一任务不并发重入**；错过执行策略（skip vs catch-up）须在 M4-5.c 冻结并**落为 `TaskDef` 字段**，不得靠运行时常量 | Rust 单测（同 id 并发触发只执行一次）+ `SCHED_MISSED_POLICY_FIELD` |
