### RISKS（诚实剩余风险）
1. 若 1421 上已有**非 Vite** 的其他服务，`dev-server.sh` 会判定"他人所有"而不启动 Vite，
   客户端将加载错误内容。符合 ownership-safe 契约（不杀他人进程）；若发生，用户应单独管理该端口。
2. `setsid` 缺失时回退为普通后台进程（进程组回收退化为单进程 kill），在主流 Linux 上 setsid 默认存在。
3. dev server 就绪探测用 HTTP GET（2s 超时回退 TCP）；Vite 偶发慢启动由 60s 上限兜住。
4. 未重新构建以复测指标（见 METRICS 说明）；如 A0 集成后要求实测，可在空闲时跑
