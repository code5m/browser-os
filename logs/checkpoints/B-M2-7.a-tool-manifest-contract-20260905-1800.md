## 一、采纳的冻结决策（F1~F9，原样落地）

| 码 | 裁定 | 落地方式 |
|----|------|----------|
| F1 | 工具只描述「清单是什么」，不含任何执行能力 | `ToolMeta` / `ToolSource` 纯数据，`tools.rs` 无 spawn/bridge 写原语 |

| F3 | 用户 `workspace/tools/*.html` 运行时扫描；目录不存在→空数组 | `tools::build_tool_list` 用 `fs::read_dir` 容错，无 `.unwrap()` |

| F5 | 命令名 `list_tools`；ACL 与 `list_artifact_images` 同段允许 | `default-commands.toml` 在 `list_artifact_images` **之前**插入（规避末位逗号坑） |
| F6 | 风险面在 M2-8（Web 隔离），清单层零风险 | `list_tools` 只读、不写审计（对齐 `list_artifacts`/`list_repos` 范式） |
| F7 | 零新增 Rust 依赖 | 仅用 `std::fs` / `include_str!`；`Cargo.toml` 未改 |
| F8 | **不用 `asset` 协议面 / `include_dir!`**；内置走 `include_str!` | `build.rs` 保持极简（`tauri_build::build()`）；`tools.rs` 内 `include_str!` 嵌入 5 份 |
| F9 | 种子：JSON 格式化 / Base64 / 时间戳 / 正则 / Cron（Markdown 预览留待扩展） | 5 个 `*.html` 已落盘 `src-tauri/src/tools/` |

> 关于 F1「用户覆盖内置同名」推荐项：本期 `list_tools` 仅做内置+用户**并集**（用户 id 带 `user-` 前缀，与内置命名空间隔离，天然不碰撞）。同名覆盖的解析语义推迟到 M2-8（前端按 id 打开时处理），避免在本卡引入范围蔓延。

5. `src-tauri/src/tools/*.html`：5 个种子 HTML（其中 `regex-tool.html` 已剥除 3 行 Google Fonts 外链，纯离线）。
6. `scripts/check-tools-policy.py`（**新夹具**）：守护 F1~F9，10 个坏样本变异防呆（含 `TOOL_BUILD_INCLUDE_DIR` 守 `include_dir!` 禁用、`TOOL_EMBED_MISSING` 守 `include_str!` 计数、`TOOL_ACL_ORDER_WRONG` 守末位逗号顺序）。
