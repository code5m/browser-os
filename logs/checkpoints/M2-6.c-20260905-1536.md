## STATUS

PASS（GUI 端到端点击验收仍按 M2 系列口径挂账；后端真实进程启动/输出/落盘已由单测取证）

## 实现范围

- 新增 `run_command(id, values)` Tauri 命令，并完成 handler 与 ACL 同步。
- 命令片段执行复用既有 `script_runner` 内核：同一 `ScriptProcessTable`、同一进程组启动/取消/超时、同一输出 reader、同一 `script-runs.json` 落盘与 `RunSnapshot` 事件模型。
- `CommandSnippet.argv` 按冻结契约作为完整 argv 使用；只支持整元素 `{NAME}` 占位替换，禁止局部插值，禁止 shell 拼接。
- 前端新增 `bridge.runCommand(id, values)` 封装。

## 关键裁定修正

`CommandSnippet.interpreter` 是 M2-6.a 冻结下来的契约字段，但本卡执行期不把它前置为 `bash/sh/python/node` 包裹层；否则会把普通命令片段错误变成脚本解释器参数，并重新接近 shell 包裹风险。实际执行以 `argv[0]` 为程序、其余元素为参数，仍由 `script_runner` 统一走 `std::process::Command` argv 数组。`Shebang` 明确拒绝，因为命令片段没有正文文件与可执行位语义。

## 安全与审计

- `run_command` 过 `check_invocation_source` 与 `check_id`，仅主 webview 可调。
- 不恢复 Tauri shell 插件，不使用 `sh -c` / `bash -c`，不做命令行字符串拼接或自写 shell 词法解析。
- 参数值继续复用 M2-3 的 `check_required`、`validate_param_value`、`validate_enum_value` 与 Path 根目录校验。
- 审计新增 `cmd.run.start` 与 `cmd.validate.reject`，detail 只含 id、run_id、count、dangerous、error_code；不记录 argv、参数名、参数值、命令行、正文或路径列表。
