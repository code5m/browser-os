## 2. 持久化/关闭协议边界（如实声明）

**落盘白名单**（`data_dir/sessions/<id>.json`，原子写 tempfile+rename）：
`id / tab_id / url(已脱敏) / title(≤200B) / preview(已脱敏+≤512B+truncated 标记) / resource_count / resources(脱敏 DTO，最新 ≤50 条) / saved / close_reason / created_at / updated_at`。

**落盘黑名单**（结构上不存在，policy 脚本守）：token / cookie / Authorization / Set-Cookie / 任何 headers / request body / response body / 插件原始资源事件（RawResourceEvent，含未脱敏 URL）/ 任何凭据（Keyring 完全不接触）。

**关闭协议**：
- **tab 关闭**：前端 `tabClose` 统一走 `closeInterceptor` → 弹「保存并关闭 / 删除并关闭 / 取消」（`close_prompt` 默认开，关闭不可静默丢弃）。「保存」= 采集预览（evalInTab，失败回退空串）→ `session_save` 立即落盘 → 关闭；「删除」= `session_discard`（不落盘）→ 关闭；「取消」= 什么都不做。
- **窗口/应用关闭**：ShutdownCoordinator 新增 `flush-sessions` 任务（注册在 `close-tabs` **之前**）→ `flush_sessions_inner`：`auto_save_on_exit` 开时落盘仍打开 tab（`app_shutdown_flush`），否则**仅释放草稿（不静默保存）** + 清理孤儿 .tmp + 容量裁剪 + 审计。前端 `beforeunload` 双保险调 `flush_sessions`。
- **重启恢复**：启动时 prune tmp + 容量裁剪 + 统计日志；`session_list` 回看；`session_restore` 用**已脱敏 URL** 新建页签。
- **异常退出（崩溃/SIGKILL）**：原子写保证无半截 JSON（rename 原子）；未显式保存的草稿随进程消失——**磁盘上只存在用户明确保存过的会话**；下次启动 `prune_tmp_files` 清理残留。

**关键设计决策（与设计文档的偏离及理由）**：
1. **`session_export` 不落盘**（返回脱敏 JSON 文本，前端复制到剪贴板）：避免新增路径写入面（无需 allowed_roots 校验），导出位置由用户决定。
2. **`auto_save_on_exit` 默认关**：默认不静默保存浏览痕迹（隐私优先）；用户可显式开启。
3. **恢复用脱敏 URL**：一次性 token/登录态参数不会恢复，还原页面可能需要重新登录——隐私红线的必然代价，不伪造原 URL。

## 7. 人工验收清单（可复现）

1. `cargo build --release` 启动应用 → 打开任意网页 → 右侧 Dock「💾 会话」。
2. 点「保存当前页签」：列表出现新会话；点开会话可见标题/URL/预览/资源瀑布（URL 中敏感参数为 `***`）。
3. 关闭页签（✕ 或 Ctrl+W）：弹出「保存并关闭 / 删除并关闭 / 取消」；三选一分别验证：保存→列表新增；删除→列表不变；取消→页签保留。
4. 「恢复」：新建页签打开该会话 URL（登录态页面可能需要重新登录，属预期）。
5. 「导出」：剪贴板得到脱敏 JSON（无 token/cookie 明文）。
6. 「删除」：会话从列表消失；`data_dir/sessions/<id>.json` 同步删除。
7. 开启「退出自动保存」后退出应用 → 重启 → 列表出现 `app_shutdown_flush` 会话；关闭该开关退出 → 未保存会话不出现。
8. 检查 `data_dir/audit.json`：会话审计仅 id/tab_id/计数，无任何 URL。
9. 构造崩溃（`kill -9`）后重启：无半截 JSON，`sessions restored` 日志计数正确。
