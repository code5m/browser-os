## 变更明细（仅 3 文件，206 插入 / 21 删除）

### src/components/layout/MainArea.vue
- 为 6 个 `defineAsyncComponent` 懒加载面板（Task/Database/SkillManager/AgentManager/Graph/Plugin）补 `loadingComponent`/`errorComponent`（`panelLoading`/`panelError`，用 `h()` 渲染，**避免运行时模板编译依赖**）+ `delay:80`/`timeout:10000`。
  - 加载中 → `role=status` “面板加载中…”；失败 → `role=alert` “该面板暂时无法显示”。
- `v-if/v-else-if` 链末尾补 `v-else` 兜底分支：当 `layout.mainView` 为空或未知键时，主区渲染“当前视图不可用（<枚举值/空>）…请切换”的 `role=alert` 提示，**杜绝空白/死区主区**。
- 新增 `<style scoped>`：`.panel-state`/`.panel-error`/`.pf-title`/`.pf-desc`（居中、可读、键盘可达、非交互文本）。

### src/components/layout/StatusBar.vue
- 纯展示：本地 `KNOWN_VIEWS` 映射 + `viewLabel`/`viewUnknown` 计算属性（枚举键非路径/URL/凭据，无敏感泄露）。
- 模板：有可读名时显示“当前：<名称>”；未知视图显示 `role=alert` “⚠ 未知视图：<枚举值>”。新增 `.viewchip`/`.viewchip.warn` 样式。

### src/App.vue
- 新增 `onErrorCaptured`：子树渲染抛错时被捕获，仅记录通用提示（不暴露内部错误细节）并切到错误兜底视图，避免整树白屏/死区；返回 `false` 停止向上传播。
- 新增 `ready`/`shellError` 状态 + 启动遮罩（`v-if="!ready && !shellError"`，`role=status` 旋转指示器 + “正在启动…”）与外壳级错误兜底（`v-else-if="shellError"`，`role=alert` “客户端遇到问题 / 界面渲染遇到问题，请重启客户端。”）。正常时 `<template v-else>` 才渲染外壳。
- `onMounted` 体包裹 `try { … } finally { ready.value = true; }`，保证启动遮罩必关闭（即使初始化中途异常）。
- 新增 `<style>`：`.boot-overlay`/`.boot-spinner`/`@keyframes boot-spin`/`.boot-text`/`.shell-error`/`.se-title`/`.se-desc`（fixed 居中、深色背景、高 z-index、纯展示）。
