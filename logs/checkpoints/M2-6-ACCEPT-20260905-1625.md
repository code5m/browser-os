### 新增

**D18｜命令片段 `argv[0]` 未过启动目标白名单（对 `M2-4.a §8.1` 的未申明偏离）**

- 事实：`security_policy::check_launch_target` / `BLOCKED_LAUNCH_PROGRAMS`（`sh/bash/zsh/fish/powershell/cmd`）在全仓**只**被 `bridge.rs:3877` 消费；命令片段路径未调用，故片段可写成 `argv = ["bash","-c","{CMD}"]`，参数值将重新被 shell 词法解释。
- **判为非 BLOCKER 的三条理由**（这是本卡最重要的裁定动作）：
  1. **无新增能力面**：脚本库（M2-5 已 PASS）本就允许用户自写任意 bash 脚本正文并执行，命令片段与脚本库是**同一授信作者模型**——片段作者即本机用户，二者能力等价；
  2. **红线原文针对应用侧拼接**：`M2-4.a §8.1` 禁止的是 `Command::new("sh").arg("-c").arg(format!(...))` 这类**应用侧字符串拼接**。命令片段路径零 `format!`、零重解析，`argv` 原样进 `execve`，红线**目的**未被破坏；
  3. **黑名单形同虚设**：`M2-6.a §7 F4` 已裁定「argv[0] 黑名单易被绕过（别名、绝对路径、`env` 间接调用）」，`/bin/bash` 即可绕过六个名字，补上不等于获得安全边界。
- 未处理的部分**如实记为债务**：该偏离在 a/b/c 三卡 checkpoint 中**均未申明**（c 卡只记了「`interpreter` 不作为包裹层」，未记「`argv[0]` 变成用户输入」对 §8.1 的影响），属**未申明的契约偏离**（与 D15 同类）。
- 后续检查点（与「评估废弃 `ScriptParam.raw`」同级）：裁定**补齐** `check_launch_target` 一致性校验，或**显式豁免**并在 `domain.rs` 契约注释与 UI 文案中写明「片段作者＝授信作者，argv[0] 不校验」。在裁定落地前，不得据此认为 `bash -c` 被防御。

**D19｜需求 #4 的「内置常用命令」未落地种子数据**

- 事实：`SNIPPET_BUILTIN_CATEGORIES`（系统/网络/磁盘/进程/文本）已冻结，但**全仓无任何内置片段种子**（`rg "builtin: true" src-tauri/src` 仅命中 `scripts.rs:943` 测试代码）；`load_snippets_at` 缺文件/损坏时返回**空数组**，用户首次打开命令库为空。
- 判为非 BLOCKER 的理由：M2-6.a §5 与 b 卡范围**均未包含**种子数据（b 卡范围＝持久化 + 四命令 + ACL + 审计 + 夹具转 ACTIVE），以任务卡为验收基准不构成漏交付。
- 影响：需求 #4 范围原文「内置常用命令分类（系统/网络/磁盘/进程/文本处理）」**只交付了分类框架，未交付内置命令本身**；`builtin` 字段与「内置不可删」逻辑已就位但当前无对象可用。
- 后续检查点：**M2-6.e 内置片段种子**（新增，与 M2-7 同级待排期）——按五类预置常用只读命令（`df -h` / `ss -tulnp` / `du -sh` / `ps aux` / `grep -r` 一类），标 `builtin: true` + `dangerous` 逐条标注，落种时机须保证幂等且不覆盖用户自建片段。

- 范围：`snippet_*` 四条 IPC 的端到端点击（b 卡挂账）、`run_command` 面板执行与输出回显、`dangerous` 二次确认、收藏切换（d 卡挂账）。
