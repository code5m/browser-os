## 1. 背景与范围

M2-7 完成了「清单与打包」：`list_tools` 只读枚举、`builtin_tool_html(id)` 编译期嵌入 5 份种子、用户 `workspace/tools` 扫描。M2-8 消费这两样，把工具**打开**给用户：

- 前端 `tools` 模块（工具箱 UI）：列出 `list_tools` 结果，点击即打开。
- 打开方式：Rust `open_tool(id)` 命令创建一个**子 webview 窗口**，URL 指向自定义 `tool://` 协议，协议处理器返回工具 HTML 字节。
- **隔离（核心，R:xhigh）**：工具窗口**不授予任何 bridge 命令能力**——工具是纯离线 HTML，不需要也不能调用任何后端命令；即便用户工具 JS 试图 `invoke(...)` 也被能力层拒绝。

## 3. 设计决策（冻结，实现者须逐条遵循，推翻须写明理由）

| # | 条款 | 裁定 |
|---|---|---|
| F1 | **前端模块注册** | 沿用 M2-6 `commands` 范式：① `useLayoutStore.ts` 的 `MainView` 联合类型增 `"tools"`；② `MOD_META` 增 `tools:{ icon:"🧰", label:"工具箱" }`；③ `ActivityBar.vue` 的「工具」分节（apps/scripts/commands 之后）增 `{ view:"tools", icon:"🧰", label:"工具箱" }`；④ `MainArea.vue` 增 `<div v-else-if="layout.mainView==='tools'" class="modview"><ToolBox/></div>` 并 import；⑤ 新组件 `src/components/workspace/ToolBox.vue`。`onItem` 已对菜单项走 `openModule(v)`（去重复用），无需改 ActivityBar 逻辑 |
| F2 | **打开机制** | `#[tauri::command] open_tool(id: String, app: AppHandle) -> Result<(),String>`：label=`tool-<id>`；已存在该 label 的窗口 → `show()`+`set_focus()`（去重，不重复开）；否则 `WebviewWindowBuilder` 创建，URL=`tool://localhost/<id>`，初始尺寸 900×650、最小 480×360、title 取自工具名（取不到用 id）。非法 id → `Err(String)`（前端 toast） |
| F3 | **加载协议** | 注册自定义 `tool://` 协议（`app.protocol().register("tool", handler)` 于 `main.rs` `.setup`）：① builtin → `builtin_tool_html(id)` 字节，直接 `text/html`；② user → `id` 形如 `user-<文件名>`，取 `<文件名>` 经 `workspace/tools/<文件名>` 读取（见 F5 校验）；③ 未知 id / 读失败 / 越权 → 返回**安全错误页 HTML**（内联、零外链，不泄露绝对路径/系统信息）。响应 `Content-Type: text/html; charset=utf-8` |
| F4 | **隔离（权限最小化，核心）** | 工具窗口**不写入任何 capability 文件**（不新增 `capabilities/tool.json`，也不改 `default.json`）→ 工具 webview 获得**零 bridge 命令权限**：即便用户工具 JS 调 `invoke("run_command",...)` 也被能力层拒绝。`tool://` 协议为 app 级全局注册，无需 per-window 能力。`withGlobalTauri:true` 仅注入 API 全局对象，不授权命令调用 |
| F5 | **用户工具硬依赖 D23 闭环** | 以「自定义协议 + 路径校验」解决 M2-7 的 D23，**不扩展 `assetProtocol.scope`**（守住 M2-7 F8「不引入 asset 协议面」）。读取用户工具前：`id` 必须 `strip_prefix("user-")` 且文件名**不含 `/` `\` 且以 `.html` 结尾**；`target = base.join(file_name)` 后 `canonicalize()` 必须与 `base.canonicalize()` 同前缀（`starts_with`），否则拒绝。防御 `..` 穿越 |
| F6 | **生命周期** | `open_tool` 维护 label 去重（聚焦而非重开）；应用退出时 Tauri 自动关闭全部窗口，无需额外钩子。本期不引入 AppState 工具登记表（如需 reopen/批量关，留 M2-9 或后续） |
| F7 | **错误页与失败兜底** | 协议层对任何异常返回静态错误 HTML（不 panic、不泄露路径/系统信息）；`open_tool` 对非法 id 返回 `Err`。用户目录不存在（M2-7 F3）→ `builtin_tool_html` 仍可用，仅用户工具为空列表 |
| F8 | **零新增依赖** | 仅用 `tauri::http`（随 tauri）、`std::fs`/`std::path`（`canonicalize`/`starts_with` 做校验）、`tauri::Manager`；不引入新 crate |
| F9 | **验收基线（M2-9 用）** | 每个种子离线可开、零外链、零 bridge 写原语；工具窗口无法调用任何桥命令（隔离断言：构造一个用户工具 HTML 调 `invoke('list_tools')` 应被拒） |

## 4. 不可动 / FORBID

- 不得扩展 `assetProtocol.scope` 纳入 `workspace/tools`（守 M2-7 F8）。
- 不得给工具窗口开放任何 bridge 命令能力（守 F4 隔离）。
- 不得让工具 HTML 读取 `workspace/tools` 之外的任意文件（守 F5 越权防御）。
- 不得引入新 Rust/前端依赖（守 F8）。
- 不得修改 `domain.rs` 既有类型；`ToolMeta`/`ToolSource` 已在 M2-7 冻结。
