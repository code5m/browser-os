## 1. F1~F10 逐条裁定（展开卡 §7 冻结条款的最终结论）

| # | 条款 | 裁定 | 理由 |
|---|---|---|---|
| **F1** | 存储形态 | **`argv: Vec<String>`**（不采用 `line: String`） | 字符串行需自实现 shell 词法解析（引号/转义/空格），既易错又逼近 `M2-4.a §8.1` P0 红线（禁止 shell 拼接）。argv 数组天然满足「无拼接、无引号、无 shell 参与」 |
| **F2** | 占位语法 | **整元素占位**：元素严格等于 `{NAME}` 时整体替换为参数值（一个元素 ⇄ 一个值）。**禁止** `grep -r {PATTERN}` 这类字符串内插值 | 部分插值会让一个参数值被词法切成多个 argv 元素，重新开放注入面。需要 `--dir=/x` 时拆成 `["--dir", "{DIR}"]` 两个元素（标准 argv 风格，表达力不损失） |
| **F3** | 参数模型 | 复用 **`ScriptParam`**（`params: Vec<ScriptParam>`），不新增 `ScriptArg` | 复用 M2-3 冻结模型（name/label/param_type/required/default/options/secret），零新增概念；`raw` 字段在 argv 模式无效果，命令片段不依赖它 |
| **F4** | `dangerous` | **显式字段 `dangerous: bool`** | argv[0] 黑名单易被绕过（别名、绝对路径、`env` 间接调用）；显式字段 + 内置片段预置更可审计。确认 UI 归 d 卡，**字段**在本卡冻结 |
| **F5** | 分类 | `category: String`，**不做取值白名单**；内置五类以常量 `SNIPPET_BUILTIN_CATEGORIES = ["system","network","disk","process","text"]` 提供 | 与 `ScriptMeta.category` 同口径（自由字符串）；白名单会阻碍用户自定义片段。常量供内置种子与 UI 分组使用 |
| **F6** | 存储与内置 | `data_dir/snippets.json`；`builtin: bool`；**无 `path` 字段、无独立正文文件** | 命令即 argv 数组，无需落盘正文——这是与脚本库的核心差异（脚本库有 `<id>.sh`）。结构性无 `path` 字段即保证该边界不被抹平 |
| **F7** | 审计事件名 | **`cmd.*` 与 `script.*` 并列**：`cmd.run.start` / `cmd.validate.reject` / `cmd.run.cancel` / `cmd.crud.*`。detail 脱敏，**不含 argv / 参数值**（命令行可能含 secret 参数值） | 沿用 `workspace::log_audit` 与点分命名体系；argv 直接进审计等于把用户输入（可能含凭据）写盘，必须禁止 |
| **F8** | 超时口径 | `timeout_secs: u32`，`0` = 全局默认 **60**，上限 **600**（常量 `SNIPPET_MAX_TIMEOUT_SECS`） | 与 `ScriptMeta.timeout_secs` 完全同口径（`M2-4.a §2`），不新设语义 |
| **F9** | 执行入口 | a 卡**不裁定**实现方式，只冻结红线：**必须复用 `script_runner` 内核，不得新建进程/输出/取消/落盘链路**；具体入口留 **c 卡** | 入口形态取决于 c 卡对 `start_run` 的改造方式（`start_run` 当前入参是**脚本绝对路径**，见 §3）；a 卡越权裁定会锁死实现空间 |
| **F10** | 与脚本库关系 | `CommandSnippet` 是**独立类型**，不是 `ScriptMeta` 别名；不进 `scripts.json`；但共享 `script-runs.json` 运行记录与前端执行态组件 | 二者存储形态（无正文 vs 有正文）与执行入口不同，强行统一会破坏脚本库既有契约 |

## 3. 关键发现（对后续 b/c 卡的交接提示）

1. **`start_run` 入参是脚本绝对路径**（`script_runner.rs:645`：`script_abs_path: &Path`），
   命令片段**没有正文文件** → c 卡不能原样复用 `start_run`，需新增 argv 版入口
   （复用同 `ScriptProcessTable` / supervisor / 输出 reader / 取消 / 落盘逻辑即不违反「不另建旁路」）。
2. **`ScriptInterpreter::Shebang` 对命令片段无意义**（无正文文件可依赖 shebang 与可执行位），
   已在 `CommandSnippet` 文档注释冻结「执行层须显式拒绝」，**c 卡须落实**。
3. **`script.run.finish` 审计仍缺失**（D15 未偿）。若 c 卡为命令片段补 `cmd.run.finish`，
   属新增能力而非偿还 D15（D15 针对脚本），不要混同记账。
4. **ACL 顺序坑**：`snippet_*` / `cmd_*` 必须插在 `list_artifact_images` **之前**
   （`default-commands.toml` 末行无逗号；M2-3、M2-5.c 已踩过两次）——b 卡直接照做。
5. 夹具对 b/c/d 才出现的东西（`snippets.rs` / `snippet_*` / `run_command` / 前端组件）
   采用「**存在才判**」，故本夹具在 b/c/d 落地后仍长期有效，无需改码位。
