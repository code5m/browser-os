## 4. A9 入树后插件管理器 UI 必须满足的不变量（A6 评审契约）

> 一旦 A9 的 `PluginPanel.vue`（及 `bridge.ts`/`types.ts` 插件 DTO）入树，A6 将据以下契约逐条复核。本期将其固化为验收口径。

### 4.1 禁用 invoke 控件（DISABLED INVOKE CONTROLS）
- 后端**无 `plugin_invoke` 命令**（已取证 0 命中）→ 面板**不得渲染**"运行/执行/调用/启动插件"按钮或等价 affordance。
- 仅允许 `Enabled ⇄ Disabled`（生命周期状态切换，非代码执行）与 `Uninstalled`（卸载状态，非运行时销毁）两类开关；其标签须明确为"启用/禁用/卸载"，不得措辞为"运行/启动/执行"。

### 4.2 清晰生命周期状态（CLEAR LIFECYCLE STATUS）
- 必须渲染 8 态（`Discovered/Validating/SignedOk/SignedFailed/Loaded/Enabled/Disabled/Uninstalled`），状态文案来自 `PluginState`，不得自定义暗示运行的语义。
- 状态切换按钮必须以 `can_transition(from,to)` 为唯一真相源：非法迁移（如 `Discovered→Enabled`、`Uninstalled` 复活）须**灰显/禁用**，不得出现可点击但后端会拒的姿态。
- `SignedFailed` 必须展示为终态失败（可 `Uninstalled`/`Discovered`），不得暗示"已可用"。

### 4.3 无伪执行入口（NO FAKE EXECUTION AFFORDANCE）
- 不得出现插件运行日志/控制台/stdout 展示区、进度条暗示运行时启动、或"正在运行"态指示（Stage-I 无运行时）。
- `plugin_install`（若 A9 实现）按 W13 范围**仅为本地 manifest 元数据校验**（无真实磁盘写入、无网络下载）→ UI 文案须标注"元数据校验/本地清单"，**不得**出现"下载/安装中/从商店获取"等暗示网络下载或真实安装的措辞。

### 4.4 能力闸门可见（CAPABILITY GATE SURFACED）
- 安装/启用前须渲染 `permission_preview_for_plugin` 闸门：`Safe`/`Confirm`/`Dangerous`。
- 因 `PLUGIN_CAPABILITY_V1` 首期空集合 fail-closed，**任何**能力声明均被判 `UnknownCapability` 拒绝 → UI 对含能力的插件须展示"能力不在白名单，已阻止"，不得提供可继续的"强制安装/忽略"入口。
- 严禁在 UI 任何位置回显 `key_id`/签名 `value`/原始 `metadata` 之外的凭据或 token。
