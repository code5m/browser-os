## 4. 冻结契约（M2-2.a 冻结，M2-2.b 必须遵守）

1. **字节通道**：`convertFileSrc` + `asset://`；绝对路径 = 新只读命令 `workspace_images_dir()` 返回值 + `/` + `ImageRef.rel_path` 拼接（前端不得硬编码绝对路径、不得自行推导 data_dir）。
   - `workspace_images_dir()`：无参、返回 String；过 `check_invocation_source`；进 `invoke_handler` + `default-commands.toml` ACL；审计仅 action 名无路径内容。
2. **组件归属**：共用预览组件放 `src/components/shared/`（`ImageGallery.vue`、`ImageLightbox.vue`），成果库挂点 `ArtifactPanel.vue` 编辑区（`ws.current`），灯箱全局挂 `App.vue`（与 `SessionCloseDialog`/`GitWriteConfirmDialog` 同模式），供后续工具箱/会话复用（§4.2 「M2 把预览契约抽成共用能力」）。
3. **交互契约**（冻结自 M2-2.b-prework §4.2，已收敛）：ESC/点遮罩关闭；←/→ 不循环；缩放 [0.25, 4] 步长 1.2；双击 `scale===1?2:1` 复位；拖拽平移仅 `scale>1`；单图失败显示占位+重试且**不关闭灯箱**；键盘监听仅 open 时绑定、关闭即解绑。
4. **隐私红线**：溯源只出主机（复用 `src/utils/image.ts` 的 `imageSourceHost`），**不得把 `source_url` 原文渲染上屏**；错误文案只消费 `IMAGE_ERROR_TEXT`/`imageErrorText`；组件（除 `bridge.ts` 外）不得直接 `invoke`。
5. **InlineDataUrl 消费不在本卡**：`injected/collect.js` 的内联图片来源接入属于收集侧改动（需放宽 `save_image` 来源范围到远程页面 + 意图令牌，触及 `remote-collect.toml`，属安全边界扩张），**留后续检查点另行裁决**。b 卡不得放宽 `save_image` 来源、不得改 `remote-collect.toml`、不得改 `collect.js`。
6. **体积与依赖**：零新 npm 依赖（`package.json`/`package-lock.json` 不得变化）；build metrics 总体积涨幅 ≤15%。
7. **测试契约**：`src/utils/imagePreview.ts` 纯逻辑层（缩放 clamp、索引边界、切换/错误态判定，复用 `src/utils/image.ts`）+ `scripts/check-image-preview-logic.mjs`（headless 断言，覆盖 §5 T-prev-1~12）+ `scripts/check-image-preview-policy.py`（静态夹具，违规码见 §6）。
