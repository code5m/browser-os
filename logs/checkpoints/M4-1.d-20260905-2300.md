## 3. 生产判定信号契约（A10 G-5：A2 定契约 / A4 实现）

### 3.1 返回类型（A4 落 `security_policy.rs`，**零 db 依赖**，F4）

```rust
pub enum ProductionVerdict { Production, NonProduction, Unknown }
```

### 3.2 信号集（冻结）

| 编号 | 信号 | 取值 | 归类是 |
|---|---|---|---|
| **S1** | 显式标记 `production_hint` | `Some(true)` / `Some(false)` / `None` | Production / NonProduction / 无信号 |
| **S2** | 名称启发式：`host` 或 `database` 命中词表 `prod\|prd\|production\|live\|online\|生产\|正式` | 命中 / 未命中 | **命中 ⇒ Unknown**（不得单独判 Production） |
| **S2'** | 名称启发式（反向）`test\|dev\|staging\|uat\|local\|demo\|sandbox` | 命中 / 未命中 | **命中 ⇒ NonProduction 候选**（仍需无 S2/S5 命中才生效） |
| **S3** | 拓扑：`host` 解析为回环/私有网段，或 `Sqlite` | 命中 → NonProduction 候选 | NonProduction |
| **S4** | 加密：非回环地址且**实际**未加密（由 M4-2 记录） | 命中 → 升级为 Unknown | Unknown |
| **S5** | 不可判定：库名为空 / 主机不可解析 / 连接建立失败 | 命中 | **Unknown** |

### 3.3 决策规则（fail-closed，顺序即优先级）

1. 任一 **Production** 信号（S1=`Some(true)`）→ `Production`
2. 任一 **Unknown** 触发（S2 命中 / S4 命中 / S5 命中）→ `Unknown`
3. 仅当**全部**信号为 NonProduction 候选（S2' 或 S3 命中）且无 1/2 命中 → `NonProduction`
4. **无任何信号**（`production_hint=None`、名称无命中、SQLite 路径合法）→ `Unknown`（**不是** NonProduction）

> 规则 4 是 G-5 的核心：无信息时**默认按生产处理**（拒绝写），而不是默认放行。

### 3.4 写闸门全链路（任一不满足即 `DB_WRITE_DENIED`）

`ProductionVerdict ∈ {NonProduction}` **且** `allow_write == true` **且** 本次二次确认通过 **且** 分类器判定为允许类别。

### 3.5 测试矩阵（A10 G-5 验收要求，A4 实现）

| 用例 | 输入 | 期望判定 | 写 |
|---|---|---|---|
| 不可解析主机 | `host="db.invalid.example"` | `Unknown` | 拒 |
| 空库名 | `database=""` | `Unknown` | 拒 |
| 仅名称匹配 | `host="prod-01.corp"`、`production_hint=None` | `Unknown` | 拒 |
| 显式非生产标记 | `production_hint=Some(false)` + 回环 + 无 S2 命中 | `NonProduction` | 允许（仍需 `allow_write` + 二次确认） |

## 5. Policy notes：`check-database-policy.py` 码位表（交 **A4** 实现）

> 沿用 A1 §6「一次性定义码位 + pending 集合 + 默认模式只判本卡职责」范式，
> 以及三项通用约定：①`--self-test` 双向（1 好 + N 坏各自命中对应码）；②坏样本**变异防呆**（未真正改动按漏检计）；
> ③`--expect-pending` 与 `PENDING_CODES` 常量双向一致。

| 码位 | 判定方式 | 归属 | 状态 |
|---|---|---|---|
| `DB_CFG_HAS_PASSWORD_FIELD` | 扫 `domain.rs` 中 `DbConnectionConfig` 定义体，命中 `password\|passwd\|pwd\|secret\|token\|dsn\|conn_str` 字段 | M4-1 | **default** |
| `DB_WRITE_DEFAULT_DENY` | `allow_write` 必须带 `#[serde(default)]`，禁止 `default = true` 形态或缺属性 | M4-1 | **default** |
| `DB_JDBC_SIDECAR` | 扫 `Cargo.toml`/`build.rs`/`scripts/`：禁 `jdbc\|jre\|jdk\|maven\|gradle\|ojdbc` | M4-1 | **default** |
| `DB_UNDECLARED_RUNTIME` | 扫 `src-tauri/Cargo.toml` 的 `[dependencies]`：禁 `tokio\|async-std\|sqlx\|diesel`（**不扫 Cargo.lock**——tokio 是 tauri 传递依赖，扫 lock 会误报） | M4-1 | **default** |
| `DB_ERROR_CODE_CLOSED` | 码位表与 `DbErrorCode` 变体集合一致（18 码） | M4-1.d 骨架 | pending → A4 |
| `DB_SQL_PARSE_FAIL_CLOSED` | 分类器不可解析必须拒绝，不得降级放行 | A4 | pending |
| `DB_MULTI_STATEMENT_FORBIDDEN` | 实现侧禁 `execute_batch` / `simple_query` / `batch_execute` 处理用户 SQL | A3 | pending |
| `DB_CRED_NAMESPACE` | Keyring 键必须 `db:` 前缀 | A3 | pending |
| `DB_CRED_IN_AUDIT` | db 审计 detail 禁含 SQL 原文与凭据键 | A3/A4 | pending |
| `DB_RESULT_LIMIT_MISSING` | 结果结构必须有 `truncated` / `field_truncated` | A3 | pending |
| `DB_PERSIST_NOT_ATOMIC` | 连接配置落盘必须 tempfile+rename | A3 | pending |
| `DB_TIMEOUT_NOT_LAYERED` | 必须复用 30/600/5 分层，禁自定义另一套 | A3 | pending |
| `DB_ACL_ORDER` | `db_*` / `task_*` 的 ACL 必须插在 `list_artifact_images` 之前 | A4 | pending |
| `DB_PLATFORM_DEGRADE` | 非 Linux 必须显式返回 `DB_NOT_SUPPORTED`，禁静默失败 | A3 | pending |
