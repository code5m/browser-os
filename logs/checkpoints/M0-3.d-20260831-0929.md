## 收口规则

1. **不再经 shell**：`Command::new("sh").arg("-c")` 彻底移除，字符串不再被二次解释。
2. **禁解释器兜底**：`sh`/`bash`/`zsh`/`fish`/`powershell`/`cmd` 一律不得作为启动目标——否则等于换个壳绕过收口（这是本轮最关键的补充判断）。
3. **可执行性校验**：绝对路径须是文件，否则沿 PATH 查找；查不到即拒绝（`LaunchProgramNotFound`）。
4. **字段码剔除**：`.desktop` 的 `%f/%F/%u/%U/%i/%c/%k` 等由启动器填充，程序自身不理解。
5. **审计**：每次启动写入 `log_audit(action="launch")`，记录 program 与 args。

## 兼容性（已核查，无需改前端）
