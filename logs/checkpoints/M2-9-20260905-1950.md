## 一、验收目标（DAG 收口：M2-7/M2-8 的验收基线 F9 在此兑现）

五个内置种子工具（json / base64 / timestamp / regex / cron）须满足：

1. **可枚举**：经 `list_tools` 返回 5 条，字段齐全（id/name/category/source=Builtin/entry）。
2. **离线可开**：经 `open_tool` 以 `tool-<id>` 打开，URL=`tool://localhost/<id>`，不依赖网络。
3. **零外链**：每份种子 HTML 不含 `http(s)://`、不含 CDN/外部 `script src`/外部 `fetch`/`@import`/`<link href>` 外链。
4. **零 bridge 写原语**：每份种子 HTML 不含 `invoke(` / `window.__TAURI__` / 任何 `@tauri-apps/*` 引用（纯前端自包含）。
5. **单数真源**：每份种子 HTML == `builtin_tool_html(id)` 嵌入字节（M2-7 F9：仅一处 `include_str!`）。
6. **隔离断言（F4）**：工具窗口 `tool-*` 不出现在任何 capability → 零 bridge 权限；即便恶意用户工具 HTML 调 `invoke` 也被能力层拒绝。
7. **打开负向**：`open_tool` 拒绝含 `/` 或 `\` 的非法 id（Err，不创建窗口、不 panic）。
8. **路径越权防御（F5）**：`user-<文件>` 经 `canonicalize`+`starts_with` 校验；`..`/非 `.html`/跳出 `workspace/tools` 一律拒绝。
9. **错误页零外链**：`error_page` 内联、无外链、不泄露绝对路径（M2-8 已落，此处回归固化）。

## 二、冻结决策（F1~F9）

| 码 | 裁定 |
|----|------|
| F1 | **自动化以两层并进**：(a) Rust `#[cfg(test)]` 单测直验 `builtin_tool_html(id)` 嵌入字节内容（零外链/零 invoke/非空）——单数真源；(b) 新夹具 `scripts/check-seed-tools.py` 在门禁层复验种子文件 + capability 隔离 + `list_tools` 覆盖 |
| F2 | 不做运行时窗口测试（`WebviewWindowBuilder::build` 需 GUI/事件循环，headless 易碎）；离线打开由「F3 零外链 + F5 嵌入字节 + `tool://` 协议」结构性保证，回归固化 |
| F3 | 外链判定：`http://` `https://` `<script src=` 指向外域、`@import url(http`、`<link rel=stylesheet href=http`；`tool://` 不计（本端协议） |
| F4 | 写原语判定：`invoke(`、`window.__TAURI__`、`@tauri-apps`、`__TAURI_INVOKE__`、`window.__TAURI__.core`；内置工具应全为 0 |
| F5 | Rust 单测对 5 个 id 逐一 `builtin_tool_html(id).unwrap()` 非空且不含外链/invoke；并断言 `BUILTIN_TOOLS` 与 `builtin_tool_html` match 臂一一对应（夹具层） |
| F6 | 隔离以「capability 零 tool-*` 为权威断言（M2-8 TOOL_CAPABILITY_LEAK 已落，M2-9 复用并明确为收口证据）；运行时拒绝由 Tauri 能力层保证，记为「结构断言 + 可选手动集成验证」，不引入 headless 运行测试 |
| F7 | `open_tool` 非法 id 拒绝逻辑（`id.contains('/')||id.contains('\\')`）由夹具结构性复验存在；Rust 端不单独开窗口测试 |
| F8 | 路径防御抽离为纯函数 `validate_user_tool_path(base, file_name)`（无 `AppHandle` 依赖），Rust 单测覆盖：非 `.html`→Err、含 `/`→Err、含 `\`→Err、symlink 跳出 base→Err、合法文件→Ok |
| F9 | 错误页回归：夹具扫描 `tools.rs` 的 `error_page` 内联字符串无 `http(s)://`；Rust 单测断言 `builtin_tool_html` 字节不含路径泄露（非必，F3 已覆盖） |
