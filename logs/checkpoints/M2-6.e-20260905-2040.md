## 一、目标

首次打开命令库不再为空：预置五类（系统 / 网络 / 磁盘 / 进程 / 文本）**只读**常用诊断命令，标 `builtin: true`，逐条标注 `dangerous`。

## 二、冻结裁决（F1~F5）

| 码 | 裁决 |
|----|------|
| F1 | **单一真源＝代码内嵌**：种子以 `snippets.rs` 常量函数 `builtin_snippets()` 内嵌（类比 `tools.rs::BUILTIN_TOOLS`），**绝不写入** `snippets.json`。理由：不落盘则用户删除/编辑天然无法污染内置集合，幂等且零迁移成本。 |
| F2 | **id 带前缀** `builtin:`（`BUILTIN_SNIPPET_ID_PREFIX`）。`can_delete` 已拒删；本卡额外在 `snippet_update` 拒绝该前缀 id，防命名空间冲突。 |
| F3 | **全部只读**：种子仅含诊断类命令（uname/uptime/hostname/ss/ip/ping/df/du/ls/ps/free/top/grep/wc/cat），无写盘、无删除、无网络写入 → `dangerous` 一律 `false`。此「逐条标注」即 D19 要求的标注动作。 |
| F4 | **禁止 shell 拼接**：`argv[0]` 必为字面量程序名；任何种子不得含 `sh -c` / `bash -c`。与 `M2-6.a §7 F1/F2`、`M2-6-fix1 P1-2` 口径一致。含占位符的内置（如 `{PATTERN}`/`{FILE}`）须为**整元素占位**，且 `params` 中必须有对应参数。 |
| F5 | **五类全覆盖**：`SNIPPET_BUILTIN_CATEGORIES` 五个分类每个至少一条；`merge_builtin_snippets(user)` 返回「内置恒在 + 用户片段保留（误用前缀者丢弃）」。 |

## 三、不变量（验收）

1. `builtin_snippets()` 非空；五分类均覆盖。
2. 每个内置 `builtin==true`；`argv[0]` 非占位符；argv 无 `sh -c`/`bash -c`。
3. `merge_builtin_snippets` 保留用户片段、计数 = 内置数 + 用户数；误用 `builtin:` 前缀的用户片段被丢弃。
4. `snippet_list` 经 `merge_builtin_snippets` 返回；用户首次打开命令库即见内置种子。
5. 不写 `snippets.json`、不改 `validate_snippet`/契约字段、不新增 npm 依赖。
