## 1. 实现范围

- `src-tauri/src/bridge.rs`：新增 `script_runs: Arc<ScriptProcessTable>` 进程表状态；新增 `run_script` / `cancel_script` / `script_status` 三条命令。
- `run_script`：按脚本 id 读取已启用 `ScriptMeta`，复用 `validate_meta` 和 M2-4.b `start_run`，返回内存 `RunSnapshot`。
- `cancel_script`：校验 `run_id` 后调用进程表 `cancel`，只置取消位，真正进程组回收由 supervisor 完成。
- `script_status`：返回内存快照，不含输出正文。
- `src-tauri/src/main.rs` + `src-tauri/permissions/default-commands.toml`：三命令进 `invoke_handler` 与 ACL。
- `src/types.ts` / `src/bridge.ts`：新增 `RunStatus` / `RunSnapshot` 和三条 typed bridge 封装。
- `scripts/check-script-exec-policy.py`：默认 active 码从 b 卡扩展到 b+c 共 16 个；d 卡 4 个码位保持 pending。
- `scripts/check-script-domain-policy.py`：收窄 M2-3 历史边界检测，放行 M2-4 合法运行表/命令层，仍拦 M2-3 领域/持久化越界执行与落盘运行记录。

## 2. 安全与隐私

- 三条命令全部调用 `check_invocation_source`，远程页面/伪造 label 不可直接调用。
- `id` / `run_id` 走形态校验；脚本不存在返回 `SCRIPT_NOT_FOUND`，禁用脚本返回 `SCRIPT_DISABLED`。
- 参数值不在命令层审计；真正参数校验仍在 `script_runner::build_argv` 内按 M2-3 九条 fail-closed 规则执行。
- `RunSnapshot` DTO 只含 `run_id/script_id/status/started_at/finished_at/exit_code/error`，结构性不含 stdout、stderr、body、headers、Cookie、Authorization、token。
- 审计只记录 `id/run_id/status/param_count`，不记录参数值、脚本正文、URL 或凭据。

## 3. 边界

- 本卡不做输出环形缓冲、背压、`script-output` / `script-finished` 事件、`script-runs.json` 落盘。
- 本卡不注册 `kill-running-scripts` 到 `ShutdownCoordinator`；退出收口归 M2-4.d。
- 本卡不做前端脚本执行面板；UI 归 M2-5。
