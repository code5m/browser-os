## 2. 门禁完整性缺陷（F-A11-W15-1）— `build metrics` 基线劫持（已定位并修复）

**严重度：高（门禁可信度）· 不阻断本次发布（真实值仍在上限内）**

### 现象（初见）

`scripts/pre-merge.sh:221` 选取基线的方式为：

```bash
baseline_file="$(ls -1 "$ROOT"/logs/m0-build-metrics/build-metrics-*.json 2>/dev/null | sort | head -1 || true)"
```

`sort` 后**首个**文件为：

```
build-metrics-052b18a.json      ← 被选中（'0' < '4' < 'a'）
build-metrics-4f0e8ab.json      ← 真正的 M0 基线，被跳过
build-metrics-6f4e554.json
build-metrics-886ea29.json
build-metrics-a7eefbb.json
build-metrics-w14-candidate.json
```

`build-metrics-052b18a.json` 与**当前 HEAD 自身**的指标完全一致（`total_bytes=767059`），因此比对结果：

```json
{ "exceeds_growth_limit": false, "deltas": { "total_bytes_pct": 0.0, ... } }
```

初看该门已退化为「HEAD 比 HEAD」，恒为 0.0%。

### 根因（精确归因）

经取证（`git ls-files` + `stat`）：`build-metrics-052b18a.json` 为**未跟踪**文件，mtime **2026-09-07 16:06:19** —— **即本 A11 验证批次在 16:06 自行执行 `measure-build-metrics.py` 时生成的快照**（该脚本默认按当前 HEAD 的 commit 命名写盘：`<root>/logs/m0-build-metrics/build-metrics-{git_commit}.json`）。**并非 A0/A1 在 W15 收口时生成**（初版 checkpoint 误记，以此修订）。

因该 HEAD 哈希以 `0` 开头，字典序排在所有既有基线之前，被 `sort | head -1` 选中，从而把真实 M0 基线 `4f0e8ab` 挤出。真正的脆弱点在**基线选择依赖提交哈希前缀的字典序**——任何 lane 只要在「哈希前缀较低」的 HEAD 上跑一次 `measure-build-metrics.py`，就会留下同名的游离快照并静默劫持门禁。

### 已应用的修复（A11 自清理）

本批次已 `rm -f logs/m0-build-metrics/build-metrics-052b18a.json`（仅删除本批次自己产生的、未跟踪的游离产物，未触碰任何 lane 的已提交文件）。删除后 `sort | head -1` 重新选回真 M0 基线，复跑确认：

```
[pre-merge] M0-4.c 构建指标对比 ... 基线 logs/m0-build-metrics/build-metrics-4f0e8ab.json
[pre-merge] build metrics 未回归（基线 ...4f0e8ab.json）
[pre-merge] PRE_MERGE_RESULT=ALL_PASS
```

```json
--compare build-metrics-4f0e8ab.json
{ "exceeds_growth_limit": false, "deltas": { "total_bytes_pct": 25.14, ... } }
```

即：**真实增长 +25.14%，仍在 25.2% 上限内 → 本次发布真实合规**，门禁在删除游离快照后恢复有效。

### 残留建议（A0 决策，A11 不越权改）

根因在于基线选取逻辑，游离快照只是表象；为避免后续 lane 复现劫持，建议 A0 择一收口：

- **方案 A（推荐）**：在 `pre-merge.sh` 中**显式钉住**基线文件（如 `build-metrics-4f0e8ab.json`），替换 `sort | head -1`；
- **方案 B**：改 `measure-build-metrics.py` 基线选择为「按文件 mtime 最早」或显式配置项，避免依赖哈希字典序；
- **方案 C**：在 `pre-merge.sh` 中忽略未跟踪的、与当前 HEAD 同名的指标快照（即排除 `build-metrics-${GIT_COMMIT}.json`）。
