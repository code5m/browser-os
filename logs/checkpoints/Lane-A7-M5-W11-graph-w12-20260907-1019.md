## 1. 交付摘要

把 W10 图谱 live-query 卡片（`A7-M5-W10-graph-live-query-card-20260907-0927.md`）升级为 **W12 可原子照抄的实施计划**，覆盖 board 要求的五维：command contracts / limits / cancellation / privacy / tests。

**关键判定（本波新增，修正/收敛 W10 的含糊与 stale 文档）：**

1. **范围收窄为 3 只读命令**：`graph_query` / `graph_node_get` / `graph_stats`。明确剔除 M5-8 原始 9 命令设计里的写/列/导出命令、SQLite 持久化、抽取器、后台维护任务——以冻结的 `graph.rs`/`domain.rs` 为真相源（M5-8 的 9 命令 + SQLite + `source`/`source_ref`/`created_at`/`updated_at`/`extractor_version` 设计已被 W5–W10 演进取代，W6 评审 F1 已确认这些字段不存在于真实 DTO）。
2. **命令位置裁定（重要）**：3 命令**定义在 `bridge.rs`**，调用 `crate::graph::*` pure helper + `check_invocation_source`（同在 `bridge.rs`）；`graph.rs` 仍零 `crate::bridge`（守 `GRAPH_NO_SECOND_PATH`）。W10 §2.5 写的是“graph.rs 新增 3 命令”，与 `GRAPH_NO_SECOND_PATH` 冲突（graph.rs 若引 `crate::bridge` 取 source check 即违规），本计划据此纠正。
3. **`GraphState` newtype 独立 managed state**：`pub struct GraphState { pub store: std::sync::RwLock<GraphStore> }` + `impl Default`。因 `AppState`（`bridge.rs` L253）是 `#[derive(Default)]` 而 `RwLock` 不 impl `Default`，改用独立 newtype 可**不动 `AppState`**，避免手动 `Default` 重构与他 Lane 冲突。
4. **稳定错误码 1:1**：`GraphError::code()` 把 13 变体映射为 `GRAPH_*` ASCII 串（W10 §2.6 曾把多类折叠进 `GRAPH_STORE_LOAD_FAILED`，本计划改为 1:1 便于前端映射与测试断言；稳定 ASCII + 零 secret echo 不变）。
5. **View 类型放 `domain.rs`**（DTO 单一真源），`graph.rs` 只放 `From` impl 与 helper。
