## Default Permission

This set of permissions describes the default grants for the browser-tabs plugin.

#### This default permission set includes the following:

- `allow-create-tab`
- `allow-update-rect`
- `allow-set-visible`
- `allow-close-tab`
- `allow-navigate`
- `allow-list-tabs`
